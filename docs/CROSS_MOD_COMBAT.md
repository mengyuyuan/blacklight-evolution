# 跨模组战斗规则

服务端配置文件为世界目录 `serverconfig/blacklight-combat-server.toml`。新世界默认开启；原版生物之间及黑光内部的战斗不应用这套跨模组倍率。原有猎手平衡、母巢结构防护仍然保留。

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| externalDefense | true | 保护黑光注册生物、虐杀模式主角及黑光掉落物 |
| externalIncomingMultiplier | 0.25 | 外部模组攻击伤害倍率 |
| externalWindowHealthFraction | 0.15 | 每个时间窗口最多承受最大生命的 15% 外部伤害 |
| externalWindowTicks | 10 | 共享伤害窗口，20 TPS 时为半秒 |
| externalOffense | true | 增强黑光原生攻击对外部模组生物的伤害，不作用于玩家 |
| externalOutgoingMultiplier | 2.0 | 原生攻击对外部生物的倍率 |
| externalTrueDamage | true | 穿透护甲、抗性、附魔、盾牌及原版效果减伤 |

识别使用伤害类型、直接攻击实体、攻击者及近战主手物品的注册命名空间，不需要逐个添加模组名。其他模组的近战武器复用 `minecraft:player_attack` 时也会识别。虐杀模式拿外部武器近战、使用外部枪械，不会把外部攻击变成黑光原生攻击。

最终 HP 伤害在黑光生命单位换算后再受倍率与共享额度约束；穿甲弹分段命中、重置原版无敌帧、多个攻击者连续命中共用目标额度。它是限速伤害，不是锁血：受伤仍能累积致死，低血量也能被击杀。掉落物使用整数生命，每个默认窗口最多损失 1 HP，避免小数取整绕过保护。预算随实体保存，时间回退时重置。

原生攻击的伤害来源保留原伤害 ID、直接实体、攻击归属、投射物/爆炸标签和死亡消息。仅增强对外部生物的攻击；普通模式使用普通武器、对原版生物及 PvP 不获取该倍率和真伤。

TheTitansNeo 1.0.8 与 Potentia beta 0.12.2 的可选桥接对黑光真伤放开自定义单次限伤。子弹俯冲保持原有高度伤害桥接。有效伤害达到泰坦剩余生命就进入其正常死亡流程，保留击杀归属与原生死亡动画，不让活实体凭空消失。普通武器上限、无敌阶段与行政无敌保留。

## 适配边界

通用规则处理正常 `hurt` 伤害链。直接 `setHealth`、`discard`、绕过伤害链的强制击杀，或完全自定义生命系统仍需针对相应模组适配；不能承诺任意模组的任意实现都被拦住。原版 `/kill` 和虚空伤害不进入保护规则，也不拦截其他模组的死亡事件。此配置不修改对方 JAR，不增加必装前置。

可选安装联测使用 `-PcompatLiveTest`，复现环境与精确第三方版本见 HIVE_AND_BULLETDIVE.md。没有打包第三方 JAR，也不把 QA 测试类放进发行包。

## 已执行验证（2026-10-18）

两版各 8 项真实模组 GameTest 通过。NeoForge 验证 TheTitansNeo 自身 attackEntity 连续攻击 30 次也不会触发强制删血兜底；Forge 另测百万生命蜘蛛泰坦。两版均验证主角、猎手、掉落组织、开关及原版战斗隔离。1500 点原生近战对带护甲/抗性的泰坦造成完整 3000 点伤害，后续足量攻击进入正常死亡并保留玩家归属。TaCZ 30 发普通/穿甲轮换使 800 HP 母巢损失 25 HP，后续原形体近战仍造成原定伤害。NeoForge 443、Forge 444 项单元测试通过。
