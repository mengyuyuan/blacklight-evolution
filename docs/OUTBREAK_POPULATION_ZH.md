# 感染体密度与城市名额 · 2026-10-29

本轮针对 NeoForge 1.21.1。保留区域阶段、真实养分、游戏规则、碰撞和不加载远处区块的限制。

| 项目 | 调整前 | 调整后 |
|---|---|---|
| 城市名额 | 所有 Mob 共用80 | 默认非感染体48、感染体128，合计硬上限176 |
| 96格局部感染体 | 绿8、黄14、红18 | 绿8、黄20、红32 |
| 补怪周期 | 60tick（约3秒） | 40tick（约2秒） |
| 每玩家每轮最多补充 | 所有区域均1 | 绿1、黄2、红3 |
| 维度共享每轮最多出生 | 4 | 8 |
| 每玩家每轮候选位置尝试 | 6 | 12 |

这些是目标上限，不是强制生成的保证数量；空间、区域概率、区块运行范围和其他产怪来源仍会影响实际结果。

`cityMobLimit` 现在限制非感染体（居民、军方、其他普通生物），感染体使用 `infectedPerDimension`；发布过程中尚未可见的实体也保留对应名额。两类加起来的硬上限避免旧存档或模组生物过多时无限增刷。例如旧存档已有80只非感染体，在默认48+128设置下最多还能新增96只感染体，不会删除那80只，也不会超过176继续补怪。`cityMobLimit=0` 仍关闭城市全部人口生成。

红区外围城区补怪不再被“48格内所有Mob达到8只”的旧街道人口限制卡住；它服从感染体的局部/维度上限。居民、士兵保留自己的局部防拥挤检查。

一轮补充多只后会重新统计邻域普通、成长、成熟谱系，后续出生根据真实新种群补位。晚期普通感染者仍占权重60%，便于玩家消耗、回血；成熟宿主和猎手占比适度增加。高阶阶段仍要求释放病毒后的实际时间，进化者仍需真实吞噬和器官整合，不会无条件空降。

## 配置

`blacklight-outbreak-server.toml`：`spawnIntervalTicks=40`、`infectedWithin96Blocks=32`、`infectedPerDimension=128`、`birthsPerBatch=8`。

`blacklight-city-server.toml`：`cityMobLimit=48`（新含义是非感染体预算）。

`blacklight-gameplay-server.toml` 的 `[outbreak]`：`yellowLocalCap=20`、`spawnPositionAttempts=12`、`greenBirthsPerPlayer=1`、`yellowBirthsPerPlayer=2`、`redBirthsPerPlayer=3`。绿/黄/红概率仍为12/55/100，阶段日期仍为1/3/7/14。

旧服务器的配置值不会被模组强行覆盖；要采用这组密度，需要手动调整已有配置或使用本轮附带预设。本机试玩实例会备份旧配置后应用这些值，其余设置与存档保留。

验证结果与产物见 E:/Blacklight-Spawn-Density-20261029/verification.json。
