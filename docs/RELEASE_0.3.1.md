# 0.3.1 — 子弹俯冲落地负载修复（NeoForge 1.21.1）

0.3.0 实测从 Y=66666 俯冲到主世界 Y=53 后，服务端累计落后 200713 ms。
退出后存档中有 11173 个掉落物实体、704 个经验球；另有大量方块和流体更新。
原有每刻破坏预算没有涵盖破坏后持续存在的实体和下一刻更新成本。

## 修改

- 每个维度的所有俯冲任务共用负载预算；达到 768 个掉落物、128 个下落方块或 512 个经验球时暂停继续破坏，负载降低后恢复。
- 每刻破坏最多 512 块，最多使用 8 ms；本刻其他服务端工作接近 40 ms 时减少或暂停破坏预算。
- 掉落物按空间单元寻找附近可合并对象，保留原版合并规则、物品组件、拾取归属、堆叠上限和实际数量。
- 不改下落加速度、高度威力公式、伤害和坑洞目标范围。过载暂停不消耗剩余破坏能量，也不会删除掉落物。

## 验证范围

- 单元测试覆盖累计掉落物压力、多个任务共享预算和服务端繁忙时的时间预算。
- 专用服务端测试使用 66666 格威力，验证过载时不破坏、不消耗能量，清除测试压力后恢复。
- 实际方块破坏测试验证 320 块石头的掉落数量守恒及附近合并。
- 此修复防止新的俯冲继续堆积实体；不会自动清除旧存档中已经存在的上万掉落物。
- 极高高度下若玩家不拾取掉落物，地形任务可能等待原版掉落物自然消失后继续。这是负载保护，不是瞬间完成整片坑洞的保证。

尚需人工复测完整主世界 66666 格俯冲与多人同时施放；不把专项回归通过等同于所有环境不卡顿。
