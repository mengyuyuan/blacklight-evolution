《虐杀原形》Blacklight: Ascension — Minecraft 1.20.1 Forge
版本：0.3.0-forge-1.20.1-dev.5（开发预发布）
原作者：末者；Forge 移植维护：雨夜。

包含新毁灭技、子弹俯冲、原地蓄力防滑、红雾修复及感染怪物死亡后的 capability 崩溃修复。作者已补齐 27 个新技能动作，完整 bundled 包内置 251 份资料，无需另外设置动作目录。

安装：
1. 使用 Minecraft Java 1.20.1、Java 17、Forge 47.4.10。
2. 将本版 bundled.jar 放入 mods，移走旧 Blacklight JAR，避免重复加载。
3. GeckoLib 4.8.4 是必装前置模组，必须选择 Forge 1.20.1 版并单独放入 mods。客户端和服务端都要安装；完整包不内置它，缺少此前置无法启动模组。
4. MixinExtras 已内嵌，无需另装。
5. ParCool 可选；不需要 Epic Fight、Epic ParCool 或 Weapons of Miracles。
