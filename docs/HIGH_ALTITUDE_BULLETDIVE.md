# 高空子弹俯冲强化（2026-10-13）

本轮保留原版解包已确认的起手、飞行、真实接地与收回动作；速度系数和新增的风压层是 Minecraft 表现调校，不声称是原版重力数据。

## 下落

客户端预测和服务端控制器共用 BulletdivePhysics：以真正进入 FLIGHT 后的 tick 数 t 计算 v = 0.9 + 0.36t + 0.02t²（格/tick）。加速度也随时间增长；无玩法高度或终端速度上限。由同一动作时钟重算速度，不从原版量化的速度包累积，避免 3.9 格/tick 的包截断。数值达到 double 表示边界时才防溢出。

地面碰撞仍使用 Minecraft 实际碰撞，实际接地才触发伤害和坑洞；伤害、破坏威力继续根据服务端记录的实际落差计算。未提升网络更新频率，未加入按高度增长的粒子或实体数量。

## 表现

- 常规气流保持短距离就可见；额外高速通道按对数压力持续增长，普通跳楼和超高空不再很早呈现相同强度。
- 加长组织拖尾，增加固定数量的气流条和连续尾部风压圈。高速气流使用连续光学时间，不再只用实际落差取模，减少高速闪烁。
- 加强沿实际下落方向的边缘模糊、空气条纹和镜头视野变化，中心保持可辨。仍遵守玩家的视野效果与屏幕效果设置；不锁定视角、鼠标或 F5，不修改第一人称手臂投影。
- 特效顶点先用双精度减去相机位置，再转 GPU 浮点坐标，修正千万格高度下绝对坐标量化导致的跳动。

- 高速第三人称仅对附近的本地俯冲角色绕过当前 tick 坐标的距离裁剪，防止帧间插值位置仍在镜头旁时人物被提前隐藏；其他实体与普通状态保持原规则。

## 验证与边界

两个版本各 27 项俯冲物理、破坏预算、特效时序与世界气流测试通过，独立边界检查通过。实机结果另见交付目录验收记录。全量回归沿用上一版已记录的未解决失败，不把专项通过说成全量通过。

千万格单独测试关闭方块破坏以隔离速度、碰撞和同步；这不代表已经运行了千万格的完整巨坑破坏或多人压力验收。80/2000 格另用真实方块破坏、实际伤害、恢复及 GPU 截图验证。

NeoForge 千万格实机：真实落地，控制器峰值 26219.78 格/tick；5199 个高速帧均捕获到真实人物骨骼。约 59 秒含末尾恢复观察，未发生穿地。速度图形与碰撞测试使用集成服务器，不等同多人网络压力测试。

Forge 千万格实机也已真实落地，峰值 26265.60 格/tick，约 59 秒含恢复观察；2744 个高速帧中 2742 帧捕获人物骨骼。80 格首次并行运行漏拍了指定特效帧，单独重跑后全部通过；2000 格的释放、伤害、破坏、收回与截图通过。
