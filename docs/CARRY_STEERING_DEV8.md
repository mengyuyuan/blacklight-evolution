# dev.8 — 持有生物时的移动转向

持有生物时 `CONSUMING` 附件仍为 true，旧的镜头相对移动入口因此跳过朝向更新；第三人称鼠标转镜头后，人物仍沿抓取前的朝向解释按键。

现在只有普通持有阶段（HOLD）开放携带转向。W/A/S/D 以实际控制镜头为参考，人物每 tick 最多转 45 度；原版移动输入同时换算到转身后的坐标系，保证按 S 或侧向急转不会把世界移动方向再转一次。人物、握持点、接收者共用实际人物朝向及同一插值，渲染时修正转弯圆弧与直线位置插值的差异。碰撞检查仍然适用。

捕获、吸收、投掷和攀附阶段保留既有动作朝向约束；第一人称沿用原生鼠标控制。不会改写动作资源、F8 配置、伤害或吸收结算。

验证：`CarrySteeringTest` 3 项，包括 270 种镜头角、人物角及 W/A/S/D/对角输入组合的世界移动向量不变量，以及后退/侧移转为前向步态、松键不产生运动。完整打包和 224 文件资料检查通过。该数学检查不是实际客户端抓取、网络与碰撞验收；需在新启动的 dev.8 中复核持有走跑、急转、投掷及吸收。
