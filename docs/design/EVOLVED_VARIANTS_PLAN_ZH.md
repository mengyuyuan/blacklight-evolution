# 七类进化者实现计划

范围 NeoForge 1.21.1。继承已完成刃臂样板，不改六次成熟吞噬、器官整合和选型冻结规则，不做另一开发者负责的清剿/黑色守望内容。

| 实际类型 | 主导偏向 | 外形 | 专项战斗 |
| --- | --- | --- | --- |
| strength_evolved | 力量 | 方块人、完整锤拳双臂 | 有前摇和收回的震地范围攻击 |
| armored_evolved | 重甲 | 左前臂原作盾甲与触须组织、右短刃 | 有耐力和破防空当的正面格挡、盾击 |
| predator_evolved | 掠食 | 二代三级利爪双臂 | 短扑杀、命中后的有限取血 |
| tendril_evolved | 触须 | 钩状前臂与可伸展肌束 | 可躲开和被墙阻断的拉拽，正常碰撞移动 |
| skirmisher_evolved | 机动 | 保留原刀臂结构、缩短远端的轻型双刃 | 有准备动作的高速短突袭，碰撞和悬崖检查 |
| sensory_evolved | 感知 | 二代二级利爪的骨质末端 | 瞄准后实际骨刺实体投射，不穿墙命中 |
| regenerator_evolved | 供养再生 | 二代二级触须组织双臂 | 消耗真实养分治疗附近实际感染同伴 |

稳定类型进入服务端运行集合与数据包候选后才开放自然选型。旧存档已经选型的个体维持选择，旧无字段个体继续刃臂。客户端从同步的宿主选择读取类型，不重新抽签。

用户明确要求达到已有双刀的精度，并连续否决简单拉伸轮廓、粗糙材质与统一面具外形。此前胶囊/切面拉伸武器不作为交付模型。本轮改用已解包的二代实际 power 表面，按双刀的同类方法适配肩肘、保留源拓扑；不是按一个简单截面反复拉长。

建模规范按 blockbench-use / blockbench-modeling：Java 桌面原生实体光照；标准玩家身形；沿用 67 关节和已适配的肩肘锚点。原作武器保留约 1,900–3,300 个三角面，角色增加独立兜帽边、衣袋、护膝与靴子。腿部表面收窄以保留间隙，原武器未覆盖的上臂保留衣袖连接，避免丢肩。源色区映射到本模组 MC 顶点调色板；没有将原游戏贴图文件打入模组。共用 128×128 人物图集与已有/小型 256×256 武器图集，不靠大贴图补偿轮廓。

当前没有可用 Blockbench MCP 连接，使用可复现的资源构建脚本生成专用运行网格与可编辑 Generic Model，再在原生游戏内检查连接、行走、专项前摇/接触/收回。编辑源不冒充已包含运行时双权重蒙皮。

Generic Model 的材质已内嵌，顶点调色板另转成内嵌小型色板；打开文件不依赖本机绝对贴图路径，也不将有颜色的武器导出成白模。运行模型继续使用双权重和顶点色，不因编辑源格式而降精度。机动型与盾甲右刃使用原刀臂图集，避免套用新武器通用图集。

源参考核对 `E:/Prototype2-Research-20261024`：已导出 gray、runner1、default 三套参考；运行骨架通用移动、闪避与刀臂动作保持原文件。七种专长为该模组器官偏向的适配设计，不宣称二代原游戏本来就有这七种命名敌人；专项动作在既有骨架上单独制作，不修改已有动作采样精度。

实际采用 `alex_hammerfist3`、`alex_claws3`、`alex_tendril3`、`heller_shield_3`、`alex_claws2`、`alex_tendril2`。具体源文件 SHA256、源/适配面数及保留侧别写入 `evolved-variants-geometry.json` 和运行模型 `sourceSurfaces`；三级锤拳的 2,518 个源三角面全部保留。机动型保留已有 Runner1 刃面并缩短远端；盾甲右臂沿用已有刃面。

验收逐类做真实六器官选型、完整蜕变、保存恢复、实际攻击/特殊效果、受击与中断、墙体及无效目标、客户端移动与动作阶段。全部通过前不将七种预留名称算成实装完成。
