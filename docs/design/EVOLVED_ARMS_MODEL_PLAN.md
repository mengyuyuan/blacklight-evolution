# 进化者专用双臂

目标是保持普通方块人身体，优先细致、清晰的生物武器外形。面向 NeoForge 1.21.1 桌面客户端，主要观察距离三至十二格。肩、肘使用已经适配的二代原骨架；模型不覆盖头部或改变身体比例。

几何采用本地二代 `evolved_runner1` 的对应原刀臂表面，保留刀背倒刺、镂空、正面细长和侧面宽刃的轮廓。完整双臂适配肩肘，而非把玩家武器套在手腕。前臂与腕部的原权重归并到刚性刀臂；保留腕关节长度，只适配超出腕部的远端长度，避免垂直站姿插入地面。细血管使用新制像素图集；标准方块身体采用新制兜帽、面罩与战术服皮肤。

基础材质使用原生实体光照和不透明网格，微弱发光层只绘制命中血管像素的表面；不依赖光影包或 PBR。共享 256×256 图集，横纵四像素每模型单位。原刀臂共有一千九百三十二个三角形，体表形状保留，发光面按贴图局部筛选；当前包含身体和退化四边形在内的 GPU 提交预算低于六千三角形。保持少量材质批次。

`tools/fit_p2_evolved_arms.py` 适配原刀臂并生成像素材质，保留 `art/evolved-arm-adapter/evolved_arms.bbmodel` 供编辑。该文件是中立姿态双臂的编辑源；完整运行时蒙皮与二十七份动作或姿态通道保存在模组资源及 `evolved-poses.data` 中。其中待机与戒备各取原片段首帧作为基础姿态，其余保留完整采样。编辑源不包含运行时权重控制器，不能替代完整骨架。

验收检查站立、奔跑、双斩、跳斩、受击、近距离抓取和持续连击；除了中立轮廓，还检查运动中的肩肘缝隙、刀锋朝向、贴图与控制恢复。帧率结论须以实际多人/多实体场景测量为准，不由面数或截图推断。
