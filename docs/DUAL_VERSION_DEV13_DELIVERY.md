# 双版本技能与冲击更新

NeoForge 1.21.1 / Java 21：0.3.0-standalone-dev.13。
Forge 1.20.1 / Java 17：0.3.0-forge-1.20.1-dev.4，独立适配 PR。
用户要求两个版本一起提交；两份 PR 并行审阅，不把尚未合并的来源提交写成已合并 SHA，也不互相整支合并。

## 本次行为

- 临界质量蓝血、三个地面/空中毁灭技和独立收招；作者制作的方块地刺和组织模型、场景扭曲。
- 子弹俯冲持续加速，伤害、破坏能量与坑深随真实落差增加。50 格以内红簇，超过 50 格追加红雾。
- 服务端拥有方块破坏、保护事件、掉落和玩家设置；全服共享工作预算。不是 TNT 射线爆炸实现。
- 原地按住空格蓄力时清除水平惯性和行走输入；移动蓄力、起跳和镜头仍保持原有控制。
- Shader 重载监听改为注册在 Mod 事件总线。

## NeoForge 验证

隔离工作区重新 assemble，核对 251 个运行资料；本轮针对姿态时钟、俯冲算法、临界质量、技能和设置的 37 项测试全部通过。
前序同版本 native 验收：dev12 burst-v2 实际 78.795 格/232 方块/2 个工作 tick；638.795 格/2024 方块/10 个工作 tick。箱子、库存掉落、保护和开关通过。
dev13 planted-v3 客户端 32 / 服务端 34 个蓄力观测样本最大水平漂移均为 0；running-v2 跑跳衔接通过。
没有据此宣称多人压力测试或所有其他 Mod 兼容通过。

## 产物范围

本次可玩交付使用 external-profile（251 文件），含新技能和身体恢复。默认公共构建 bundled（224 文件）仍是基础动作集；新技能曲线沿现有研究规则保留仓库外，不把基础包冒充完整技能交付。
外部 profile 通过成品字节核对，原游戏网格、纹理和 FX 研究数据不进入安装包。源码、可编辑模型、导出脚本及来源说明随各 PR 审阅。
同一服务器两端必须使用相同 Minecraft、加载器、模组版本和 profile；不要将 1.21.1 存档直接降到 1.20.1。
