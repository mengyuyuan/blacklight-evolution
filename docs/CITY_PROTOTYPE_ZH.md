# 城市维度样板（NeoForge 1.21.1 / Forge 1.20.1）

新建世界默认生成深圳福田市民中心周边的独立城市维度：约 1440 × 1232 格，一米一格，使用 OpenStreetMap 实际路网和建筑轮廓，经 Arnis 3.3.0 生成并转为离线方块模板。市民中心、图书馆、音乐厅、书城及周边道路均在该区域内。地图不在玩家电脑上联网下载。

这是实景数据驱动的可玩样板，不是测绘级、逐房间的精细复刻：缺失的建筑高度和内部装饰由生成器补足，地面暂为平地。旧的 512 × 512 程序化测试城市保留原生成器模式，不会强行重写既有区块。两个版本使用同一份城市布局和建筑模板。

市民中心已单独重建 486 格跨度的薄屋顶、黄色圆塔、红色方塔、中庭和南侧阶梯，避免自动生成器把屋顶拉成楼体。图书馆、音乐厅东侧入口补充玻璃立面和树状支撑，南广场补充步行铺装、座椅和照明；其余周边建筑立面仍属实景数据基础版。修改地标只作用于新生成区块，试玩应新建地图，已有城市不会被自动覆盖。

## 进入与返回

- 合成“城市通行信标”：上方一铁锭，中间铁锭 / 指南针 / 铁锭，下方一红石粉。右键切换城市与进入前的地点。
- 也可以使用 `/blacklightcity travel`，不要求管理员权限。
- 进入前的位置和维度存入玩家数据，返回时检查安全落脚点；有 2 秒传送冷却。乘骑、睡眠、死亡时不能使用。
- 新城市入口在市民中心南侧广场。返回道具不会消耗；即使丢失道具也可以使用返回指令。

## 城市与母巢

- 真实路网和主要建筑位置固定，建筑内部采用 Arnis 生成的楼层与陈设，不声称对应现实内部布局。
- 市民中心及中轴线核心区保留正常状态；两座母巢分别从西侧、东侧各四处建筑候选点中按种子选择。外围包含感染区、边缘区和交火区，感染只改变街区状态，不随机移动深圳建筑。
- 城市母巢寄生于普通建筑，与现有的巨巢 Boss 是不同内容。摧毁建筑外墙七个“母巢孵化口”会使该母巢失活，停止生产和扩散；已生成的感染者不会因此消失。
- 孵化口开启时会产生感染者，偶尔产生猎手；周边敌人过多时暂停生产。正常街区有居民，交火区有黑色守望士兵。
- 扩散只在已加载且正在运行的区块内进行，每次扩展一个相邻街区，最多增加 12 个街区。关闭服务器、离开维度不会补算离线扩散。
- 血肉覆盖、组织束、脉管、硬壳、坏死组织、薄层、孵化口和囊泡采用项目自制像素材质。

## 服务器控制

配置文件：存档的 `serverconfig/blacklight-city-server.toml`。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| population | true | 居民、感染者、军队生成总开关 |
| infectionSpread | true | 新街区感染扩散总开关 |
| hiveFacadeDamage | true | 母巢失活后下部外墙坏死变化 |
| cityMobLimit | 80 | 城市维度已加载 Mob 总数上限 |
| spreadIntervalSeconds | 180 | 扩散间隔（秒） |

管理员可以在游戏中使用 `/blacklightcity population false`、`/blacklightcity spread false`、`/blacklightcity facade false` 暂停相应行为；把 false 改成 true 可恢复。游戏内开关会随存档保存，仍受服务器配置总开关约束。

`/blacklightcity status` 显示母巢失活数量和新增感染街区数量。

`/blacklightcity credits` 显示地图署名。数据来源与复现步骤见 `FUTIAN_DATA_SOURCES.md`。

## 当前边界

- 城市区域以外暂为平坦草地，不是无限城市。
- 地面扩散和坏死变化有每秒更新预算；只替换与生成状态一致的方块，并避开记录到的玩家放置位置。其它模组绕过放置事件直接写入同种方块时，无法区分其来源。
- 母巢失活只影响下部外墙外观，不会把整栋楼替换为空气。原作逐帧垮塌动画尚未复刻。
- 清空过的普通街区不会因重新加载而反复补人口；母巢生产与扩散、进度和关闭状态由服务端保存。
- 原作参考来自本机资源中 `HiveXX_tod` / `props_tod` 的外墙刷怪点标记，以及原作任务资料。七个孵化口、生成间隔和范围是本样板的玩法参数，不声称是原作精确数值。

## 开发验证

`gradlew test --tests '*CityLayoutTest'` 检查布局边界、种子变化和入口保留。

`gradlew runGameTestServer -PcityTest` 检查真实维度生成、跨区块高度、母巢孵化口、通行路径与状态保存。NeoForge 的专用测试资源在 flat 测试预设中加入城市；Forge 使用独立的 city_futian / city_legacy 测试维度。测试预设、额外测试维度和测试类不进入发行包。
