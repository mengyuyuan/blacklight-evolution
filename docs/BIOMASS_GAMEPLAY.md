# 粘液玩法测试说明

轻按 X 身份变形；长按 X 约 0.35 秒打开独立「特殊变形」轮盘，滚轮选身份变形或生物质粘液，松开确认。Esc / 右键取消轮盘。X 不使用原来的 Z 武器/辅助轮盘，按键重绑后轮盘提示跟随变化。

主动粘液：留下一具外壳，轻按 X 或在独立轮盘选择「返回原壳」可取消，不回血；尚未完成的吞噬会中断并释放生物。原壳必须仍然存活、在同维度已加载区域且有站立空间。

死亡粘液：另一种小型身体，靠八条贴地触须交替伸出、收缩来拖动。没有外壳，不能取消、关虐杀模式或退出重进来恢复人形。再次真正死亡并重生也保留死亡粘液状态，必须吞噬生物。虚空等绕过无敌的直接死亡仍遵守原版死亡规则；已成功吞噬则允许完成重构，不重复要求进食。

贴近可吞噬生物后，粘液覆盖它的实际模型；服务端确认击杀后恢复主角，不残留第二团粘液。低矮空间保持粘液，可以爬到空地完成重构。

原壳爆发会留下真实组织方块底座，每次随机尝试生成 6～12 条细触须。触须优先寻找附近地面、墙面或玩家放置的实体方块作为锚点，部分末端形成组织块团。随机布局只由服务端生成，并随实体同步和保存；客户端不每帧随机。挖掉锚点后对应触须停止显示。组织块和持久触须不会按特效寿命自动消失。

触须延展半径约 7～11 格；伤害半径 11 格，保留视线检测。实际地形破坏最多 160 格，跳过容器、液体和不可破坏方块。底座最多 6 块，远端组织块每组最多 4 块；保护事件和 mobGriefing 均生效，不强制加载区块。范围是 Minecraft 适配值。

服务端与客户端需安装同版。本包为测试版本。

模型使用连续连接的低多边形曲面与逐渐变细的触须，不再叠方块。移动时两组触须交替抬起寻找地面，支撑触须的末端固定在世界坐标；停步后收稳，转身重新选落点。触须地面探测仅在换落点时运行，不创建新实体或强制加载区块。

0.3.4-biomass.9：粘液主体改成八边棱面的扁平轮廓，触须使用六边截面和平面光照，复用武器的黑红像素材质；贴图随模型变形，不随世界坐标游动。保留连续弯曲和抓地步态，不使用分离的方块节段。
