# 黑光生态共存修复 · ecology.1

## 本次行为

- 全局疫情时钟只决定可用阶段。自然感染和环境补怪必须附近有活感染体、实际组织/巢口、存活建筑核心或最近一次投瓶事件；历史红区/全局启动记录不能单独充当来源。
- 自然补怪、孵化、环境感染、自然近战接触感染共享已加载维度与区域预算。感染初期即占名额，等待转换不会产生第二份额度；回调期间预留名额，失败或保护否决释放。
- 环境概率每轮只判一次，找落点的次数不再放大感染概率。旧城市初始街区、道路补怪、居民感染和地表组织蔓延也接入来源/保护规则。组织探测只读已加载区块。
- 手动投瓶与玩家主动感染弹仍可在局部发动感染，允许超过自然软预算；实际数量会阻止后续自然补充。不会自动删除已有感染体。
- 自然感染默认保护命名生物、驯服宠物、原生交易 NPC 和无敌对象。黑光城市自行生成的居民仍属于可感染生态。免疫规则对手动与自然感染均生效。
- 安装 OPAC 时，通过其公开领地权限 API，以不具管理员权限的黑光自然生长身份检查自然感染和补怪。领地 API 异常时拒绝该次自然推进、保留原实体，不批量报错。未知领地/任务系统可用免疫规则、保护标记或 `NaturalInfectionEvent` 对接；没有宣称任何保护模组自动完整适配。

## 第三方生物保留

第三方生物默认承载感染，而不是被删除后创建通用宿主。保留同一个实体与 UUID、AI、移动、装备、原生属性修正、境界/灵气、法术和任务能力。原生和平/交易/战斗逻辑仍由原模组控制，不强行用近战 AI 取代施法、飞行或脚本。

附着的黑光组件保存组织年龄和稳定器官偏向，使用现有无限成长公式，提供自己的生命/攻击/护甲修正及成熟器官的补充战斗效果；器官质量可参与吸收研究。修正使用独立 ID，不覆盖外部属性基础值、不因存档/重复更新复乘。治愈后移除自己的修正。年龄按实际加载的实体 tick 增长并同步观察者，不按离线时长补涨。

这不是宣称所有外部模型都已有完整高级异变建模、聚合体吞噬、器官动作或进化者转换。原生技能与模型由原实体保留；高级解剖形变/转换需要明确的物种适配。现有原版生物与旧宿主的器官、聚合体和无限进化继续工作。

## 伤害与收益

默认不因玩家装备来自外模组，就统一扣掉 75% 伤害。识别伤害归属、投射物、已加载宠物/召唤物和常用 owner/caster/shooter 接口；未提供可识别归属的自定义攻击需要该模组的适配。

普通感染体不套用精英的跨模组伤害窗口。猎手、进化者、母巢、九头蛇等对外部 NPC 保留现有防尖峰窗口；玩家输出走正常合法结算。盔甲、原生盾和伤害事件本身仍有效，不伪造最低伤害。

普通黑光攻击默认不再对所有外部怪物一律双倍真伤。正式大招/子弹俯冲保留显式真伤及泰坦/暮色的已有机制桥接。小翔修仙 NPC 的灵气盾和独立个人灵力盾支持正式真伤；玩家盾、管理员无敌和其他监听器的取消/死亡否决保留。

吞噬把有效威胁换成生物质、进化点和黑光器官研究，不复制整份外模组境界、法术和能力数据。收益对高生命/高攻击/护甲使用对数加成，默认最多 8 倍。这个上限只针对本次额外资源收益，不限制代数、器官或玩家无限进化。击杀仍获得同目标基础吸收资源的 50%，不提供吸收回血/器官发现，不重复结算。

## 配置

新配置：`blacklight-ecology-server.toml`。普通专服通常生成于 `<世界目录>/serverconfig/`，单人于 `saves/<存档>/serverconfig/`；GameTest/部分启动方式可能使用运行目录 `config/`。这是服务端配置，不能只改客户端配置期待联机服务器生效。

| 键 | 默认 | 用途 |
|---|---:|---|
| requireLocalSource | true | 自然感染/环境补怪要求物理来源 |
| livingSourceRadius | 24 | 活感染体/投瓶临时源距离 |
| tissueSourceRadius | 4 | 组织探测半径，仅已加载方块 |
| worldInfectedCap | 96 | 普通维度已加载感染体数量预算 |
| cityInfectedCap | 128 | 黑光城市维度数量预算 |
| worldRegionalShare | 0.35 | 普通区域感染体软比例 |
| cityRegionalShare | 0.8 | 黑光城市区域软比例 |
| preserveExternalEntities | true | 第三方原实体承载感染 |
| protectClaims | true | 检查已安装 OPAC 权限 |
| protectNamedFromNaturalInfection | true | 命名生物保护 |
| protectTamedFromNaturalInfection | true | 宠物保护 |
| protectTradersFromNaturalInfection | true | 原生交易 NPC 保护 |
| immuneEntities | [] | 绝对免疫的 ID/命名空间/实体标签 |
| preserveEntities | [] | 额外保留原实体的 ID/命名空间/标签，可选原版物种 |
| naturalDisabledDimensions | [] | 关闭自然感染与补怪的维度 ID |
| threatRewardStrength | 1.0 | 对数威胁收益系数，0 关闭 |
| threatRewardMaximum | 8.0 | 额外威胁收益倍率上限 |

区域软预算按 `floor(max(16, 区域内加载生物数) × 比例)` 计算，还受原有红/黄/绿区绝对数量及维度上限约束；维度上限与旧 `blacklight-outbreak-server.toml` 上限取较小值。两者都统计感染初期。默认比例是可调的共存起点，不是对任意整合包都适用的最终平衡保证。玩家手动感染、现有超额种群不会被清除。

示例列表值：`immuneEntities = ["some_mod:quest_npc", "another_mod:*", "#some_mod:protected_npcs"]`。实体持久数据 `BlacklightNaturalInfectionProtected=true` 可阻止自然感染；自定义免疫实体标签为 `blacklight:infection_immune`。

跨模组战斗配置仍为 `blacklight-combat-server.toml`，新增 `reducePlayerOwnedAttacks=false`、`protectCommonInfected=false`、`legacyBlanketOffense=false`。要明确启用旧版无差别强势规则，应自行开启相应选项；`legacyBlanketOffense` 还需旧 `externalOffense`/`externalTrueDamage` 选项配合。新总开关避免旧服务器保存过的 true 值悄悄继续启用双倍真伤。正式大招不依赖这个旧版开关。

感染、概率、进化速度、初次属性继承、击杀收益及残血保命的既有配置继续保留。未改无限进化、器官成长、代数公式或升级成长倍率。

## 旧存档与验收边界

不会删除旧感染体或重置成长。已经被旧版替换的宿主缺失原生任务/能力数据，无法凭空无损恢复；此次先阻止继续丢失。旧世界需要由玩家正常清理已有种群，或服主按备份制定恢复方案。不要把新数量上限理解为自动全服清怪。

本次通过双版本真实服务端 GameTest、实际 OPAC 0.32.7、小翔修仙 0.2.106 与 0.1.1532_server 验证；具体项目、日志、摘要与制品哈希见交付目录的验收记录。持续传播测试使用真实实体/世界 tick，并显式加速生物成长；记录的 MSPT/TPS 只描述该小型隔离测试，不能代替生产服负载压测。本次不控制鼠标、不启动客户端试玩、不自动更新远程服务器。
