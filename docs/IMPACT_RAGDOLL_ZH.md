# 武器接触与受击布娃娃（开发版）

Minecraft 1.21.1 / NeoForge 21.1.244 / Java 21。代码、资源和构建缓存均在 D 盘；Forge 1.20.1 尚未同步。

## 当前判定

断肢需要两项条件同时成立：服务端接受本次伤害且目标死亡；本次锐利表面扫掠确实接触可分离区域。不再根据武器名称固定砍头、砍双臂或拆成六块。非致命命中仍保留局部受击／击飞控制，不使存活目标凭空丢失肢体。

- 利爪：读取 `claw_blender.json` 中三根长刃和拇指短刃的锐利材质三角面，两只手分别随对应骨骼采样。保留独立刃片标识，各刃分别判断接触，结果按实际触及的身体区域去重。不是“每根刃必掉一块”。
- 刀刃：读取 `form_blade.json` 中连续刀身的锋利表面，随 Hand_R 攻击动画扫过目标。刀背、掌部、装饰突起不作为这次切割面的来源。
- 鞭拳：读取 `whip_tip.json` 的锐利钩刃，用服务端 WhipCurve 的末端和切线定位。墙面截断鞭索后，不在截断处伪造一个刀尖。鞭索中段命中不授权切断。直刺类动作标记为穿刺，不因命中就自动拆肢；横扫／回扫才允许切割。
- 锤拳、肌肉、冲击波、投掷：保留钝击布娃娃，不使用锐刃切断规则。未覆盖骨架的旧钝击处决效果保留。
- 普通剑斧：没有黑光共享骨骼与锐刃网格，使用服务端瞄准射线实际接触的身体区域，不再固定剑断臂／斧断头。

采用原攻击窗口和当前／上一刻位置，采样锐利三角面与旋转后的身体分区碰撞体。每游戏刻至少八段，较快表面按约 0.04 格补插值；单区间最多 32 段。墙体可见性仍由服务端检查。对支持的骨架，近战锐刃必须取得实际几何接触后才扣血，防止宽范围判定提前杀死低矮目标、真实刀锋尚未抵达就结束攻击。身体冲撞和地面冲击波仍使用各自接触规则；不增加伤害次数，不改变掉落。

每个被切下部位携带自己接触轨迹的冲量，猪躯干额外携带各根爪刃接触面的局部位置和法向。每手三根长刃和一根拇指短刃均独立保留，双手最多八个切面；不同刃片不会因为切面接近而在发送前合并。新协议 `standalone-51-contact-wound-blood` 还同步伤口部位、局部位置、喷射方向与强度，联机两端必须更新。

## 伤口血效

对已经支持的成年猪和人形，锐刃按每根实际接触的刃片生成伤口；钝击按已接受伤害时的瞄准／接触位置定位，普通剑斧也接入。受伤点跟随当前模型姿态，倒地时跟随物理身体，断肢时跟随独立碎块；分离处两侧另有短暂出血。只接受服务端命中报告，不由客户端粒子制造伤害或切割。

命中先产生定向喷射，随后衰减为滴落。血滴有重力和方块碰撞，碰地／碰墙形成短暂血迹，约八秒内淡出。使用现有白色材质绘制程序化细条与不规则斑点，不修改世界方块。最多 96 个出血点、768 滴血和 256 处血迹，超出 64 格、卸载世界或超时会清理。喷射散布允许视觉变化，伤口位置和切断结果不随机。已覆盖对象关闭旧的身体中心红色粉尘，未覆盖对象保留原效果。

这是按伤口重新实现的血效，尚未与《虐杀原形》原游戏素材或逐帧录像对齐；编译和客户端启动已通过，游戏内观感未验收。

## 物理与渲染

人形整身使用 11 质点、距离与活动范围约束。头、手臂、腿被授权分离时，复制当时的原模型与贴图，本体隐藏该部位；碎块独立旋转、扫掠方块碰撞、反弹、摩擦与休眠。原版护甲和手持物不会悬在已切掉的本体部位上。独立穿戴护甲暂不复制到碎块；士兵网格自带装备随子模型分离。

成年猪使用独立四足结构：水平躯干、头、四条腿，共六个刚体和五个关节。重击接管整身运动，活体仍跟随服务端位置并在控制结束后用八刻过渡恢复动画；死亡后保留整个物理身体。未切中的关节继续连接，只有服务端确认的锐刃接触可以断开关节。猪躯干命中按接触切面裁剪实际模型表面，保留原贴图 UV 并封闭切口；各段躯干携带其对应的头腿关节，不把每次击杀固定拆成六块。利爪各刃分别产生候选切面，擦边与间距过小的面不制造薄片。碰撞、落地摩擦、旋转和休眠均在客户端计算。猪鞍的原版站立模型层在接管期间隐藏，暂未随尸体复制。

服务端继续负责活体位置、AI、伤害和掉落。客户端最多 32 个人形身体、96 块人形碎片，以及 24 个猪身体／144 个猪物理块；死亡／分离后通常最多保留 100 游戏刻。超出 64 格、离开世界或区块卸载时清理，不创建服务器尸体实体。

## 明确边界

支持默认缩放的成年士兵、黑色守望、普通感染者、僵尸系、骷髅系和猪灵系，且需实际使用 HumanoidModel；另外单独支持原版成年猪的 PigModel。玩家、幼体、骑乘／睡眠目标、其他动物、巨型怪和其他模型尚未接入。

武器侧使用真实导出的锐利网格及共享原生动画；身体侧仍是按朝向拟合的分区盒，不是逐三角形皮肤碰撞。猪使用按原版模型尺寸建立的四足分区，不缩放套用人形。猪躯干支持切面裁剪；人形仍沿预设部位分离，尚不支持任意躯干切面、肘膝截断或肢体薄片。客户端个性外观、模型资源包和调试器尺寸不改变服务端标准尺度。倒地、扭身时的分区、旋转碎块的包围盒碰撞仍属近似，不能宣称与原版《虐杀原形》的引擎物理完全一致。

## 验证与复现

执行 `gradlew.bat assemble --no-daemon`，产物为 `build/libs/Blacklight-Ascension-MC1.21.1-NeoForge-1.0.0-bundled.jar`。编译通过不代表游戏内切割位置、性能和多人已经验收；本轮未运行 GameTest 或自动化游戏测试。

人工验收应对比：同一招式命中不同高度／左右侧；仅一个爪刃擦到目标与多刃横扫；刀背碰撞；鞭索中段、尖端直刺和尖端横扫；隔墙、空挥、无敌目标；不同朝向和移动目标；尸体清理及相邻未受击实体模型是否恢复。胸部单点命中不能凭空让头和双臂一起掉落。关节分离与任意网格切片需要区分记录。

本次复现重点：成年猪遭利爪击杀后是否由整身关节物理接管，躯干实际被扫到时是否产生相应切面；锤拳／肌肉重击的完整身体落地与非致命恢复；地面、台阶、墙边碰撞；100 刻后清理。`assemble` 已通过，尚未据此宣称游戏内效果通过。
