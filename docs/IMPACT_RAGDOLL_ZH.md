# 武器接触与受击布娃娃（开发版）

Minecraft 1.21.1 / NeoForge 21.1.244 / Java 21。代码、资源和构建缓存均在 D 盘；Forge 1.20.1 尚未同步。

## 当前判定

断肢需要两项条件同时成立：服务端接受本次伤害且目标死亡；本次锐利表面扫掠确实接触可分离区域。不再根据武器名称固定砍头、砍双臂或拆成六块。非致命命中仍保留局部受击／击飞控制，不使存活目标凭空丢失肢体。

- 利爪：读取 `claw_blender.json` 中三根长刃和拇指短刃的锐利材质三角面，两只手分别随对应骨骼采样。保留独立刃片标识，各刃分别判断接触，结果按实际触及的身体区域去重。不是“每根刃必掉一块”。
- 刀刃：读取 `form_blade.json` 中连续刀身的锋利表面，随 Hand_R 攻击动画扫过目标。刀背、掌部、装饰突起不作为这次切割面的来源。
- 鞭拳：读取 `whip_tip.json` 的锐利钩刃，用服务端 WhipCurve 的末端和切线定位。墙面截断鞭索后，不在截断处伪造一个刀尖。鞭索中段命中不授权切断。直刺类动作标记为穿刺，不因命中就自动拆肢；横扫／回扫才允许切割。
- 锤拳、肌肉、冲击波、投掷：保留钝击布娃娃，不使用锐刃切断规则。未覆盖骨架的旧钝击处决效果保留。
- 普通剑斧：没有黑光共享骨骼与锐刃网格，使用服务端瞄准射线实际接触的身体区域，不再固定剑断臂／斧断头。

普通命中由既有动作窗口、扫掠范围、目标碰撞体、距离和墙体可见性共同判定；精确刀面查询不再额外否决已成立的普通命中。切割另用当前／上一刻位置采样锐利三角面与身体分区碰撞体，每游戏刻至少八段，较快表面按约 0.04 格补插值；单区间最多 32 段。普通命中早于刀面接触时，在同一个有效攻击区间继续追踪已命中的目标，首次真实刀面接触只补交伤口／切割，不重复扣血、服务端击退、停顿、攻击音效或掉落。目标已被本次命中击杀仍可完成这次切割；后来被其他伤害杀死、被抓取、移除、跨维度或不在实际刀面／可见范围内的目标不补切。身体冲撞和地面冲击波仍使用各自接触规则。

每个被命中的部位携带自己接触轨迹的冲量，未致死的接触也驱动对应关节；是否分离仍由服务端断肢掩码单独决定。每个被切下部位保留该部位的冲量，猪躯干额外携带各根爪刃接触面的局部位置和法向。每手三根长刃和一根拇指短刃均独立保留，双手最多八个切面；不同刃片不会因为切面接近而在发送前合并。新协议 `standalone-51-contact-wound-blood` 还同步伤口部位、局部位置、喷射方向与强度，联机两端必须更新。

## 伤口血效

对已经支持的成年猪和人形，锐刃按每根实际接触的刃片生成伤口；钝击按已接受伤害时的瞄准／接触位置定位，普通剑斧也接入。受伤点跟随当前模型姿态，倒地时跟随物理身体，断肢时跟随独立碎块；分离处两侧另有短暂出血。只接受服务端命中报告，不由客户端粒子制造伤害或切割。

命中先产生定向喷射，随后衰减为滴落。血滴有重力和方块碰撞，碰地／碰墙形成短暂血迹，约八秒内淡出。使用现有白色材质绘制程序化细条与不规则斑点，不修改世界方块。最多 96 个出血点、768 滴血和 256 处血迹，超出 64 格、卸载世界或超时会清理。喷射散布允许视觉变化，伤口位置和切断结果不随机。已覆盖对象关闭旧的身体中心红色粉尘，未覆盖对象保留原效果。

这是按伤口重新实现的血效，尚未与《虐杀原形》原游戏素材或逐帧录像对齐；编译和客户端启动已通过，游戏内观感未验收。

## 物理与渲染

人形整身使用 15 个关节点，包含肘／膝节点与分部位质量；从当前模型姿势和连续姿势采样的速度初始化，使用质量加权的距离与活动范围约束。有 forearm / shin 子骨骼的模型显示分段关节，原版整块手脚保持其模型结构。头、手臂、腿被授权分离时，复制当时的原模型与贴图，本体隐藏该部位；碎块独立旋转、扫掠方块碰撞、反弹、摩擦与休眠。原版护甲和手持物不会悬在已切掉的本体部位上。独立穿戴护甲暂不复制到碎块；士兵网格自带装备随子模型分离。

成年猪使用独立四足结构：水平躯干、头、四条腿，共六个刚体和五个关节。采样当前姿势的部位速度，重击接管整身运动，活体仍由服务端位置约束并在控制结束后用八刻过渡恢复动画；死亡后保留整个物理身体。未切中的关节继续连接，只有服务端确认的锐刃接触可以断开关节。猪躯干命中按接触切面裁剪实际模型表面，保留原贴图 UV 并封闭切口；各段躯干携带其对应的头腿关节，不把每次击杀固定拆成六块。利爪各刃分别产生候选切面，擦边与间距过小的面不制造薄片。碰撞、落地摩擦、旋转和休眠均在客户端计算。猪鞍的原版站立模型层在接管期间隐藏，暂未随尸体复制。

服务端继续负责活体位置、AI、伤害和掉落。客户端最多 32 个人形身体、96 块人形碎片，以及 24 个猪身体／144 个猪物理块；死亡／分离后通常最多保留 100 游戏刻。超出 64 格、离开世界或区块卸载时清理，不创建服务器尸体实体。

## 明确边界

原有专用骨架覆盖默认缩放的成年士兵、黑色守望、普通感染者、僵尸／骷髅／猪灵系 HumanoidModel 和成年猪 PigModel。其余非玩家 LivingEntity 由下述通用模型适配处理，包含幼体、缩放模型、其他四足、多足、水生和飞行模型。玩家不接管；尺寸超过 64 格、不可见目标及显式禁用标签不进入通用物理。特殊 Boss 的抓取许可仍由既有服务端规则裁定。

武器侧使用真实导出的锐利网格及共享原生动画；身体侧仍是按朝向拟合的分区盒，通用生物使用自身实体包围盒，不是服务端逐三角形皮肤碰撞。猪使用按原版模型尺寸建立的四足分区，不缩放套用人形。猪躯干和通用模型支持命中部件的切面裁剪；专用人形仍沿预设部位分离，尚不支持任意躯干切面、肘膝截断或肢体薄片。客户端个性外观和模型资源包不改变服务端判定尺度。倒地、扭身时的分区、旋转碎块的包围盒碰撞仍属近似，不能宣称与原版《虐杀原形》的引擎物理完全一致。

## 一代流程核查后的接管与吸收

2026-11-10 对本机私有参考资料中的 P1 startup_fig / alex_fig 做了结构和字段长度校验，并把 receiver 动画哈希与已有动作配置交叉匹配。实现没有复制原引擎求解器；下面的时间来自实际轨道，质量、约束增益、加速度、收缩及色彩算法是 Minecraft 适配值。

- 非致命命中也把接触轨迹的冲量送到相应关节。轻击保留姿态驱动，重击／死亡放开姿态驱动；重复命中叠加冲量，保留已有运动。
- 抓取沿用同一身体，不再一抓住就删除物理状态。当前接触部位负责抓取约束，其余肢体由姿态弹簧和惯性共同控制；释放或吸收不重新生成站立骨架。
- 人形和成年猪使用相同的动作、物理接管及胸部目的点时钟。原版胸口吸收 1.833333 秒、捏头 2.5 秒、锤拳摔头 1.933333 秒、鞭拳抽打 1.4 秒来自 ConsumeByParent；对应 FIG 偏移分别为 96484、7224、19280、37456。分离动作沿用 spawnGib 时点，断块轨道从自身零时刻开始。
- 头／躯干／四肢渐次被加速度受限的牵引拉向胸部。收缩时缩短连接长度或刚体关节偏移，保留方块碰撞；消融材质从指定身体区域扩散，和物理吸收分开计时。猪的斩断动作产生保留皮肤 UV 的两个闭合躯干块，肢体继续连接在所属躯干上；撕臂动作只释放对应前肢。
- 原有服务端扣血、抓取所有权、完成奖励及实体移除仍为唯一权威。伤口随同一物理／双人动作坐标系移动。数据包布局不变，CutImpulse 现在也表示未分离部位的接触冲量。

以上是专用骨架的改造；通用模型范围见下一节。没有把专用人形皮肤改成任意平面切割，也没有宣称“四爪必切四份”；既有逐刃几何接触是本项目设计，一代已核查的普通利爪 Hit 轨道是腕骨扫掠体。

验证：assemble 编译打包和构建内资源校验；未启动真人试玩，未执行游戏测试。重点试玩抓取中转身／行走、受击后立即抓取、各吸收变体的接管瞬间、非致命恢复、投掷后落地及墙边牵引。Forge 1.20.1 尚未同步。

## 原版与通用模组模型适配（NeoForge 1.21.1）

这里的武器指黑光的利爪、刀锋、鞭拳、重锤与肌肉形态。没有新增其他模组物品的名称猜测或武器分类系统。盾牌、护甲仍按原有防御逻辑工作，其产生的已接受冲击走已有战斗入口。

- 服务端取消少数物种白名单，保持接受伤害／控制后才发送物理事件。利爪、刀锋和鞭尖仍读取可见锐利网格与共享动画；四爪各自生成接触，不随机抽取身体部位。刺入不授权切片；重锤、肌肉与落地冲击只施加冲量。大体型和抗击退目标沿用原来的质量、免控与倒地判定。
- `AdaptiveRagdoll` 在实体渲染入口读取当前帧的真实四边形、UV、颜色、RenderType 和骨骼变换。原版／常见 Java 模型从 ModelPart 获取层级与枢轴；GeoEntityRenderer 通过 GeckoLib 4.9.2 骨骼入口获取同样的信息，保留原动画控制器。没有可读骨骼的标准顶点输出降级为完整网格单刚体，不能把这种降级说成完整关节布娃娃。
- 使用实际可见部件建立刚体和父子约束，继承姿态的线速度、角速度；轻击保留动画驱动，重击／死亡释放，活体恢复时回到当前动画位置。多足、翅膀、尾巴、幼体与缩放直接使用已经变换过的网格，不套人形六块模板。
- 致命锐刃接触按服务端传来的逐刃切面，裁剪接触附近、对应部位的实际相交部件与外层；保留表面 UV，对闭合切口逐环封口。切断后的关节跟随所属碎块。擦边、过薄、开放表面或预算不足不凭空补出大块几何；一次四爪横扫可能产生零个、一个或多个有效切面，不保证四份。锐刃切中的专用成年猪和人形也转入网格切割；钝击沿用专用骨架。
- 通用模型的抓取、吸收沿用同一刚体，按原有接收者时间表约束抓点、松开姿态驱动并向胸部回流。部位收缩、血肉颜色与牵引丝随物理身体移动，避免再次叠加旧 ConsumeFracture 的位移。伤口绑定捕获时的模型坐标，随断块旋转、移动。
- 通用部分最多 16 个身体、单体 48 刚体、全局 256 刚体、单体 24576 顶点；小装饰部件合到祖先。超顶点预算会完整回放原始渲染并暂缓捕获，避免模型消失。死亡后约 100 刻清理，离开 64 格、切换世界或资源重载也清理。大于 4 格的物理部件用角点碰撞近似，不能视为连续精确网格碰撞。

特殊兼容边界：直接绕过 MultiBufferSource 的 GPU／shader 渲染、重写 Gecko 的递归骨骼绘制且不调用父方法、运行中更换拓扑的模型，仍可能需要专用适配；未逐个安装所有模组验收。自定义渲染器可在绘制骨骼前后调用 `AdaptiveRagdoll.bone / clearPart`。数据包可在 `data/blacklight/tags/entity_type/ragdoll_disabled.json` 添加特定实体 ID，关闭其物理接管而不改变原有伤害规则。

验证范围：assemble 编译、资源数量与打包体积检查；未执行 GameTest，也未宣称跨模组真人试玩或多人同步已验收。建议先试玩牛／羊／鸡／蜘蛛／村民／史莱姆／鱼／飞行生物，再测幼体、缩放个体与 Gecko 模型，覆盖轻击恢复、重击倒地、各刃命中、切口、抓取吸收和同屏未受击目标。Forge 1.20.1 尚未同步。

## 验证与复现

### 2026-11-10：利爪扫腿吸收与锤拳地面接触

- 利爪默认扫腿／斩断变体新增独立接触修正：入场时只拟合右掌的抓持点，约 0.2–0.38 秒退出抓持修正；斩击前后短窗口把右爪可见刃段拟合到实际布娃娃躯干。受害者接触点读取同一帧的人形、猪或通用刚体插值位置；尚未捕获物理身体时用接收者轨道回退。左爪、扫腿、根位移和恢复段沿用原动作，捏头变体不改。
- 撤回将锤拳接触窗口硬改为 4–15 刻的尝试，原动作资料恢复。普通右键震地（含蓄满版）改由共享骨架时钟采样实际拳头网格顶点，扫到方块碰撞面的顶部后，在同一服务端 tick 触发震地伤害、地表材质碎块、声音和反馈；不在蓄力阶段触发，也不在旧窗口重复补打。
- 验证为资源轨道／网格坐标核对、编译打包和构建内资源校验。未运行游戏测试；需真人复测普通／满蓄力、空地／有目标、两种利爪吸收及非人形目标的接触表现。

执行 `gradlew.bat assemble --no-daemon`，产物为 `build/libs/Blacklight-Ascension-MC1.21.1-NeoForge-1.0.0-bundled.jar`。编译通过不代表游戏内切割位置、性能和多人已经验收；本轮未运行 GameTest 或自动化游戏测试。

人工验收应对比：同一招式命中不同高度／左右侧；仅一个爪刃擦到目标与多刃横扫；刀背碰撞；鞭索中段、尖端直刺和尖端横扫；隔墙、空挥、无敌目标；不同朝向和移动目标；尸体清理及相邻未受击实体模型是否恢复。胸部单点命中不能凭空让头和双臂一起掉落。关节分离与任意网格切片需要区分记录。

本次复现重点：成年猪遭利爪击杀后是否由整身关节物理接管，躯干实际被扫到时是否产生相应切面；锤拳／肌肉重击的完整身体落地与非致命恢复；地面、台阶、墙边碰撞；100 刻后清理。`assemble` 已通过，尚未据此宣称游戏内效果通过。

### 2026-11-10：攻击反馈回归修正

- 精确切割的伤害否决仅限已标定的成年猪和人形；通用模型维持既有命中规则，真正的锐刃接触仍单独决定切面，不能用通用包围盒伪造断肢。
- 三种布娃娃求解器的受击有效期从打击停顿结束后计算，防止短受击在停顿期间消耗掉。
- DEBUG 日志记录实际伤害前后生命值、布娃娃接收与建体/回退原因，以及锤拳触地的方块和时刻。编译和这些记录不能代替真人手感验收。

### 2026-11-10：普通受击被吸收窗口与短布娃娃覆盖

- 试玩日志显示普通利爪确实扣血，但目标进入低血量吸收窗口时没有触发 HitStop。`LivingDamageEvent.Post` 在 `hurt()` 内先创建吸收硬直，旧 `ImpactControl.begin` 随即拒绝这次攻击的击退、受击动作与停顿。现在单独保存吸收窗口的结束时刻，命中正常播放对应受击，结束后恢复剩余吸收窗口；连击不会续长该窗口，抓取中的保护仍生效。
- 群体命中的每个受控目标都获得命中停顿；攻击者的声音／镜头反馈仍每次动作只触发一次。
- 8 刻的普通伤口数据保留伤口血效和站立受击，不再新建自由物理身体覆盖原动作。击倒、致死、真实切面和抓取吸收仍接管整身；对已倒地身体的轻击继续添加冲量，不缩短倒地有效期或重置为站立控制。
