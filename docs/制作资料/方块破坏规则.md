# 枪械方块破坏规则

**与对生物伤害分开。** WeaponCatalog的damage/radius描述原武器平衡；以下是新方块材质耐久与命中冲击点，不是真实枪械穿深/材质强度，也不能把对生物爆破半径照搬为方块破坏半径。

提取状态：已提取四个策略/适配文件；运行通过状态仍由项目验证记录确认。资料生成不等于测试或实机通过。

### 材质耐久公式

| 材质 | 耐久冲击点表达式 |
| --- | --- |
| FRAGILE | 1 |
| WOOD | Math.max(8,hardness*8) |
| EARTH | Math.max(6,hardness*12) |
| MASONRY | Math.max(30,hardness*24) |
| METAL | Math.max(120,hardness*32) |
| default | Float.POSITIVE_INFINITY |

### 子弹冲击公式

| 材质 | 每次命中表达式 |
| --- | --- |
| PROTECTED,METAL | 0 |
| MASONRY | weaponDamage*(machineGun?.8F:.2F) |
| default | weaponDamage |

`hardness`是运行方块破坏硬度，`weaponDamage`是传入玩法值，`machineGun`是机枪类别判断。PROTECTED、不合法硬度/参数与负硬度不可破坏，METAL不接受普通子弹冲击。适配器给子弹传入的是 `definition.damage()`：默认NPC对生物缩放后的profile.damage并未被当成方块冲击点，这两列必须分开。具体分类优先级、玩家/生物破坏权限与gamerule检查由适配器决定，不能仅凭策略表推定所有块都能打碎。

| 武器 | 类型 | 原实体效果半径 | 方块破坏半径 |
| --- | --- | --- | --- |

| military_carbine | BULLET | 0.0 | 0.0 |
| military_machine_gun | BULLET | 0.0 | 0.0 |

| rocket_launcher | ROCKET | 4.0 | 3.0 |
| missile_launcher | MISSILE | 4.0 | 3.5 |
| thermobaric_launcher | THERMOBARIC | 5.0 | 4.0 |
| infection_launcher | INFECTION | 3.0 | 0.0 |

### 爆破冲击原文

```java
if(material==null||material==Material.PROTECTED||blastRadius(kind)==0||!Float.isFinite(weaponDamage)||weaponDamage<=0
                ||!Double.isFinite(distance)||!Double.isFinite(radius)||distance<0||radius<=0||distance>=radius)return 0;
        float type=kind==WeaponDefinition.Kind.GRENADE?.75F:kind==WeaponDefinition.Kind.THERMOBARIC?.65F:1;
        return weaponDamage*2.5F*type*(float)(1-distance/radius)*(material==Material.METAL?.6F:1);
```

### 实际材质分类原文

```java
if(state.isAir()||state.getBlock() instanceof net.minecraft.world.level.block.LiquidBlock||state.is(PROTECTED)||state.getDestroySpeed(level,at)<0
                ||FirearmsWorldConfig.PROTECT_BLOCK_ENTITIES.get()&&state.hasBlockEntity())return BlockDamagePolicy.Material.PROTECTED;
        if(state.is(FRAGILE))return BlockDamagePolicy.Material.FRAGILE;
        if(state.is(WOOD))return BlockDamagePolicy.Material.WOOD;
        if(state.is(METAL))return BlockDamagePolicy.Material.METAL;
        if(state.is(EARTH)||state.getDestroySpeed(level,at)<1)return BlockDamagePolicy.Material.EARTH;
        return BlockDamagePolicy.Material.MASONRY;
```

### 实际破坏权限原文

```java
if(owner instanceof ServerPlayer player){
            if(player.isSpectator()||!player.mayBuild()||!level.mayInteract(player,at))return false;
            return !NeoForge.EVENT_BUS.post(new BlockEvent.BreakEvent(level,at,state,player)).isCanceled();
        }
        return CommonHooks.canEntityDestroy(level,at,owner);
```

实际爆破半径取 `min(WeaponDefinition.radius, BlockDamagePolicy.blastRadius)`；先在已加载、世界边界和高度合法范围内枚举，再按距离和位置排序。超过中心1.5格的候选需碰撞射线无遮挡；逐个受配置上限限制，不承诺穿墙炸穿整座建筑。完整工作循环原文在block-damage.json的blast_raw。

当前适配器ledger构造参数原文：`512,200`。

BlockDamageLedger是有界、临时缓存：相同位置且state一致才累计，state更换从新命中计算；过期/倒退时间清除，容量满淘汰最近最久未用条目，达到耐久阈值才返回broken，未碎裂纹stage范围0..9。不是永久存档中的建筑血量系统。具体缓存容量/寿命以适配器构造值或配置为准。

实际单块/多块放置事件清除旧位置裂痕，覆盖玩家拆换相同状态木板的修理场景；不监听每次射击权限探测都会发出的BreakEvent。任意命令、活塞、其他模组不发放置事件的替换没有统一世代标记，不能宣称全面识别。

```java
if(event.isCanceled()||!(event.getLevel() instanceof ServerLevel level))return;
        var ledger=LEDGERS.get(level);if(ledger==null)return;
        if(event instanceof BlockEvent.EntityMultiPlaceEvent multi){
            for(var snapshot:multi.getReplacedBlockSnapshots())ledger.forget(snapshot.getPos().asLong());
        }else ledger.forget(event.getPos().asLong());
        flush(level,ledger);
```

爆破适配器显式接收命中世界，只允许存活、未移除、仍在同一世界的射手；旧世界弹体不会根据已换维度的射手到新世界同坐标破坏。移除/死亡/跨维度射手只保留弹体消失视觉，不产生建筑和实体伤害。
