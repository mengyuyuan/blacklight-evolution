# NeoForge / Forge 对照

| 项目 | NeoForge主工程 | Forge对应工程 |
| --- | --- | --- |
| 游戏/Java | Minecraft 1.21.1 / Java21 | Minecraft 1.20.1 / Java17 |
| 现有模组维度 | blacklight:world 大世界及 blacklight:city 城市 | blacklight:city 城市；本工程没有Neo大世界world |
| 维度内军事设施 | 两维度启用city_military_bases；大型基地及安全位置的附属检查站/补给模块 | 城市维度启用city_military_bases；复用同类基地/检查站模块 |
| 资源目录 | data/blacklight/structure、recipe、loot_table | data/blacklight/structures、recipes、loot_tables |
| 配方结果字段 | result.id | result.item |
| 保存/注册/事件API | NeoForge1.21.1 API、HolderLookup/组件 | Forge1.20.1 API及NBT物品保存 |
| 玩家枪械数值完全相同 | True | True |

| NBT | 字节hash完全一致 | Neo/Forge DataVersion | 尺寸一致 | 嵌入人员一致 | 真实箱数量一致 | 运行槽定义一致 |
| --- | --- | --- | --- | --- | --- | --- |
| blackwatch_checkpoint | False | [3955,3465] | True | True | True | True |
| blackwatch_outpost | False | [3955,3465] | True | True | True | True |
| frozen_research_station | False | [3955,3465] | True | True | True | True |
| large_blackwatch_base | False | [3955,3465] | True | True | True | True |
| large_military_base | False | [3955,3465] | True | True | True | True |
| military_camp | False | [3955,3465] | True | True | True | True |
| military_checkpoint | False | [3955,3465] | True | True | True | True |

NBT字节不同不直接证明布局不同：DataVersion、物品count/Count、实体保存API可能有差异；请用各端原始快照核对。[Forge解析数据](data/forge_structures.json)与data/nbt/forge保存独立结果。两端完整NBT、配方、loot、军事与客户端源码均各自保存，不用Neo原文替代Forge。来源manifest记录每端路径/字节/hash，baseline各记分支/HEAD/dirty。

独立小哨站继续使用原版群系jigsaw；维度内自然设施是大型基地及附属模块，不能把每一个小模板都说成独立维度随机结构。自然生成只影响新生成区块，不自动覆盖旧区块或玩家建筑。

本档案不会自动构建或宣布任一端实机通过。城市驻军预算与第一人称反馈正在本轮修改时，最终以刷新后的来源快照和主任务验证记录为准。
