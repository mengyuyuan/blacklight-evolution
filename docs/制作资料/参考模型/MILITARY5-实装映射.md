## 骨架和动作适配

Blockbench 坐标按 `(x, 24-y, z)` 转成原生人物坐标，旋转按 `(-x, y, -z)`、ZYX 顺序转换。原作者负 X 的 `Left Arm` 对应原生右臂，不能只凭骨骼英文名对调。每侧上臂/前臂长度均为 6，肩在躯干局部 `(-6,0,0)`、`(6,0,0)`。

实际使用参考旋转求得的主握点为 `(-1.2473704, 6.2673432, -1.7659294)`，支撑握点为 `(3.1749512, 5.6010061, -9.8513058)`，单位为模型像素。枪体和两个握点属于同一携枪组；左右惯用手镜像这个组。

大角度瞄准由上身带转，携枪组保留最多 0.10 弧度的相对瞄准角。两肩固定在躯干套筒，分别用两段 IK 接到动态握点；携枪组只作必要的小平移，使两握点落进半径 11.97 的手臂可达区域。这个约束修复了初稿“大角度转头导致肩根绕枪漂走”的问题。**约束属于适配层，原始 2174 个关键帧没有被改写。**

动作按各士兵自己的观察状态播放。只有真实同步的弹匣减少 1 且服务器冷却时间推进到有效射击窗口，才触发一次原始射击曲线。初次出现、换武器、脱装、抓取控制与时钟倒退会建立或重置基线；换弹由实际装填后的弹匣与服务器期限识别，不再把战术 `phase==3` 当作换弹。模型新增节点每次渲染前还原，状态使用弱引用按实体区分。

仅靠弹匣和冷却时间，无法完全区分“手动换入一把同款枪，数据恰好像刚少 1 发”和真正射击。本版不增加服务器枪械 UUID/射击序号；这个极少数视觉歧义如实保留，不影响服务端伤害和弹药结算。

## 第一人称手臂

`FirearmHandPose` 使用实际物品 JSON 的握把/护木位置、元素旋转、显示缩放和物品变换求握点。步枪护木、榴弹器前握把和火箭筒前握把分别处理，不共用一个猜测坐标。

实时渲染读取当前玩家的真正 `PlayerModel` 手臂和袖层，并通过 `ModelPart` FK 求腕点。普通模型和纤细模型的关节高度不同；这里不再硬编码错误的 14 单位腕高，也不调用会二次叠加 idle 摆臂的原版空手函数。臂和袖子的姿态、缩放、可见性在绘制后恢复；隐身玩家只显示物品，不显示皮肤手臂。枪和两只手共用同一射击/换弹变换。

支持范围：主手枪且副手为空时双手握枪；主手枪配副手物品、双枪时一件物品对应一只手；枪仅放副手时保留单手枪与原版空主手，不额外画支撑手。左右惯用手按实际身体左右臂处理。

## 真实资产预览和复现

当前规范入口见 [生产预览-military5](生产预览-military5/)，原始 [revision4](生产预览-military5-revision4/) 保留不改。两端分别从自己的revision4校验并复制为规范入口，不跨端冒充。每个阵营有 12 个姿态，另有 8 张第一人称场景。档案专用图另外捕获两阵营各普通兵、重装兵、队长、军官、指挥官的穿戴和脱装，共 20 个场景、10 张双列卡；它们使用真实普通/重装几何层和注册构造的默认军衔，不复用旧直臂兵种图。图中标明 CPU 预览，不能当成 Minecraft/OpenGL 实机验收。

预览工具 `tools/ReferenceMeshCapture.java` 直接烘焙生产 `BlackwatchModel`，应用生产 pose，然后捕获真实 `ModelPart.render` 的顶点、法线与 UV。第一人称读取真实物品 JSON，使用 Minecraft 的 `ItemTransform`、真实 `PlayerModel` 臂/袖顶点和同一生产手臂变换；默认 Steve 皮肤仅用于预览。`tools/preview_blackwatch_reference.py` 将这些数据绘成图片。它不再解析旧固定直臂图片或另造一套人物几何。

每个预览目录的 `manifest.json` 记录源码、生产 profile、PNG、8 种枪械 JSON、编译后的模型 class、实际顶点捕获和输出图片的 SHA-256。修改生产模型后应重新生成，不能沿用旧图。

在已有完整本地开发构建的仓库中运行：

```text
python tools/export_blackwatch_reference.py --repo .
python tools/preview_blackwatch_reference.py --repo . --output docs/制作资料/参考模型/生产预览-military5-revision4
```

导出器保留 `art/military2/build_soldiers.py` 和其原始图集作为旧护具/人物基础，不修改原 BB、署名证据和内嵌贴图。旧脚本生成的是适配前的 Java 模型，不能把它的输出直接覆盖当前 `src/main/java/.../BlackwatchModel.java`；military.5 的双肘、携枪和可达约束由当前生产 Java 维护，衣料/轻量枪械/profile 用新导出器刷新。预览工具使用本地已缓存 Java/Minecraft API，不自行下载或启动 Gradle。

## 验证边界

定向检查覆盖原始输入 hash、12 骨骼父子关系、2174 原始关键帧完整性、实际衣料像素和原人脸像素、真实烘焙前臂、大小瞄准角下两肩和双握点、换弹连续性、共享模型复位、左右惯用手、副手占用/双枪、普通/纤细玩家的真实腕点、真实弹匣触发和单次射击恢复。

开发中实际捕获并修复了两处问题：肩随携枪点漂移、水平前臂沿枪身遮挡视线。对应 RED/GREEN 日志保存在本轮 `build/military5-reference-draft/`，初稿图保留在 `build/reference-preview*` 的旧修订目录。最终完整 JUnit、服务器验证和交付包校验以本轮统一验收记录为准；本页不把 CPU 图、API 编译或服务器测试写成已进行客户端光影实测。
