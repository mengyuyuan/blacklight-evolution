# Blacklight: Ascension 0.3.0

2026-10-13 · Minecraft 1.21.1 · NeoForge 21.1.244 · Java 21

这是 NeoForge 1.21.1 的正式版本号与本地发行包记录；不代表已经上传 GitHub、网易或其它平台。Forge 1.20.1 由另一条工作线维护，本包不包含 Forge JAR。

## 安装

将完整安装包 `mods/` 内两个 JAR 放入 Minecraft 1.21.1 / NeoForge 21.1.244 实例的 `mods` 目录，替换旧 Blacklight JAR；客户端与服务端使用同一版本。唯一额外必需 Mod 为 GeckoLib 4.9.2，不需要 Epic Fight、Epic ParCool 或 Weapons of Miracles。升级前备份世界与配置。

默认 `bundled` 构建包含完整 251 份动作和配套数据，包括毁灭技、子弹俯冲、瞄准和收回动作。无需外部动作目录；旧 `blacklight.localWeaponMotions` 参数会覆盖包内资料，普通安装应移除。按 U 打开能力与教程，查看技能当前按键和演示；修改按键后教程同步更新。

## 这次收口内容

- 纳入现有独立战斗、移动、锁定、新武器模型、液态变形、临界质量、毁灭技、持续加速的子弹俯冲及技能教学。
- 默认仓库补齐 27 份大招/俯冲资料，避免本机外部资料构建与干净仓库构建不一致。
- 极大攻击范围只遍历已加载实体，远距离射线不强制生成区块；保留高度和威力算法，不添加人为高度上限。
- 修正奖励整数溢出、地形范围加法溢出、非法动作 ID、飞行状态输入边沿，以及教程解码和墙面动作缓存的清理问题。
- 校准旧 GameTest：五倍生命单位、原生抓取时长、阶段结算与回收、当前感染宿主、装甲、目标认领及空中特技规则。保留奖励去重、命中次数、死亡释放和同步相关检查。
- 蜂巢和远距离追击夹具等待实际阶段/实体区块就绪；地面连击夹具提供真实支撑地板，避免将无支撑的假玩家误测为空中招式。
- 新刀臂模型与旧抓取/投掷回退动作发生头部重叠，调整两个动作的右手旋转；模型尺寸、根位移、时长和释放时间保持不变。200 Hz 连续资源姿态采样的最小头部间距分别约 0.139 和 0.067 模型单位，高于原测试要求的 0.06。
