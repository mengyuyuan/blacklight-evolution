# 毁灭技高额真伤

NeoForge 1.21.1：地刺墓地主判定2000、触须弹幕1600、临界痛苦4000点实际生命伤害。地面与空中版本使用同一预算；近身独立冲击保持较小的补充伤害，判定逐目标去重，不按动画帧重复结算。

这是一组明确的Minecraft平衡值，不更改解包动作元数据，也不声称原游戏伤害就是该数值。正常生物和使用五倍黑光血量单位的生物，按目标单位反算输入伤害，保证基础HP预算一致。既有自身器官增伤、跨模组配置倍率仍可影响最终伤害。

独立伤害类型`blacklight:devastator`带施法玩家归属，绕过护甲、抗性、保护附魔、盾牌、原版效果减伤与同次技能碰撞之间的受伤冷却。猎手25%普通玩家攻击减伤、母巢常规武器抗性及黑光成熟组织/甲壳减伤不会吞掉此伤害。每条既有接触轨道仍只命中一次，其他普通攻击不会变成真伤。

仍使用正常hurt、死亡、掉落和击杀归属流程，不直接设置目标生命或删除实体，不给予全局无敌绕过。其他模组自己取消伤害事件或覆盖实体受伤方法的情况，仍需按其实现联测。

子弹俯冲保留既有高度能量公式、真伤与方块破坏设置，不改它的加速度、场景特效或高度算法。本轮不做世界阶段、全局限伤或Forge移植。
