# 感染体消化与储备器官

2026-10-27，NeoForge 1.21.1。适用于感染宿主；不是六项主角购买技能。

本批增加六个可继承的稳定 ID，不重排旧枚举、不重抽旧宿主器官。

| 器官 | 实际作用 | 输入、限制和表现 |
| --- | --- | --- |
| 研磨胃 `gizzard` | 处理 `blacklight:tissue_grindable` 中的真实纤维食物 | 小麦、干草等物品每份基础 6 养分；480 工作量，成熟度改善研磨速度；腹侧肌胃收缩 |
| 发酵前胃 `fermentation_chamber` | 处理 `blacklight:tissue_fermentable` 植物 | 树叶、幼苗等真实物品每份基础 8 养分；1600 工作量，明显慢于肉食；后腹腔缓慢收缩 |
| 吸收肠襞 `absorptive_gut` | 改善实际完成消化的食物转化 | 加成为 `0.5 × 强度 / (2 + 强度)`；小数结余保存；不因读档或空腹时间产生收益 |
| 消化胰腺 `digestive_pancreas` | 为肉食和软食分配有限酶 | 一单位真实养分合成一批酶，每份食物使用一次；肉食和软食有不同提速，剩余酶与已处理进度入存档 |
| 嗉囊 `crop` | 存储更多实际食物份数 | 基础 2 份，按强度扩展，最多 12 份；满了拒收而不扣物品；颈根储食袋随负载收缩 |
| 脂肪体 `fat_body` | 储存正常 2400 养分容量以外的真实余量 | 按强度最多 600 额外容量；低储备时逐步释放，储备减少时外形回缩；时间本身不能生成脂肪 |

标准食物按实际 `FOOD` 组件识别，基础收益为营养值的两倍，单份有界至 64。
通过标签区分肉食、研磨和发酵底物，不要求逐一登记其他模组的生物或食物 ID。
标签可由数据包扩充；石头等无对应可食用信息的物品不作为食物。

玩家近距离右键可投入一份；检查实际距离、墙面遮挡及宿主忙碌状态。生存模式真正消耗一件物品，
正确返还碗等食用容器；满库存只掉落尚未放入库存的剩余容器。创造模式沿用不扣物品的规则。
感染体饥饿且未近距交战时会吃附近已加载的合适掉落物；每维度每 tick 最多八次拾食查询，
单体查询有错峰与间隔。不会寻找全世界食物、拆任意方块或加载新区块。

击杀真实猎物的既有食物收益，在拥有本批消化器官时先进入消化队列；同一次死亡仍只结算一次，
队列满时不额外直接兑现。已有真实掉落物仍可由后续拾食处理。
普通食物、杀敌获得的食物与脂肪都不会生成成熟器官吞噬次数、供体履历或进化者门槛。

消化每秒推进，长期储备、部分进度、酶、脂肪和吸收小数均保存。未知未来食物条目有界保留，
当前不能处理就休眠，不被转换成免费养分。储备无空间时暂停对应食物，而不是删除其价值。
没有对应器官时，旧脂肪保留但不自行释放。

躯干内脏只使用一个实际躯干插槽；颈根嗉囊使用头部插槽，缺失分类时使用稳定的虚拟插槽。
器官根部固定在宿主动画骨架上，其余结构按真实消化状态与负载变化；不向每条腿重复添加整套内脏。
蜘蛛替换人形上半身后的嗉囊仍使用实际供体头颈连接。
常驻 HUD 不增加新段落，按住 Alt 的目标详情在有存货时显示食物份数和脂肪余量。

机械验证：711 项单元测试、11 项实际独立服务端 GameTest 通过。
涵盖真实物品标签与组件、容器返还、满队列拒收、耗时消化、吸收效率、酶支付、脂肪存取、
实体保存重读、附近掉落物拾食、真实击杀一次性入队、九个宿主共用查询额度、攻击占用拒收。
客户端外形验收另附截图与报告。已有专属外形与通用外形共享消化表面位移，覆盖层与皮肤使用同一结果，
不因内脏藏在专属感染模型内就失去外在反馈。
