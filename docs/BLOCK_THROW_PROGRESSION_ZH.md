# 肌肉投掷：选择、动作与物理

仅肌肉强化、虐杀模式且已购买肌肉投掷 I 可用。技能页动态显示玩家当前键位。

- 面前有可抓取生物时，抓取键仍优先执行原生物抓取。
- 没有可抓取生物时，按住抓取键（默认 E）选择地形：从瞄准方块开始随机向六方向相连的方块扩展，已选方块保持不变，松开后举起。轻点选择一块。
- 选择有红色边框；选择时不删除方块，成功举起时才从世界移走所选方块。
- 举起后按住攻击键蓄力，松开投出；使用键放下，再按抓取键可快速投出。潜行键临时关闭辅助瞄准。
- 按实际尺寸判断手数：单块用单手，大型组合地形用双手。ThrowObjectSize 为以后大型物品适配共用，未声称已支持所有大型物品。
- 保留真实阻力和重力，不绘制弹道线或落点。辅助瞄准只确定发射速度，飞行中不追踪；红框只提示目标。

满蓄力 30 ticks。组合地形速度乘 n^-0.10，伤害乘 1+0.15√(n−1)，沿用模组生命单位与护甲减伤。碰撞扫描整个组合包围体，不能穿过小于自身的缝隙。命中或放下后回收各组成方块的物品，不会在原位置复制方块；doTileDrops 为 false 时不掉落。

服务器决定选择种子、时间、数量、每格破坏许可、最终移除、伤害、瞄准与发射。任何格受到保护都取消整次拔取。菜单/失焦取消选择；12 ticks 未收到选择保持包则过期，不删除地形。保存组合材质、相对排列和已回收进度，防止重载重复掉落。NeoForge 协议 standalone-10；Forge forge-1.20.1-6；旧客户端不能混连。

## 动作参考与适配范围

双手参考 alex_weap_2hnd_sml_pickup / sml_amb / alex_weap_2hnd_throw；源状态机将 throw 的 0–15 帧作蓄力段，15 帧后作释放段，执行标记在释放后约 0.0333 秒，20 TPS 映射为 1 tick。

单手参考原版单手投掷武器分支 alex_weap_missile_idle / throw，配单手抓取；不是声称原版存在 Minecraft 方块动作。throw 39 帧起作释放，执行标记约 0.1 秒，对应 2 ticks。动作重定向到本模组骨骼，另做方块握点、双手接触、尺寸偏移及末段回到步态。游戏蓄力 1.5 秒为本模组玩法调整，不冒充原版时间。

八段动作附来源片段与哈希；不打包原始解包文件或私人测试工具。
