# 武器膨胀、方块投掷与黑色守望开发版

## 武器攻击放大

参考动作缩放通道按现有招式时间轴适配，共49段曲线。刀锋伸长、利爪掌部膨胀、锤拳分段放大；身体动作与已确认的模型保留。网格、发光、拖尾使用同一个动作时钟，收招后还原。详见 WEAPON_ATTACK_GROWTH_ZH.md。

## 方块投掷

感染并开启虐杀原形模式后：
- E：优先抓取有效生物；无有效生物且没有锁定目标时，抓起准星前3.5格内的可投掷方块。
- 左键或再按E：经过抛掷动作释放，普通形态基础伤害8、肌肉形态12；游戏的统一生命单位换算仍生效。
- 右键：放下为可拾取的方块物品，不自动放置地形。

支持泥土、草方块、常见石材、原木和木板，由 `blacklight:throwable_blocks` 标签控制。无建造权限、受保护区域、带方块实体／流体、非完整碰撞体或不可破坏方块均不抓取。先检查破坏事件，实体生成失败不移除原方块；命中不继续破坏周围地形。退出、死亡、跨维度和保存后重新加载会回收持有物。回收遵守方块掉落规则，物品生成被取消时保留实体重试。

## 黑色守望

- 步兵：基础生命24、护甲4，三连发、换弹、接近与后撤。
- 重装兵：基础生命60、护甲10、更高抗击退和单发伤害，换弹更慢；吸收前需要削弱。
- 生命显示仍按现有5倍单位换算，即通常显示120和300生命。枪击基础伤害分别1.6和2.2，不再重复放大。
- 视线与弹道检查阻挡；友军挡住弹道时不穿透友军。被抓取或吸收时停止射击。
- 吸收士兵可取得身份；未暴露的黑色守望、平民与动物伪装沿用已有识破／目击规则。
- 自制Minecraft方块式头盔、防毒面具、护甲、步枪和贴图；重装兵增加肩甲及护膝。枪声目前组合使用Minecraft现有声音。

据点在新生成的平原、向日葵平原、热带草原、沙漠、雪原出现，驻守4名步兵和1名重装兵，不自动刷新驻军。击杀与物资箱提供军用电路。

定位：`/locate structure blacklight:blackwatch_outpost`

仅在明确选择的测试地点生成：`/place structure blacklight:blackwatch_outpost`（会改变附近地形）。

刷怪：`/summon blacklight:blackwatch_soldier`、`/summon blacklight:blackwatch_heavy`，创造栏也有刷怪蛋。

两个军用电路、一个铁锭、玻璃、红石可合成野战感染探测器：上中铁锭；中排电路、玻璃、电路；下中红石。右键报告48格范围内最近感染生命的距离和方位，冷却5秒。这一轮技术物品先接探测器，完整实验室与超级士兵不在本轮完成范围内。

## Forge dev.7：玩家移除后的崩溃修复

本机 dev.6 试玩日志显示，执行清除实体（包含玩家）后，Forge 已移除玩家并使 capability 失效，PlayerTickEvent 仍进入利爪更新，触发 Missing Blacklight entity capability；退出清理也访问同一个失效对象。dev.7 在玩家更新入口检查数据是否可用，并先释放抓取／攻击会话，再跳过旧玩家数据读写；动画、锁定、肾上腺素及方块持有状态的退出清理同样检查生命周期。不复活已移除玩家的 capability，不用临时默认存储掩盖持久数据问题。此问题来自 Forge capability 生命周期，NeoForge 没有相同的存储实现。

## Forge dev.8：客户端移除过渡

补齐客户端 WeaponMorphTracker 在玩家移除后继续采样的问题；死亡或世界更换清除变形缓存，锁定与模式查询不再把旧玩家当作活动对象。只对已移除客户端实体提供只读空快照，服务端及存活客户端仍严格使用真实 capability；延迟同步不写回已移除实体。assemble通过，副本成功进世界。电脑操作工具拒绝操作 Java 窗口，因此尚未完成自动 kill／重生复现，不能据此宣称该场景验收通过。
