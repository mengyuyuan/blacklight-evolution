# 感染市民、飞行宿主与同类吞噬修复

## 普通感染者

`blacklight:common_infected` 的注册 ID 不变，旧存档无需删怪。实现改为独立的 Monster，移除原版僵尸的举臂、变溺尸、村民转僵尸等行为。
使用自制方块人模型和四套原创像素贴图：深色外套、工装、衬衫、医护服。衣着由身份稳定选择，存档和转化为成长宿主时保留，不按渲染帧随机。
黑光组织沿肩、胸、前臂和太阳穴连接；没有把整套僵尸皮肤染黑。分段手肘、膝盖用于蹒跚行走、追击和左右交替扑击。
扑击使用服务端时间：先蓄力，第 11 tick 接触伤害，第 26 tick 收招结束；每轮最多一次命中，检查目标、接触范围和视线。被抓取、眩晕或正在包裹时取消待发攻击。
保留低阶资源怪的属性和直接吸收定位；普通感染者仍按人形抓取消耗，不因 Java 父类变更走四足或大型目标分支。

## 蝙蝠与幻翼

原感染宿主只为飞行谱系配置了导航/无重力，缺少空闲飞行目标；没有交战目标就可能停在地上。
补上受已加载区块、碰撞、液体和视线约束的空闲巡航，以及空中移动阻尼；远距交战保留一定高度，靠近后攻击。
原版蝙蝠备用渲染代理不执行实体 tick，单独 `setResting(false)` 不会启动 1.21.1 的飞行动画。现在显式停止休眠状态并启动振翅状态，仍从宿主绝对时钟采样，不每帧重新开始动画。
幻翼和自制飞行宿主的翅膀继续按各自飞行周期采样；不依赖地面走路相位才扇动。

## 成熟、互吞和恢复

阶段时钟加快不等于每个生物的组织年龄立刻加快。12000 为初步成熟，48000 为完整发育后参与同类竞争的门槛；六次真实成熟吞噬、器官整合、蜕变空间等条件保持。
2026-10-27 试玩图的自动存档可读到 19 只异变宿主，多只超过 24000，但当时最大的约 32367，尚未达到竞争门槛。城市区块卸载后不补算离线成长。
符合吞噬资格且接触中的捕食者，最后一击会保留猎物 12% 生命，接入真实吞噬场景，避免攻击跨过低于 15% 的窗口直接杀死。
此保护不作用于玩家伤害、远处目标、幼体、被玩家占有/无 AI/不可受伤对象，也不阻止普通环境和第三方战斗杀死目标；真正结算死亡时跳过保留逻辑。
已有玩家仇恨不会永久排除附近低血量同类：完整成熟且未被控制、未刚受伤的普通宿主，可以在有预算的搜寻中转向可吞噬猎物。近距离玩家交战时不主动另挑满血同类，进化者仍优先追击玩家。
吞噬成功且死亡被接受、击杀归属匹配后，捕食者恢复自身最大生命的 40%，并获得 40 tick 的短暂恢复期：其他 Mob 来源伤害乘 0.35。玩家伤害、管理击杀与绕过无敌的来源不享受这段保护。
死亡取消、打断、离开或重复回调不获得回血。原有器官继承、养分和整合仍走原结算。

## 验证边界

最终 755 项单元测试、133 项必需实服用例通过。日志分别为 `civilians-units-r3.log`、`civilians-server-r9.log`；正常生产构建为 `civilians-build-r1.log`。
新实服场景检查独立市民的旧存档、人形吞噬路线、真实攻击接触/抓取打断、蝙蝠/幻翼离地，以及成熟对手通过真实 AI 交战完成吞噬和回血。
两项原出生配额夹具按场景中已有活体预留“最后一个”人口位，避免将其他场景原有生物误算成可用空间；仍在真实加入回调内验证名额占用/异常退还。抓取夹具给 FakePlayer 补驱原玩家 tick 入口，不把无 tick 的假玩家当作实际完整客户端玩家。
同一生产 JAR 在 `native-civilians-flight-r3` 完成 8 张原生客户端画面：四套衣着正背面、追击、蓄力、命中后段、收招，以及分别近看的蝙蝠和幻翼起飞振翅。实际命中帧由服务端测试验证，客户端截图的记录年龄见 JSON，未将命中后段截图称为精确接触 tick。
前两轮原生夹具用于调整飞行截图时机和遮挡；最终分别等待实际离地再独立取景，没有提高生物位置来冒充起飞。单元和实服用例没有因此放宽飞行约束。
成年交战夹具预先给宿主 48000 组织年龄，不等于从默认出生、成长到六次自主吞噬的全流程生态验收。完整自然链路与总目标中其余器官、城市生态仍单独跟进。

补充回答后期外形：`native-late-species-r1` 用同一物种种子、未吞噬器官的样本，分别预设 48000/240000 组织年龄，完成蝙蝠、幻翼、凋零、铁傀儡的八张静态原生画面。
蝙蝠与幻翼保留物种并增长组织和体型；该例实际高分别从约 1.03/0.58 格变为 1.71/0.96 格。凋零和铁傀儡在这两个年龄的实际尺寸不变，因多部件特殊谱系被排除于普通代谢和竞争之外，不能宣称它们已经接入完整无限进化。
这些预设年龄、无 AI 的展示只证明当前渲染现状；镜头按身体尺寸自适应，截图不能用来比较绝对体型，也不是自然成长或吞噬后的聚合体证据。
