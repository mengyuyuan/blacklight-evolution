# 疾跑默认配置修复

录制实例使用 sprint_acceleration=0.055、sprint_max_speed=0.95，但此前代码默认值仍是 0.23968446601941748、2.0645631067961165。新建试玩目录没有配置文件时重新使用旧值，造成体验不一致。

两个加载器的代码默认值与 config-presets 现已统一为录制参数。满级疾跑速度上限为 0.95 × 1.45 = 1.3775 格/tick（27.55 格/秒）；旧值为约 59.87 格/秒。升级倍率、跳跃、滑翔和冲刺动作素材不变。

读取配置时，仅当加速度和速度上限同时精确匹配旧预设，才在内存中替换为新默认值；用户自定义组合不会被覆盖。保存配置时写入实际使用值。没有配置文件的新安装直接使用新默认值。联机仍由服务端下发参数。

原有 sprint / fast / fastest 动画以素材自身节奏为上限，不能再次随高移动速度倍速叠加。发布包同时带有默认配置，避免依赖录制目录的私有设置。
