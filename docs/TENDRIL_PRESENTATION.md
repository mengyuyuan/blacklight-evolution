# 触须呈现与身体连接

`DevastatorEffectRenderer` 的胸腹、肩和腕起点来自 `BlacklightPlayerModel` 实际绘制的同一组关节矩阵及世界坐标变换。低伏动作不能用站立碰撞箱高度代替胸部高度；腕部 `Tool_R/L` 的偏移为掌根附近的 −0.03 格，避免此前 +0.30 格将起点移回前臂。第一人称无世界模型绘制时，使用同一当前姿态求备用世界锚点；原生第一人称和感知轮廓绘制不会覆盖第三人称锚点。

内部 `BodyRoots` 包含胸部中心、胸部四个表面点、腹部四个表面点、左右肩和左右腕，共 13 个世界坐标点。胸腹束选择朝向目标的表面并沿胸腹带分散；肩腕束保持真实关节连接。`capturedChest(entityId)` 供验收读取本帧实际胸部中心。

宽度采用已核对的 Tendril 随机/prop 家族 Scale 0.3–0.7；此前的 0.7–2.6 并非该家族范围，密集根部因此过粗。不同束保留源 WaveSpeed 2–7、WaveAmplitude 0.15–0.5 及既定身体比例，并使用 0.2/0.5 秒的波幅过渡。小幅连续宽度脉动、肩腕分配和向外的胸腹表面出口属于 Minecraft 呈现适配，不声称恢复了未知原生回调。湿亮和凸起红筋仍由已创作的模型与既有湿组织材质提供。

总束数保留 `max(60, synchronized contacts)`，所有目标仍来自服务器同步的同一 contacts 列表。每束使用原 `contact.at`、推进/回收速度和回收起点计算；没有改变服务器命中、射程、384,000 顶点预算、身体租约或视觉寿命。原作 50.5–53 秒参考支持胸腹凝聚后向外伸展、外围细须和局部湿亮，不能证明精确原生分配或收回语义。
