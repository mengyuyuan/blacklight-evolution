# 同类模组包体对照与下一轮实验

2026-10-26 核对官方发布页、史诗战斗公开源码和本地正式 JAR。这里的本地数值使用十进制 MB；发布站的 MB 标签可能采用 MiB，不能混算。此文是研究结果，未实施的格式改造不能计入 compact.2 的体积收益。

## 实测差异

| 本地文件 | JAR 字节 | 最大相关资源占用，已压缩 |
|---|---:|---|
| Epic Fight 20.14.17，Forge 1.20.1 | 8,071,119 | 动画与骨骼目录 1,112,674；代码 2,739,917 |
| Epic Fight 21.17.3.1，NeoForge 1.21.1 | 8,578,288 | 动画与骨骼目录 1,132,764；代码 3,166,938 |
| Spore 2.2.0j，NeoForge 1.21.1 | 119,073,141 | 音频 100,512,604；贴图 12,438,465 |
| Blacklight compact.2，NeoForge 1.21.1 | 139,481,499 | 地理瓦片 71,507,440；城市核心 6,964,001；动作约 32,600,000；教程 GIF 9,292,026 |

史诗战斗确实只有约 7–8 MiB。其官方文件页列出相同版本；不能以黑光功能多为理由忽略动画目录的显著差距。[官方发布页](https://www.curseforge.com/minecraft/mc-mods/epic-fight-mod/files/all)

本地同长度奔跑样本的对照：史诗战斗 `run.json` 有 20 条轨道、单轨最多 5 帧，共 99 个轨道帧；黑光 `basic_sprint.json` 有 21 条轨道、单轨最多 33 帧，共 693 个轨道帧。原始 JSON 分别为 16,438 和 178,239 字节。它们不是同一个动作，不能据此直接推算整包可缩小多少。公开的 `AnimationClip` 在运行时整理关键时刻并插值，说明可以研究稀疏关键帧与运行时采样的分工。[官方实现](https://github.com/Antikythera-Studios/epicfight/blob/1.21.1/src/main/java/yesman/epicfight/api/animation/AnimationClip.java)

Spore 的主要占用来自音频，不宜仅凭感染生物数量比较包大小。其主体源码目前未公开，本轮没有声称审计过该私有源码。[官方发布](https://www.curseforge.com/minecraft/mc-mods/fungal-infection-spore/files/8342823)、[官方 Wiki 的仓库状态](https://www.fungalinfectionspore.wiki/home)

失落城市 1.21-8.4.5 官方文件页约 1.4 MB。其建筑由可重复楼层、部件和调色板组合，而不是存储真实城市的全部地理轮廓。模块化建筑值得采用；真实深圳与洛杉矶的道路、山海和建筑位置仍需保存独有数据。[发布页](https://www.curseforge.com/minecraft/mc-mods/the-lost-cities/files/9026865)、[官方资源设计](https://github.com/McJtyMods/mcjty.eu/blob/main/www/docs/mods/lost-cities/asset_structure.md)

## 优先级

1. **动作的运行时编译格式。** 先统计实际消费的骨骼、常量通道、重复时间轴和数值类型；只在恢复出的运行时输入相同的前提下，共享数据、压缩常量和冗余通道。原始编辑/来源数据保留在仓库，不强制玩家携带全部编辑信息。需要覆盖伤害帧、位移、接触点和多人动画。
2. **关键帧曲线实验。** 对可被相同插值精确表示的片段减少冗余采样；对不能精确表示的动作保留原采样。任何有误差的简化必须独立报告误差并实机比较，不以“更小”为由默默改变动作。
3. **地理结构去重。** 保留真实位置，尝试坐标差分、共享特征表、跨瓦片重复要素引用和小组索引压缩。已有通用二进制实验在 8 个样本中反而比 XZ JSON 大，不能把“二进制”当作必然收益；需要全量测量、限制解码内存并验证生成结果。
4. **教程帧与模型复用。** 优先查 GIF 重复帧、透明区域、模型重复几何和可共用贴图；保留清晰度与技能演示内容。PNG 和已压缩音频不是当前最大的收益来源。
5. **持续预算。** 保持构建输出资源排行榜和 200,000,000 字节主 JAR 门槛；新城市只增加独有地理和地标，复用建筑生成器及生态实现。地图仍内置，游玩时不下载城市。

只调整 ZIP 等级、混淆 Java 代码或再套一层压缩无法解决主要占用。compact.2 已经将上一版 172,361,664 字节降至 139,481,499 字节；下一轮应先用独立实验测出上面各项的真实收益，再决定实现顺序，不承诺未经验证的最终大小。
