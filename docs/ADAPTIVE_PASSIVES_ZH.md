# 适应性与组织再生（开发版）

此功能来自维护者转述的赞助玩法。最终规则以本文件为准，不宣称为原作技能。

## 操作

- 技能页 → 生物进化：适应性 350 EP、组织再生 350 EP；适应性 II 500 EP，需要先学习适应性。学习的被动在虐杀模式生效。
- 普通玩家可饮用适应性药水 / 组织再生药水获得对应永久被动；无需感染，无需虐杀模式。授予资格和层数存档，死亡后保留；牛奶或清除效果不会删除永久资格，下刻恢复标识。
- 创造物品栏可找到两瓶药水。合成：玻璃瓶＋蜂蜜瓶＋地狱疣＋铁锭（适应性）或恶魂之泪（组织再生）。
- 两种来源共享同一份层数，不叠加执行；初始为0层，重复饮用不刷层数。

## 精确计算顺序

进入这套被动前，先处理护甲、抗性、既有伤害单位换算、金心和临界质量储备。只对最终能进入生命扣除的伤害结算；取消的攻击、无敌期被拒绝的攻击和完全被前置防御吸收的攻击不叠层。/kill 等绕过无敌的伤害不拦截。

设进入被动前伤害为 D、当前生命 H、最大生命 M、适应性层数 A：

1. 基础适应性：减伤 A/(A+H)。升级版：A/(A+100*H/M)。先用命中前的层数和血量计算；百分数和减伤率不提前取整。
2. 实际伤害 d=D*(1-减伤)，阻挡 B=D-d。
3. 适应性每次有效受伤固定加1层（维护者后续明确修正了最初的伤害/6说法），再扣 round(B*0.1) 层，最低0层。
4. 组织再生按 round(D/6) 增层，与适应性的固定+1分开。
5. 每20游戏刻回复当前再生层数的生命值，然后扣 round(层数*0.2)。不补算离线时间；满血也按时扣层。回血沿用正常治疗事件，受其他模组治疗规则影响，不增加临界质量。

正数四舍五入：floor(x+0.5)。按指定公式，组织再生剩1或2层会保留（20%四舍五入为0），未擅自改成至少扣1。生命单位是点，2点等于原版1颗心。HUD百分比显示取整，不影响内部计算。

例：H=10、A=90、D=60 → 6点伤害、挡54点、A=90+1-5=86，剩4血后减伤约96%。再生原有10层 → 本击增加10层 → 20层 → 下一秒回复20点、剩16层 → 下一秒回复16点、剩13层。

升级例：H=10、M=1000、A=99 → 百分数1 → 99%减伤；若D=60，受伤0.6、挡59.4，剩99+1-6=94层。正常未死亡血量百分数保留小数，不把低于1%的生命算成0。

## 模式边界修复（2026-10-15）

永久药水提供模式外的基础被动，不把已学习的适应性 II 一并带到模式外；II 级公式需要感染且开启虐杀模式。附件替换本身会同步，更新被动时不再额外重复发送。
