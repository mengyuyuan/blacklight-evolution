# 黑光技能与独立药水的拆分

黑光本体保留进化点购买的适应性、组织再生及现有适应性 II 技能。当前技能公式保持原实现：适应性有效受伤加 1 层，扣除被减免伤害的 10% 层数并四舍五入；组织再生按适应性减伤前伤害除以 6 四舍五入加层，每 20 tick 按层数回血并四舍五入衰减 20%。技能只在已感染且开启虐杀模式时生效。

永久药水、赞助者文档的两阶药水规则和击杀成长迁入 `standalone-passives/` 独立项目。独立构建不依赖黑光，黑光构建也不自动打包药水。详见 [独立药水说明](../standalone-passives/README.md)。

两者共同安装时，同名药水能力接管该项结算，黑光技能不会重复减伤、回血或加层。未喝对应药水的技能不受影响。

旧药水 ID 为存档兼容保留，移除主模组中的合成配方和创造栏入口。仅装主模组时旧药水无法饮用，会提示安装独立模组；旧永久资格保留但不生效，安装独立模组后迁移一次。技能解锁记录与药水状态独立，迁移不赠送进化点、不购买技能、不重复赠送层数。

两版协议已更新，客户端与服务端需安装匹配版本。独立药水 Mod 的测试记录见其 TEST_RESULTS.md；没有将编译成功当成游戏验收。

## 层数 HUD

U 技能页面 → 设置 → 显示黑光被动层数，可单独开关黑光层数 HUD。独立药水的显示由 Mods → Adaptive Passives → Config 中的开关控制。二者均为本地显示偏好，保存后重启保留，不影响被动效果。
