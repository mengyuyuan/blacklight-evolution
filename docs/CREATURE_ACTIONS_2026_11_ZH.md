# 现有黑光生物：动作驱动的技能接入

本批同时面向 NeoForge 1.21.1 与 Forge 1.20.1。先让现有生物的动作、实体移动、命中和收招使用同一时钟；没有把尚未制作的新剧情 Boss 或无人机算入完成项。

## 本批新增与修正

| 生物 | 动作/技能 | 接触或释放帧（20 tick/秒） |
| --- | --- | --- |
| 普通感染者 | 左右抓击、双手扑打；出招时锁定方向，可绕背躲开 | 11 / 11 / 14 |
| 潜行者 | 抓击、前扑、双抓 | 14 / 18 / 12、24 |
| 喷吐者 | 单发、三连吐、近身后撤 | 14 / 14、24、34 / 后撤不伤害 |
| 重型变异体 | 重拳、双臂砸地、冲撞 | 18 / 24 / 14–26 内每目标一次 |
| 蜂巢 | 冠瓣先打开，再释放幼体；生成前重新检查数量和世界规则 | 打开后第 8 tick |
| 九头蛇 | 沿用现有砸地、横扫、侧扫；补齐对非玩家敌人的攻击与感染阵营过滤 | 保留原有动作时序 |

变异体原先共用一个循环攻击片段，且近战只检查玩家；现在每种有独立招式，能攻击有效的非玩家敌人。主动出招的目标选择变化不会清掉已承诺的挥击方向。目标死亡、抓取、失能、越过领地限制等仍会中止动作。

喷吐使用带重力和阻力的低抛物线，朝前摇时记录的位置发射；移动目标可以躲开。每一发发射前检查视线。友军不会受伤，但会挡住弹道。冲撞、前扑、后撤移动的是服务端碰撞体，不能穿过方块。

伤害接入已有的感染者命中粒子和声音通道，只在伤害被接受后产生反馈。砸地在接触帧产生脚下方块材质的碎屑和撞击音。没有清空原版受伤冷却来强行造成多段必中。

抓取现在在冻结变异体之前明确清除其待执行招式，避免放开后补出冻结前的攻击。

## 动作来源

本批潜行者、喷吐者和重型变异体的九个片段，来自仓库已有自制攻击动作的重定时、镜像，以及新增的蓄力、腿步、后撤和收招关键帧。不是新提取的原作动作，也不声称拥有原作完整 AI。

`tools/build_mutant_combat.mjs` 生成 Gecko 片段和 30 FPS 姿势表，记录在 `art/mutant-combat/manifest.json`。服务端用 tick 时序执行技能，客户端按同一个起始时间采样，后加入观察的客户端也能定位到当前姿势。

普通感染者继续使用项目自制的关节动作；新增双手扑打有独立的蓄力、伸臂、躯干前倾和恢复。前扑是地面突进，不是带腾空落点计算的跳跃技。

## 其余现有生物的入口核对

这些系统此前已存在，本批保留，不能算成本批新增：

| 生物/形态 | 已有动作和能力入口 |
| --- | --- |
| 猎手 | 挥击、连续抓击、双拳砸地、扑击、侧闪；`CreatureAttack` / `CreaturePoseTable.HUNTER` |
| 普通感染宿主 | 组织近战前摇与接触；原物种远程、跳跃、攀爬、飞行能力；`NativeInfectedCombat` |
| 继承器官宿主 | 器官伸出、命中、撤回周期；`TissueAbilities` 与组织动作状态 |
| 进化者 | 刀臂突刺、跳斩、后撤和闪避；`EvolvedCombat` 与二代姿势适配 |
| 巨型/飞行宿主 | 现有体型、器官及飞行控制；不会把地面人的招式直接套给所有骨架 |
| 至高猎手 | 爪击、反手、重拳、踩地、地刺、毁灭技、投掷、冲撞、跃击、抓投和弱腿倒地；`SupremeHunterMove` |

模型复用和技能驱动已有通用模组入口，但本批没有逐个安装第三方模组验收；不能据此宣称所有模组或自定义渲染器均已兼容。缺失的一、二代怪物及剧情 Boss、黑色守望战术 AI、无人机仍属于后续工作。

## 验证

- 两个平台各 19 项真实服务端 GameTest 已通过：九个招式、接触时间、非玩家目标、墙体、背后躲避、友军、冲撞不穿墙、真实抓取、NoAI 打断、普通感染者三个出招与目标选择器变化、九头蛇横扫、蜂巢先开后生与取消生成。
- 日志：`D:/CodexCache/creature-combat-neo-server.log`、`D:/CodexCache/creature-combat-forge-server.log`。
- 隐藏、静音客户端只使用 `D:/CodexCache/creature-combat-qa/client` 下的独立存档；没有操作桌面输入，也没有打开或修改用户世界。截图与接触记录输出到同目录树的 `frames`。
- Forge 1.20.1 隐藏客户端保留 138 张有效帧，按当前证据清单生成五张联系表并审阅；涵盖接触前后、连击第二段、三发喷吐、后撤、砸地、收招和孵化。早期过暗截图被同名覆盖，不作为最终验收。1.21.1 未在本批重跑客户端画面，使用同一份动作资产并通过服务端与单元测试校验。
- 最终单元测试与交付包校验记录在 `D:/CodexCache/creature-combat-qa/neo-artifact.json`、`forge-artifact.json`；截图记录为 `frames/evidence.json`（本批九招）与 `frames/extra-evidence.json`（普通感染者、蜂巢）。未记录的项目不能视作已通过。

测试源码通过独立 Gradle init 脚本启用，不进入正常交付包。
