# 基地为什么能驻军，士兵的归属是什么

本文解释military.5开发版规则；正式安装包与最终验证状态以本版实施记录为准。旧military.4安装包不会因这份文档自动获得新功能。

基地由三部分组成：看得见的建筑、存档里的基地登记、建筑中还可用的指挥设施。生成一座基地时，游戏会登记其阵营、位置、原驻军名额、岗位和弹药箱。玩家自己搭一座相似建筑，暂时不会自动变成已登记基地。

## 人数不是建筑容量

| 数字 | 实际含义 |
| --- | --- |
| 军方16、黑色守望20 | 每座大型基地最初可以发放的驻军名额，逐批出现；阵亡不免费补刷 |
| 默认80 | 本维度同时加载的原生驻军预算，可配置；普通怪物不占这个额度 |
| 后来归队的士兵 | 可以在此驻扎、巡逻和取弹，不冒充一个新的原生名额 |
| 小队、班排连、中队大队 | 人员的指挥编制，与一座建筑的驻军发放记录分开 |

因此，16/20不是“多一个人就不许进入”的房屋容量。基地状态里的`issued`和`loaded`仍表示原生驻军发放及加载数量，不把外来巡逻兵混入原名额。

## 基地受损和失效

指挥楼原有6处指挥终端，任意一处还在就能维持指挥功能。6处都已加载、而且全部持续缺失约10秒后，基地才判为指挥设施失效。观察缺失期间先暂停新的自动发兵。

一面围墙破了、一个仓库没了，不会直接撤销基地身份。远离基地导致区块卸载，也不代表基地被毁。这里判断的是指挥功能，没有凭空给整座建筑一个百分比血条。

修复至少一处原指挥终端可以恢复功能，但不会重新造楼、重填箱子、复活死者或重置已发放的名额。

## 士兵会去哪里

- 原基地守军正常时保留岗位。
- 独立刷出的士兵初始化后，寻找256格内已登记、已加载、同阵营且有效的基地，作为外出巡逻的归属。
- 没有合适基地时，保存生成位置作为野外巡逻点，在附近活动并继续作战。
- 所属基地确认失效后，士兵保留原身份、军衔、编制、装备和剩余弹药，寻找另一座同阵营有效基地并正常步行转移；找不到就独立巡逻作战。
- 手工下达和上级继承的组织命令优先，自动归属不会偷偷抹掉命令。

原来由哪座基地发放，与现在住在哪里是两份记录。转移不会复制士兵，也不会让旧基地把同一名士兵再发放一遍。

## 弹药从哪里来

士兵只能从当前有效驻地登记的弹药箱实际取出匹配弹药，必须寻路靠近；箱子会扣掉相同数量。换基地本身不补弹，空箱不出弹，普通装饰箱也不会自动成为军火库。弹药箱被破坏会影响补给，但不直接等同整座基地失效。

## 查询与调整

下列指令需要开启作弊或管理员权限。选择器只选同一维度、附近实际存在的士兵；没刷出该类士兵时会提示没有实体。

```mcfunction
/blacklight military base status
/blacklight military home @e[type=blacklight:military_soldier,distance=..20] status
/blacklight military home @e[type=blacklight:blackwatch_soldier,distance=..20] status
```

把末尾`status`改成`auto`，让选中的士兵重新自动寻找归属；改成`field`，让他们以当前位置作为野外巡逻点。这些操作不发枪弹、不改军衔，也不撤销已有上级命令。查看军官或重装兵时，需把实体类型改为相应兵种。
