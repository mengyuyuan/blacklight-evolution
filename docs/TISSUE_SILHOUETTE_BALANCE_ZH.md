# 组织轮廓与交战修正（NeoForge 1.21.1）

2026-10-22 试玩指出普通宿主后期长成团块，而且一两下便死亡，随后指出此前物种模型不再出现。本轮保留持续成长、主导器官和原生骨架，修正以下叠加问题。

- 恢复已有物种绑定优先：本地仍有 81 份 `infection_parts` 资源。原生骨骼能匹配时优先使用这些旧造型，缺少资源或无法绑定时才使用通用生成器；多段首领保留已有专用网格。旧模型从相同服务端年龄与种子接入后期局部变形、共享整体体型和触手行走，不叠加之前的通用躯干包络及第二套肌肉膨胀。没有删掉模型资源。
- 用户随后明确两套都保留：0–12,000 tick 使用专属感染造型；12,000–48,000 tick 在该造型上平滑长出随机器官，48,000 tick 后继续发展。保留专属皮肤，不额外覆盖通用躯干/整张头壳。新器官、转轴一起回贴存活的宿主表面，旧皮肤和后期器官使用同一局部形变场；整体骨架、受击和服务器年龄继续共用。没有做两套完整模型的突然切换。

- 通用造型缓存原来截断 UUID 后重新取主导器官，可能与真实宿主的器官类别不符。现在每种真实主导对应四个固定造型种子，每个通用原生模型最多二十种基础造型，不按代数新增缓存。
- 通用后备造型中，甲壳主导才长出完整甲板与第二对肋弓，骨冠主导保留明显肩冠，颅颚主导保留大颊刃。辅助结构收敛为贴体结构，不再让每只宿主都同时满配全部器官。
- 降低成熟躯干、主导肢体及两层后期变形的截面膨胀，保留腰、关节和脚端的收束。整体体型仍持续长大，攻击及触手分支继续工作。
- 由实际骨骼中心和局部朝向，在平行直立肢体之间预计算走路间隙；基础皮肤、后期皮肤、器官根部及转轴使用同一约束。不会压缩原生几何，不对放射状蜘蛛腿硬套直立肢体约束。数据在造型生成时计算，绘制时不扫描世界或寻找邻近实体。
- 耐久改为成熟期建立基础生命与护甲、古老期以后持续递减收益增长，具体公式见 [猎食与战力成长](TISSUE_METABOLISM_ZH.md)。攻击系数未提高，未感染生物未增强；受伤比例、器官破裂和吞噬门槛保留。

该修正改善共同轮廓与平行肢体的空间，并不代表任意第三方骨架在所有动作中都不会穿插，也不代表新美术已经获玩家认可。

本轮验证（2026-10-22）：

- 单元测试 521 项通过；独立服务端 46 项必需 GameTest 通过，包括真实利爪伤害事件、五种主导器官的存活与可击杀性、受伤比例存取。
- 正常专属模型叠加器官、强制通用后备两条路径，各运行六种体型、十四个阶段，共生成并校验 168 张 1280×800 实机截图；另人工抽查成熟期、后期、行走及攻击画面。覆盖猪、鸡、豹猫、洞穴蜘蛛、僵尸、牛，并非所有第三方模型。
- 基础利爪连招的服务端击杀测试中，成熟宿主需 6 次命中，第八代按主导器官需 11–18 次，第三十二代需 14–26 次。该数据不代表满升级武器或其他技能的固定命中次数。
- 通用后备初次复测遭遇共享构建目录被其他编译覆盖，未进入地图，未计为通过；改用独立构建目录复测后通过。正常试玩也使用该独立输出，避免共享临时文件干扰。

## 后期轮廓补正

同日试玩反馈“看着没太大变换”。读取已保存的试玩实体，确认其中已有 240,134 tick 的第八代宿主及约 846,000 tick 的第三十三代宿主，问题不是等待时间不足。

- 专属皮肤多为原生方形面的端点，原局部成长场在两端归零，缺少中段顶点，导致肩部和肌肉轮廓几乎没有变化。现在仅在模型绑定时沿实际骨骼最长轴切出三段；保留表面积、法线方向、伤口和原生纹理坐标，不按年龄或绘制帧新增几何。
- 后期躯干、颚与肢体使用更明显的同一局部成长场。关节端点和腿部空间约束保留；专属纹理随组织发育渐变为暗红色，仍保留原花纹。
- 移植器官原先整块平移至原生表面，导致甲板和骨冠的远端也埋入身体。现在只将器官根部压入表面，向远端平滑减弱位移，保留外露的器官轮廓与同一根部转轴。
- 颅颚主导重新显露原先被误当作全身皮肤过滤掉的下颚网格；其他主导不额外叠加一整颗头。早期仍使用物种专属感染造型，后期器官开始于原定年龄。
- 首轮实机对照仍显得像原生皮肤加刺，故补充同一皮肤三角面上的组织覆盖：复用已变形的表面、伤口及法线，以骨骼局部坐标中的同一个连续场裁切生长边界，跨三角面保持连续，最终形成完整血肉和甲质表面；没有第二层体积包络。独立三角面从中心展开的中间方案在实机中出现网纹，已弃用。头部、躯干和肢体使用现有共享组织材质。主导器官的远端和承力截面一起发展，辅助结构不一并放大。覆盖完整后不再绘制其下的原生皮肤，也不继续进行边界裁切。
- 对照镜头按实体的物理成长比例后移，使前后期在画面中的主体高度近似一致，避免把整体大小变化当成局部结构变化。追加 24,000 与 36,000 tick 的过渡画面，检查组织覆盖、根部与器官之间的渐进衔接。

本次追加修正的测试和实机对照结果单独记录于 `E:/Blacklight-Spore-QA/tissue-stage-contrast-verification-20261022.json`，不沿用上一次通过记录充作本次验收。

追加修正最终验证：527 项单元测试通过。猪灵、牛分别覆盖五种主导器官，另检查史莱姆和蜘蛛，共十二个样本、十八段阶段/动作，校验 216 张实机截图及服务端年龄、动作计时、主体比例和渲染预算；人工抽查肌肉、甲壳、颅颚、骨冠、行走与两个中间覆盖阶段。对照使用相同投影主体比例。中间未采用的美术检查与构建失败不计作最终通过；本次没有修改战斗数值或增加器官类型。
