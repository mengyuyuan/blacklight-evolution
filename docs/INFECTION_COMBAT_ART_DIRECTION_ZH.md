# 感染体攻击升级：黑光血肉语言

本轮以 NeoForge 1.21.1 为实现和验收对象。不是给所有生物套同一团红色粒子，也不重写玩家已有动作文件。

## 共同原则

- 原生能力先保留：会飞的继续飞，会跳的继续跳，远程和施法不能退化成走近拍打。感染组织加在这些能力上。
- 黑红肌腱是受力结构，暗红肉质是体积，灰白骨质是锋刃。亮红只用于局部活动组织，不把全身点成霓虹灯。
- 先绷紧、再出力、接触后拉断或穿刺、最后回抽。重击靠体积、拖拽和停顿表现力量，不靠提高播放速度。
- 刀口、肉丝跟随实际渲染的肢体坐标；命中效果来自服务端接受伤害的位置。挥空可以有短拖尾，不能产生命中组织。
- 普通感染者是短促、湿重、易辨认的小规模撕扯；进化者更完整、更受控；大型感染体才拥有宽幅组织喷射和多段攻击。
- 本轮不增加永久地形污染、不修改玩家镜头、不重置敌人的无敌帧。可打断和可闪避的窗口继续存在。

## 六套命中结构

| 结构 | 主要载体 | 接触与收招 |
|---|---|---|
| 撕裂 | 普通感染者、利爪、猎手、扑击 | 三道有方向的短切痕，绷紧的黑红组织丝拉断，带出少量灰白碎组织，随后收缩消失 |
| 穿刺 | 骨刺、三叉戟、角、九头蛇 | 沿来向产生骨质刺入和短暂组织翻卷；细肉筋回抽，不在目标四周随机画一圈刀光 |
| 重压 | 铁傀儡、监守者近战、重锤、盾击、重型突变体 | 受击面压缩、宽而短的冲击环、体积碎屑；锤击落地另有地面波与方块碎屑 |
| 绞拉 | 抓握器官、长舌、水肌、触须进化者 | 少量较长的组织束先拉直再回弹；真实牵引继续由原抓握系统管理，效果不能额外锁人 |
| 爆生 | 肉瘤、喷吐、感染火球、母巢攻击 | 有连续体积的肉质核心膨胀、破裂、伸出分支组织、最后回收；不使用永久悬空柱子 |
| 共振 | 监守者音爆、守卫者射线 | 能量从组织核心聚集，沿实际攻击轴传播，命中产生组织波纹；守卫者受墙阻挡，监守者保留原生穿墙音爆 |

以上命中结构通过统一服务端伤害后处理覆盖普通感染者、感染宿主、猎手、突变体、母巢、九头蛇、进化者，以及仍处在感染过程中的生物。被取消、无伤害的攻击不发命中包。

## 各类攻击的落点

| 生物/能力 | 保留的特色 | 本轮强化 |
|---|---|---|
| 骷髅、流浪者、沼骸、掠夺者 | 有实体碰撞的箭、原生减速/毒素 | 施射时钟、装备继承、骨质穿刺命中 |
| 溺尸、潜影贝、女巫、唤魔者 | 三叉戟、追踪弹、药水、地面尖牙 | 独立前摇和恢复；血肉穿刺/爆生风格；尖牙检查真实地面 |
| 烈焰人、恶魂 | 原生火球 | 在原生火球之外间歇发射肉瘤，不能以肉瘤为借口删除原生武器 |
| 守卫者、远古守卫者 | 蓄力射线、游动 | 可见的蓄能和射线，命中反馈；实时检查墙体 |
| 监守者 | 高近战基线、黑暗、音爆 | 保留抗击退；恢复被通用 18 点上限压掉的近战；强化音爆、胸腔蓄力和共振 |
| 凋零 | 悬浮、凋零头颅、缓慢再生 | 叠加肉瘤弹；半血后从单肉瘤升级为三路肉瘤；爆开后六条有实际碰撞检测的触须，正常伤害管线结算 |
| 末影龙 | 飞行、龙息弹 | 增加两枚肉瘤与颌/颈蓄力；保留原末地战斗归属，不生成第二条假龙 |
| 史莱姆、蜘蛛、幻翼、蝙蝠 | 跳跃、攀爬、俯冲、自由飞行 | 恢复真实移动；原生客户端动画时钟继续运行，触须成长不抹掉飞行与游动 |
| 八类进化者 | 原有专项动作与真实碰撞 | 重锤地面波、盾击气浪、扑击/突进拖尾、骨刺命中与尾迹、触须牵引和恢复脉冲；统一接受伤害后的组织反馈 |

## 肉瘤弹四阶段

1. 飞行：搏动肉核、短组织尾；可射落，命中方块或生物才爆生。
2. 接触：半径 2.3 格内的初始冲击，最多选择六个组织分支方向。
3. 第 12 tick：组织完全伸展，检查分支实际线段与目标碰撞箱、墙体遮挡。每个目标本阶段最多结算一次，不是隐形球形伤害。
4. 第 24–36 tick：回抽；第 36 tick 移除。发射者失效会清理，未完成阶段不写入存档重放。

穿墙音爆属于监守者原有特色，不能据此让肉瘤触须、普通射线也无视墙体。凋零原生头颅的地形行为继续遵循原版与游戏规则；肉瘤本身不删除方块。

## 动画与性能

原生渲染替身只运行客户端动画更新，一 tick 一次，不加入世界、不运行服务端 AI。还原鱿鱼触腕、现代 AnimationState、蝙蝠飞行、铁傀儡/劫掠兽攻击时钟；配对吞噬、受击与进化者专用骨骼仍优先。

命中包只从服务端发给周边玩家，单维度每 tick 最多 64 个。客户端最多保留 128 组短期命中和 128 个有肢体拖尾的生物，并按距离、视锥、时钟清理。不随器官代数无限增加特效实例。不新增大纹理、录像或动作采样副本。

未知模组的自定义技能不能凭模型或物种名完整推断。新感染的 RangedAttackMob 使用通用远程兜底，原生攀爬/跳跃能力有描述字段；没有公开能力接口的专属机制仍需要对应适配，不能宣称所有第三方技能已经原样恢复。
