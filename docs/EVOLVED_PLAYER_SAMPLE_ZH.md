# 刀臂进化者样板

当前先打磨一个类型。身体保持 Minecraft 标准玩家的六个方块部件：8×8×8 的头、8×12×4 的身体、4×12×4 的手臂和腿。绑定《虐杀原形 2》进化者 `evolved_runner1` 的完整 67 骨架及原动作；保留原关节名称、父子层级、手肘与膝盖。仅把中立姿态和骨长对齐到 Minecraft 比例，并对方块表面进行蒙皮细分，不改成异形身体。

evolved.4 以二代 `evolved_runner1` 对应的原刀臂表面作为适配依据，保留真实的细长正面、宽刃侧面、刀背倒刺和开放组织轮廓，替换完整双臂。普通皮肤手臂完全隐藏，不再套用玩家武器或用厚护甲代替刀臂。肩肘按 Minecraft 比例绑定，手腕与远端刀刃随前臂保持刚性；远端过长部分按方块人的身体比例适配。保留二代原骨架层级和动作，通过真实关节指向适配；原动作与模型的前方均为 -Z，避免前后反转。

刀臂几何来源与输入散列见 `docs/design/evolved-complete-arms.json`。材质为新制像素图集，不复制游戏原贴图。方块人身体使用新制兜帽、呼吸面罩及战术服皮肤，对齐该原型的身份特征。可编辑中立姿态双臂位于 `art/evolved-arm-adapter/evolved_arms.bbmodel`，完整蒙皮和动作仍由运行时资源驱动。

普通攻击的受击停顿为八刻，重击为十六刻；击飞及起身总控制时间不超过二十四刻。一次受控后保留至少四十刻行动机会，再次受击仍扣血，但不能不断刷新停顿或推进位移。可吞噬血线的两秒眩晕独立保留，不会被普通连招缩短。受击使用二代进化者的原受击片段；攻击朝向在起手时确定，背后目标不能仅因进入包围盒就被打中。

锁定界面默认只显示一行目标摘要；按住可改键的“目标详情”（默认右 Alt）查看器官、代数和养分。初次成熟与后续初期成长计入显示代数，器官尚未达到品阶时显示“发育中”。真实可吞噬目标在头顶显示红色 DNA 标志，附近最多显示八个，遵守视线。玩家实际攻击将可吞噬目标打至对应血线后产生两秒眩晕，十秒内不会重复刷新该机会；健康的低强度生物不会因“可以直接吞噬”就被自动定身。

自然蜕变保留现有真实吞噬条件：至少六次本人完成的成熟感染体吞噬、六份取得的器官、资格积分以及成熟核心器官。世界天数只加快培养，不替代这些门槛。蜕变经历收拢、覆盖、展开，十秒完成；保留原实体、器官记录、来源和受伤比例。空间受阻会延期，重新载入从已运行进度继续。

管理员指令 `/blacklight evolved_sample` 在前方生成一个**预置六份成熟器官的试玩样本**，用于观察十秒蜕变和战斗。样本不是自然获得过程的证明。

成形后优先搜索范围内的生存或冒险玩家；丢失视线后最多保留十秒目标记忆，并通过普通寻路追击，重新计算路径有节流。突刺、退步双斩、跳斩、侧闪和实际继承的抓取能力按距离选择，命中需要真实接触与视线；创造、旁观、死亡和失效目标会解除。原形体身份本身不会让玩家成为友军，既有伪装玩法仍按原规则工作。

evolved.5 把进化者划为独立超级精英：在最终人形的成熟器官属性上，生命乘六、攻击乘五，额外护甲六、韧性四、移速乘一点二五、抗击退加零点四。当前六器官样本约一万二千八百生命、三十六点攻击属性；实际命中仍经过目标护甲与黑光血量单位换算。对感染玩家移除普通怪的十点伤害封顶，改为单次命中在防御前最多按玩家最大生命的百分之三十、再乘难度系数；不把较小伤害强行提高。成长和继承继续生效。服务端可在 `blacklight-evolved-server.toml` 调整。

原动作的 motion_root 位移通过服务端碰撞移动接入，模型保留原地蒙皮，避免重复位移。攻击中锁定起手朝向，收招可绕步；左右突刺、退步切回及跳斩有各自的真实位移。战斗时使用戒备走步，偶尔磨刃或招手挑衅；玩家逼近、出手、受击或失去视线会打断挑衅。非战斗静止时偶尔耸肩、活动颈部。姿态切换使用四刻关节插值。

刀锋拖尾从最终渲染的真实刀臂表面采样，限定在攻击窗口内，快速淡出；突刺预兆与武器展开时有贴附刀臂的红色组织流动。真实伤害被接受后才广播命中粒子和声音，空挥不伪造命中反馈；起跳、侧闪、前冲带少量地面碎屑，跳斩触地有尘土冲击。完整对照与尚未接入的二代能力见 `docs/EVOLVED_COMBAT_REFERENCE_ZH.md`。

养分储备上限与当前阶段需求分别显示。新感染体从身体获得少量初始储备；成熟且满血静止时不自动消耗。成长加速费用按阶段增加，逐渐结算；世界第七天约为两倍、第二十八天约为三倍培养速度。伤后恢复与实际器官消化仍会消耗养分。
