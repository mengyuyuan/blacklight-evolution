## 构建与收集

Java 21。普通源码编译只检查工程能构建；本地试玩需已有的完整资料目录：

```text
gradlew.bat assemble --no-daemon -PbundleMotionDirectory=<本机完整资料目录>
python tools/package_release.py --profile local-preview
```

产物收集到 `release/local-0.2.0-rc.57/`。脚本检查编译类、元数据、许可证、私有资源标记和 ZIP 内容，并生成包含未提交源码的快照、`RELEASE-MANIFEST.json` 与 `SHA256SUMS.txt`。源码快照不会收集存档、缓存、外部私有动作目录或未跟踪的美术实验目录。若用独立构建目录，向脚本传入 `--build-dir <目录>`。

没有私有资料时，可运行普通 `assemble` 生成 `source-only` 文件，供工程检查使用；不要将其当作玩法完整的替代版本。本轮不改现有认可的动画或 HUD 来掩盖资源缺口。
