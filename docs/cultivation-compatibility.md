# 小翔的修仙世界兼容

对象：`xiaoxiang_cultivation`。官方发布页：https://modrinth.com/mod/Wq7Uh1TY 。该项目官方构建适用于 Forge 1.20.1；NeoForge 代码保留同一套可选桥接，不代表存在官方 1.21.1 修仙构建。

## 处理范围

- 修仙生物与保留该物种来源的感染体使用修仙原生生命单位，不再额外乘黑光的五倍显示单位。正常感染的 1.4 倍基础生命强化和后续器官、进化成长保留，不对所有境界强行设置统一血量上限。
- 已有感染体在加入世界时迁移生命单位，保持当前生命百分比；原版生物与黑光玩家的生命单位不变。
- 转换时读取修仙公开的近战计算接口，保存可继承的攻击增益；旧版没有完整接口时，回退到公开的功法攻击或原攻击属性。不会复制陌生模组的整份能力存档。此前已经丢失的功法数据不能从旧感染体中凭空恢复。
- 让黑光原生真伤跳过修仙 NPC/妖兽独立的灵气护盾与固定防御回调。仍执行其他伤害监听器、玩家护盾、行政无敌和修仙实体自身的剧情/阶段检查，不直接改血或强制取消死亡保护。
- 修仙玩家同时感染黑光后，将来自这类感染体的原有伤害预算移到修仙固定防御之后结算，消除两个 HIGH 优先级监听器注册顺序造成的归零风险。没有增加强制最低伤害，也不取消真正的护盾与免疫。

## 服务端配置

进入世界后生成在该世界的 `serverconfig/blacklight-combat-server.toml`，不是游戏根目录的 `config`。独立服务器由服主管理；单人游戏为 `saves/<世界>/serverconfig/`。

```toml
[cultivationCompatibility]
nativeHealthUnits = true
inheritMeleeBonuses = true
nativeTrueDamageBypassesMobQi = true
budgetAfterPlayerDefense = true
```

真伤桥接同时尊重既有的 `externalOffense` 和 `externalTrueDamage`。关闭生命单位兼容会恢复原单位，迁移仍保持生命比例。更换 JAR 后重启游戏/服务器；首次新增的设置由加载器自动补齐。

## 验证方法与边界

`src/cultivationTest/` 是需单独安装官方修仙 JAR 才能运行的真实联测，不进入发行包。测试涵盖 NPC 功法继承、妖兽攻击、生命单位与旧存档迁移、原版生物、护盾开关、两种合法监听器顺序，以及无敌和领地拒绝伤害。具体通过的修仙版本与运行日志见本次交付目录的验收记录。

测试角色需先完成修仙初始身份选择。该模组对尚未选择身份的新角色提供临时保护，不能把这种正常保护当成黑光伤害失效。

本适配不等于将全部法术 AI、任务状态和修仙修炼系统搬入感染体。不存在对所有历史版本、非官方修改版或整个第三方整合包的无条件兼容保证。

## 修仙玩家攻击感染修仙者（2026-11-01 专项对照）

`CultivationIncomingGameTest`、`CultivationOnsetDefenseGameTest` 使用未感染黑光的修仙玩家、真实修仙剑和飞剑实体测试来袭方向，同时对照感染初期和完成转换后的 NPC。官方 0.2.106／Forge 47.4.10、0.1.1532_server／Forge 47.4.26 分别通过全部 10 项兼容测试。

感染初期的原生 NPC 仍有原来的灵气盾，可出现零生命损失但实际消耗灵气；清空灵气后可以掉血。完成转换及成熟后的黑光宿主可正常受到持剑／法术伤害。连续攻击耗尽黑光限伤窗口后允许暂时为零，窗口结束后恢复；不能把此现象当作永久免疫。具体反馈仍需区分感染阶段、攻击方式、配置和版本。
