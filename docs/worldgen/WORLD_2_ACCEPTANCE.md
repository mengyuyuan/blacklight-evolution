已生成的旧区块不会自动改写；复测使用独立新生成区块。

## 性能记录和验收边界

1920×1080、视距 16、模拟距离 5、限帧 120、Java 堆 3 GiB，RTX 3060 Laptop / i7-10870H。
最终轮城市加载后的静止抽查约 103–119 FPS，跨区路线临近终点截图 109 FPS、终点 119 FPS。
初始加载和维度切换时也观察到 45–98 FPS；这些是 F3 瞬时读数，未采集逐帧最低值或帧时间分位数，不能承诺锁定帧率。

最终轮 JFR 的城市阶段共有 325 个 `minecraft.ServerTickTime` 周期样本：
平均 tick 时长样本的中位数 6.76 ms、P95 44.53 ms；路线时间窗内 33 个样本的中位数 15.16 ms、P95 48.19 ms。
最大平均 tick 样本 154.08 ms 出现在首次远距离传送到路线起点时，说明冷加载仍有短时峰值。
这里统计的是 JFR 提供的平均 tick 字段，不能当作每个 tick 的延迟分布。
最终轮最大 GC 停顿 92.873 ms，日志 ERROR/FATAL 为 0、`Can't keep up` 为 0。
world.1 的 2.411 秒告警本轮未复现；不能宣称已证明所有机器和所有场景都无卡顿。

结论：本轮低洼城区/道路地表、地标轮廓、抽查边界、640 格移动加载、信标往返修复验收通过。
未覆盖多人长时间压力测试、全深圳逐栋与全海岸视觉验收、完整道路平整施工、建筑室内精修、Forge 1.20.1 移植。
远离映射城市用地和道路的低海拔地带仍可能需要海岸精修；本次不是全市实景美术完工验收。
