## 可复现命令

```
./gradlew.bat -PcityTest test build --offline --max-workers=2
./gradlew.bat -PcityTest -PgameTestRunDirectory=<isolated-directory> runGameTestServer --offline --max-workers=2
```

普通服务器使用独立目录，绑定 localhost，信标测试之外通过 RCON 检查维度与持久化。
没有控制桌面鼠标，没有打开用户原存档。
