# 黑光维度：深圳首发与世界地图扩展

当前用户决定（2026-10-15）：
- 已合并两版城市/腿部/性能修复 PR #47 / #48。
- 独立维度正式名称为「黑光维度」，后续扩展世界地图；深圳是首个真实地图区域。
- 地形数据内置模组，玩家不另装地图、不在游玩时下载城市数据。
- 先完成 NeoForge 1.21.1，再移植 Forge 1.20.1。
- 保留旧 blacklight:city 维度，新维度使用稳定的 blacklight:world ID。
- 固定以福田样板为坐标原点的米制投影，精修核心可以原位置接入。经度差归一化到 [-180,180)，未来全球横向坐标仍在原版世界边界内。
- 城市边界、地形和道路来源固定并记录哈希；通过离线构建生成紧凑的分区地理数据，运行时只解码附近数据并生成请求区块。
- 不把 OSM 缺失的建筑高度、内部装修误称为真实测绘；完整覆盖与逐栋建筑精修分开验收。

实施顺序：行政边界/地形/路网和建筑数据提取 → 独立维度生成器 → 福田核心接入 → 街区居民/感染玩法 → 服务端生成与存档测试 → 客户端视觉验收 → Forge 移植。

来源：Geofabrik Guangdong 2026-10-14 OSM 提取，OpenStreetMap contributors / ODbL 1.0；地形计划采用 AWS Terrain Tiles（Mapzen，USGS/NOAA 数据来源）。原始源文件留在工作目录外，不进入模组仓库。
