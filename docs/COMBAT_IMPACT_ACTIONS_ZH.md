# 战斗动作、打击反馈与受击物理

本轮在原有动作片段上做接触反馈。判断一次攻击，先看出招，再看碰到哪里、目标哪一处先受力，最后看身体和溅出的血落到哪里。轻击、续段和重击各有分量。双版本沿用同一套规则。

## 试玩时值得看的动作

| 动作 | 画面、声音与身体反应 | 验收方法 |
| --- | --- | --- |
| 利爪三连 | 每个爪刃沿自己的切入方向拉出窄血线。同一刃的重复采样合并，分开的爪痕最多三路，后两路较轻。 | 靠近浅色墙连续轻击尸壳，看第三段的致死反应和墙地落点。 |
| 刀刃往返斩 | 血沿刃口运动方向甩出，回刀时方向随之改变。切口处叠一层撕裂声。 | 连按前两刀，侧看伤口、飞散方向及回身时还在下落的血滴。 |
| 鞭拳与肌肉强化 | 鞭梢接触留下窄、快的斜向喷溅。强化拳把冲击沿出拳方向送进身体，重拳的接触声更低。 | 用同一站位分别试鞭拳第二段、强化拳与接踢，观察上身如何受力。 |
| 锤拳与徒手 | 锤拳落点形成宽而低的飞溅，砸地沿用脚下实际表面的碎屑和音色。裸拳留下紧凑的短促反馈。 | 分别砸石、木、金属、台阶和空边，再比较击中软体与骷髅。 |
| 肩部骨刺 | 中心重刺在模型能解析出两个表面时产生出口，轻刺留在入口。齐射的侧刺更轻、更安静，命中关节继承该支刺的方向。 | 原地打一轮快重，再试轻接重、跳射和满蓄齐射；从斜侧面观察刺、受击姿势和落点。 |
| 盾与装甲 | 盾面正撞集中在迎击点，斜撞的反弹及火星沿表面偏移。装甲从实际命中点反馈。 | 正面接一击，再让敌人从斜侧打到同一面盾。 |
| 抓取、吞噬与终结技 | 吞噬按现有受击关键帧出血；撕扯有更长的脉冲，胸口吸收向持有者收拢。地刺向上穿，触须沿缠击方向，临界痛楚与高空坠击有各自的接触强度和散布。 | 用活目标观察抓取、接触、死亡和收尾；释放终结技时观察范围内真实受击者。 |
| 布娃娃、二次碰撞 | 击中关节、武器扫速和身体体积一起决定局部冲量。斜抛撞墙会保留沿墙速度后下落；撞墙、落地和波及旁人分别确认。 | 把目标斜掷向墙，再试墙边另一个目标与空落点。 |

## 逐项验收

- [x] 双版本逐条执行下表中的招式命中入口。使用真实服务器生物确认掉血，检查反馈调用和数值有限性。此项不替代每招的完整按键回放。
- [x] 客户端经按键入口回放锤拳、利爪、刀刃、鞭拳、强化拳、徒手、肩部骨刺。记录动作编号、生命、射出侧、投射物、音效和血迹；另录防御与特殊动作。
- [x] 区分裸露软体、局部铁甲、铁傀儡、骨骼和雪；同一目标裸露顶部与金属胸甲分别检测。重击金属有金属声，骨面和雪面有各自的干接触声。
- [x] 核对遮挡、锤拳无支撑面、近处与远处目标、骨刺连续命中、二次墙碰及专服部位锁定。移动、跳跃和车辆交互进入相关回归集。
- [x] 控制密集场面开销。新增接触血滴每客户端每游戏刻上限 48；全场共用 768 个活动血滴、256 处血迹。落迹沿碰撞面裁边，支撑方块变化后清理。

## 测试与证据

- **NeoForge 1.21.1**　330 个相关单元用例，33 项专服 GameTest。实机利爪三连片段新增 7 次软体接触反馈，活动血滴峰值 213。骨刺连招片段新增 11 次。铁傀儡与骷髅观察窗分别新增 0、0 次软体反馈。另录到盾牌 2 次和装甲 2 次独立受击状态。
  地刺墓场的独立实机回放中，服务端招式状态累计确认 6 个命中。
- **Forge 1.20.1**　330 个相关单元用例，33 项专服 GameTest。实机利爪三连片段新增 6 次软体接触反馈，活动血滴峰值 203。骨刺连招片段新增 11 次。铁傀儡与骷髅观察窗分别新增 0、0 次软体反馈。另录到盾牌 2 次和装甲 2 次独立受击状态。
  地刺墓场的独立实机回放中，服务端招式状态累计确认 6 个命中。

同一拍的多爪与出口能产生数路反馈，一次软体接触计数不等于一次扣血。活动血滴和墙地印迹是客户端场景存量，包含此前尚未消退的痕迹。影片使用独立测试存档的真实游戏画面与游戏混音；服务器记录、按键、材质计数及成品 SHA-256 在同目录的验证压缩包中。
