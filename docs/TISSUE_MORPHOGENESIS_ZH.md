# 骨架驱动的黑光器官生长

NeoForge 1.21.1 默认使用程序生成的器官和宿主局部重构，不再用感染牛专用模型充当通用引擎。`TissueMorphogenesis` 不读取物种名称、实体注册表或动物模型资产；输入只有骨骼语义、原生立方体边界、静态关节位置和朝向。

用户已明确认可 r9 的造型方向。本轮后续工作保留这套轮廓、配色和非对称结构，重点完善连接、动态与不同原生体型的覆盖，不重新替换整套美术方向。

这是一套有规则和器官类型的生成器，并非无限制生成任意造型。它生成肌束、背部甲壳、触须腺体、爪/刃、头骨与独立下颌；与专门美术制作的单只角色仍有质量差距。没有宣称所有模组的任意渲染器均已适配。

成熟覆盖以深灰甲面、暗红肌束与裂隙区分，保留有限原皮肤。收窄倒角避免每段都像圆肿包；没有通过增加海量小方块提升“精细度”。共享 128×32 图集由 `tools/build_tissue_atlas.py` 生成，旧牛参考导出也调用同一材质源，避免覆盖回旧条纹图。UV 保持每模型单位约一个材质像素；退化的原始倒角使用成熟法线选投影面，投影限制在原生 UV 面内。

## 骨架、成长与动作

- `ProceduralTissueBlueprint` 读取实际 ModelPart 树，以完整路径区别同名子骨骼。初始变换把上、前、右转换到骨骼局部空间。支持 HierarchicalModel、已有的原生根接口，以及 HumanoidModel / AgeableListModel 路径。
- 优先使用身体、头、臂、腿、尾等语义；陌生名称按体积、长宽比和关节相对位置推导身体中心、头与肢体。颈部和口鼻是头部的连接区域，不生成多套下颌；鞍具、缰绳、外衣等不作为器官基体。
- 从真实立方体表面生成同拓扑的五份形状键。前面三份保留已认可的初期、中期和成熟造型；后面两份增加重度及古老增生。初期恰好组成原始长方体，后续在关节之间增加肌肉质量和方折面，保留端部连接。主导前肢发生更明显的非对称增生，没有整体放大宿主。
- 额外器官从部件表面长出。着地四肢的趾爪沿地面伸出，普通手臂和横向节肢依其自身方向生长。背部甲壳有实体厚度；触须出口与生成腺体的位置一致。
- 同一头部骨骼内的大块次级几何体（例如狼的口鼻）也可独立覆盖。主几何体仍负责颅骨和下颌，次级表面只生成覆盖，不再长一套嘴或攻击器官。用 `cubeSlot` 绑定实际原生几何体，按区域而非仅按骨骼保存本帧待绘内容；小于主块体积 12% 的耳、角等细节继续保留。所有次级区域仍共享 16 区域/1,600 面预算。
- 头骨、下颌与獠牙按实际头部尺寸和朝向生成。下颌独立开合，所有组织继承本次真实原生姿态，不写入共享模型的持久旋转或位置。
- `TissueMotion` 从世界绝对时钟、UUID 及已有服务端攻击阶段采样二级动作。呼吸不依赖实体刚进入视野时的本地 tick 计数；蓄力、接触、收回之间连续过渡。每次渲染只缓存四组局部成长阶段的动作状态，原生皮肤和组织渲染两遍复用同一状态。
- 软组织仅围绕截面自身中心轻微脉动，皮肤两端关节和接地截面固定，腺体的根截面固定；甲片、肋弓、骨刃不使用软组织脉动。不会整体缩放或推动宿主。
- 手爪与着地趾爪使用不同铰链方向。趾爪攻击时轻抬，根轴按前、上方向转换到真实骨骼局部空间；每个爪根的关节坐标与其生长截面一起变化，避免继续绕旧的统一关节卷入地下。
- 沿用服务端保存的组织年龄与宿主 UUID。存取档、帧率、更换观察者不会重新抽取外形。

## 性能与材质

每种原生模型最多缓存 16 种稳定的拓扑/比例组合，不逐帧重建。每个宿主另有按完整 UUID 计算的显露时序。每份计划最多 16 个骨骼区域、1,600 个源四边面；零厚度面、细碎装饰和超出通用坐标预算的部件跳过。

使用已有 128×32 材质图集；未覆盖区域保留投射后的原生皮肤 UV。新组织保留渲染透明度，但不继承羊毛染色。羊毛等独立外层使用同一表面变形，不再生成第二套爪和腺体。

不增加附着物实体，不随成长提高最大生命或攻击数值，也不再沿用旧牛样板专属的大碰撞箱。

## 成熟后的增生

生物保持加载时，沿用原来的服务端组织年龄继续累积。没有新建实体或重抽变体，卸载期间不按现实时间补长。

| 加载时间 | 组织年龄 | 外观阶段 |
|---|---:|---|
| 约 10 分钟 | 12,000 tick | 原来的成熟造型 |
| 约 20 分钟 | 24,000 tick | 重度增生 |
| 约 40 分钟 | 48,000 tick | 古老增生及本轮上限 |

`TissueGrowth.progress` 保持旧的 0–1 定义，防止原有覆盖和动作重复播放；独立 `overgrowth` 在后续两个区间连续插值，阶段连接处速度归零。旧存档中 12,000 tick 的成熟年龄仍是原值，加载后从这个进度继续。

`TissueHypertrophy` 增加肩背、肋弓、主导肢体、颅颚及爪刃的局部形状键。皮肤端部保留骨骼连接，着地器官沿支撑面伸长；背部硬质甲片和后掠骨刃保持自己的轮廓，埋入身体的根部跟随增生后的肩背。腺体按截面变形，其出口与攻击触须共用同一份后续坐标。

用户否定了最初后期器官过长、宽厚度不足的比例，也进一步指出不能把单轴拉长改成单纯强调加宽。当前按连接处、器官主体和末端协同发育：连接处先增生，主体肌腹随后形成体积，末端的伸展和弯曲再逐渐展开。三份旧形状键不变。

`TissueHypertrophy` 的两份后续形状键分别采样这三个连续生长过程。躯干的两个截面方向与内部中心线共同变化，头、髋关节的连接截面保持稳定。肢体的肌腹、掌根和对应转轴使用同一个局部组织变形；头骨、下颌、腭和牙根共用头部变形。骨甲、肋弓、腺体沿宿主的增生表面发展，独立爪刃及背部骨刃使用根部截面约束伸展长度，并产生小幅弯曲。着地爪保留支撑高度并轻微分指，横向节肢不会再被误用竖直腿的接地约束。

每份生成计划的稳定种子同时参与这套发育参数，差异作用于连贯的器官与组织关系，不逐帧随机。所有比例都在真实骨骼局部空间计算，不是整只宿主的缩放，也不扩大原生碰撞箱。已有的五形状键、16 变体、共享材质与面数预算保持不变。

既有成熟形状键和面索引不改写。只是多存两份顶点/关节坐标，没有增加面数、材质图、渲染遍数或变体缓存数量；额外形状键会增加少量缓存内存。旧的三形状键参考资产继续停在成熟造型。原生碰撞箱、最大生命及每次攻击伤害不因本轮增生提升。触须长度最终为原成熟值的 1.6 倍、半径为 1.5 倍，服务端实际攻击距离跟着同一年龄增长，保留蓄力、视线检查、一次命中及自然收回。

## 攻击与同步

沿用感染宿主的服务端近战和触须攻击：成熟组织获得触须距离，经过蓄力、一次命中与完整收回，检查视线、距离和目标有效性。生成的爪和下颌跟随挥击；网格数量、客户端帧率不会造成额外伤害。

没有增加客户端伤害判定或新的同步字段。所有观察者使用原有 UUID、组织年龄及攻击状态计算外观。

## 兼容边界与旧样板

普通 ModelPart 模型可以直接使用生成器，陌生名称有几何推导，但不等于全部第三方模组已经联测。GeckoLib、自定义 GPU 网格、多部件 Boss 没有走这条管线，继续保留原有路径；需要另接骨骼读取适配器。生成数据无效或没有可用骨骼时回退。

旧感染牛 JSON / Blockbench 工程保留作美术对照，开发参数 `-Dblacklight.authoredCowTissue=true` 可显式查看，默认关闭。普通安装不需要额外动物模板。

Forge 1.20.1 尚未移植本轮生成器。本轮没有自动发布或合并。
