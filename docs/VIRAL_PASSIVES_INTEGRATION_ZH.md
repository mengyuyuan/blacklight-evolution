# 病毒聚合体与被动系统双版本整合

同步跟踪：[Issue #44](https://github.com/mengyuyuan/blacklight-evolution/issues/44)。本次先提交评审，不代表已合并或发布。

## 范围与来源

- 基于当前对应版本主线：NeoForge `f504a72`、Forge `585f0d5`。保留已合入的抓取、地形投掷、感染属性范围与疾跑默认值修复。
- 聚合体来源：NeoForge `7ce14cb`、`5b42865`、`ab0b9a8`；Forge `38fed26`、`b1b6fdb`、`945cdc8`。部分最初碎裂逻辑已在主线，仅补入尚缺的实心碎块、路径拖尾、地面残迹与命名，不用旧分支覆盖主线其他文件。
- 被动来源：NeoForge `695af46`、Forge `c92ee31`，保存另一会话完成的适应性、组织再生、技能升级、永久药水、HUD、存档及同步实现。
- 中文界面统一使用“病毒聚合体”和“病毒稳定性”；保留内部注册名、存档字段及游戏规则 ID，避免仅为改名破坏旧存档。
- 视觉由 Java 几何与程序像素素材生成，可编辑源代码保留；此次不替换既有动作、武器或盔甲资源。

2026-10-15：双版本离线 `assemble` 均成功，构建校验确认原有 252 个动作/配置资源未变化。已检查全部资源 JSON 可解析、中英文键与格式占位符一致；按准确版本名打开两个 bundled JAR，确认全部顶层源码类均已打包，新视觉类、药水/图标/配方和新文案存在，未混入私有 QA 模组。本轮未重跑单元测试、GameTest 或启动用户游戏。
