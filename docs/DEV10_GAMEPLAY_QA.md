# dev.10 俯冲、第三人称与设置修正

本轮对应用户在 dev.9 的实机反馈。dev.9 的 59 项单元检查、17 个技能用例和旧地形消除检查属于历史记录，不能证明本轮新增掉落或联机已通过。

## 行为

- 子弹俯冲以服务端真实最高位置至接地位置的落差结算伤害、材料能力、坑宽、坑深和能量；没有额外的固定高度或威力上限。视野和特效强度可有视觉饱和，不能反过来限制伤害或破坏。
- 地形使用 Minecraft 原生破坏与掉落，箱子内容按原生移除路径处理。`doTileDrops` 控制原生方块掉落；原版箱子库存散落不受这个规则控制，本 Mod 也不另行吞掉库存。基岩、世界边界、未加载区块、交互权限与第三方逐块保护仍有效。
- **U → 设置 → 子弹俯冲 · 方块破坏**，默认开启。服务端保存玩家自己的选择并同步；关闭保留伤害和冲击表现，取消尚未完成的地形任务。设置随存档保存并在死亡后保留。
- 全服共用每 tick 的候选数、真实破坏数与耗时预算，预算限制处理速度。每位玩家同时最多一个地形任务；新的有效俯冲取代自己的旧任务。
- 补充真实 FLIGHT 阶段的三维气流、骨点组织尾和渐进世界视野。尊重用户效果选项，保留 F5 与鼠标自由观察，原生第一人称手臂投影不被世界 FOV 改动。
- 播放时钟改为纯采样，身体渲染使用本次渲染的 partial tick。跑步和俯冲后处理保留场景深度、还原绘制状态并重绑主缓冲；资源重载后重建。
- HUD 只保留红血后方的蓝色临界储备，移除额外的临界质量数字。地刺主根约为旧版的 3.8 倍宽，尺寸依据见 [比例文档](SPIKE_PROPORTIONS_DEV10.md)。

## 本轮验证记录

生产代码编译及 13 个测试类的 60 项定向检查通过（0 failure/error/skip）。资产生成另有 5 项 Python 尺寸/拓扑检查通过。最终 17 个原生技能用例、20 项实际临界健康事件与新增地形掉落检查通过，报告没有 violations。

真实地形 helper 顺序验证 12 格破 8 块、80 格破 229 块，箱子本体只掉落 1 个、两个格子的库存合计准确掉落 6 颗钻石，土块掉落 227 个。逐块保护区域破坏 0 块；关闭设置不建立任务；同 tick OFF → ON 仍取消旧任务；`doTileDrops=false` 的纯土块区实际破 236 块且无新掉落实体。基岩保持，测试清理仅在完成区域验证并实际写入后执行。

80 格真实 FLIGHT 在纹理柱旁观察到世界气流几何和实际 FOV 增大；四个高度都有真实几何/FOV记录，2000 格前段仍以天空为背景，不用它冒充近建筑体验验证。总 16931 个真实渲染帧，活动效果帧 p95 间隔 12.1466ms，总体 p95 为 13.0794ms，均包含取图开销；不是独立专服 TPS 或多玩家压力基准。

爪子跑步、完整稳态装甲、跑中蓄力、飞行与烟后落地共五组各 16 张实际帧图；站立原生 Space 蓄力、飞行、落地三组各 16 张。实际渲染模型的手脚矩阵有限、没有缩放翻转，同 tick .8/.2/.8 查询不改已提交时钟；两套最终断言通过。图组是两段连续短取样，不是整段录像。可见区域未发现整肢突然消失；站立落地的前方测试木偶遮挡腰与远手，不能认证被挡住的接缝。图审为助手检查，不是用户真人验收。

旧爪子 v1 的写图阻塞与站立 v2 错用移动落地断言的失败记录均保留；修正为后台写图与独立站立蓄力断言后重新执行，没有将旧失败改为成功。

独立服务端与真实客户端使用两个 Java 进程，在仅本机可连接的 127.0.0.1:25568 启动、登录及协议协商成功。服务端报告 `dedicated=true`，未出现客户端类加载错误。真实 `SkillSettingsPayload` 经生产处理器执行 OFF → ON → OFF；服务端附件、玩家 `.dat` 与客户端同步回执一致。默认 true 在 Codec 中可存为 `{}`，以实际 Codec 解码核对，不能把缺省字段当作 false。

## 适配边界

《虐杀原形》没有 Minecraft 方块和掉落表；高度、材料、坑形与分批算法属于明确的 Minecraft 适配。源文件用来核对动作、释放、接地、组织回收和镜头依据。新特效几何为项目原创，未将私有 FX 网格或贴图复制进运行包。

本轮本机连接检查不能代替多玩家压力、高延迟、完整生存或用户真人体验验收。
