# 九头蛇双向入口与一代生物收口

适用：NeoForge 1.21.1 / Java 21、Forge 1.20.1 / Java 17。本轮版本号 `0.3.4-dev.12-hydra.1`，仍是开发候选版本，不代表已经完成所有整合包和双客户端联机验收。

## 生存流程

1. 击杀蜂巢核心获得一个活性蜂巢组织。对黑光维度以外的坚固方块上表面使用，附近 8 格不能已有九头蛇。
2. 根部先表现为脉动的组织囊。引来 5 只可被正常杀死的生物喂养；命名生物和宠物必须由种植者牵引。死亡被取消不计数，玩家不作为饲料。
3. 至少累计 2 分钟实际加载的生长时间（喂食动作不计入）。周围感染最多半径 6 格，每秒最多替换 2 个表面方块；关闭 mobGriefing 或 infectionSpread 仍能喂养成长。
4. 成熟后完整九头蛇从地下钻出。目的地区块准备完成后，种植者靠近触发：低头 → 双角夹起 → 下潜 → 黑光维度出土 → 抛出 → 收回地下。
5. 到达端是持久保存的配对九头蛇。走开后再靠近，或右键重新请求，即可通过同样的夹持、下潜、出土和抛出动画返回原入口。无需领取或使用信标。原有调试旅行指令保留，但不承担生存闭环。
6. 潜行可避免自动捕获；夹持中潜行、九头蛇受击或消失会中断并放回安全地面。两端配对记录维度、方块位置和实体 UUID；目的地丢失或被占用时安全失败，不复制传送器。

普通怪物九头蛇负责战斗，种植九头蛇负责喂养和传送，不运行野生攻击 AI，也不能被吞噬。所有九头蛇共用出土/钻地基础片段。野生九头蛇、传送器使用 1.6–2.4 随机体型并保存，目标端继承源端体型。

## 动画与固定镜头

九头蛇动作表重定向自本地一代解包的待机、hyd_enter、hyd_exit、hyd_grab_concrete、hyd_ped_toss 和攻击片段。持物阶段叠加双角夹持；服务端夹持位置与客户端蒙皮采样同一动作表。完整网格包络检查确认出土首帧、钻地末帧均完全在地面以下。

玩家不用原版骑乘关系或坐姿。采用已有受击/下落动作加护身、悬垂、双手 IK 与抛出过渡。这部分是 MC 配对适配，不冒充已经找到原版专用受方动画；抛出时点和喂养/维度机制也属于适配。

每个出发/到达场景只选择一次固定世界机位。机位沿九头蛇周围选择无方块遮挡的方向，保持位置与朝向，不跟随玩家或角颚钻入地下；夹起到收回期间暂用第三人称，结束、中断、死亡或退出世界后恢复原来的视角。镜头仅属于该次传送玩家，旁观者不被强制切换。协议升级为 `standalone-20-hydra`，同平台服务端与客户端需一起更新。动画期间持续刷新目的地区块凭证，避免成熟出土接夹持、钻地后凭证过期。

猎手为连续蒙皮模型，保留原动作重定向和骨骼校准，接入挥击、连续抓击、扑击、砸地和侧闪。调整只针对玩家与猎手交战，玩家升级仍提高伤害。轻跳闪避默认独立按键 Alt，也支持快速松开疾跑键；普通空格短按仍为跳跃。墙跑采用脚底朝墙的地面奔跑坐标，松开疾跑可转攀爬。

## 资源与验证方法

模型可编辑文件、骨骼检查及生成工具分别位于 `art/creature-connected`、`art/hunter`、`art/hydra` 和 `tools/`。原始游戏解包、私人中间数据、测试世界及日志不进入安装包。模型约为九头蛇 1125 顶点 / 2132 三角形、猎手 2649 顶点 / 5186 三角形。来源说明见 `THIRD_PARTY_ASSETS.md` 和 `CREATURE_COMBAT_SOURCE_AUDIT_ZH.md`。

`-PhydraReleaseTest` 启用独立服务端 GameTest；`-PhydraVisualTest` 启用隔离新世界实机流程，自动击杀蜂巢、使用真实掉落、实际喂养五只生物、等待自然成熟并往返。自动测试不会操作已有玩家地图。隔离 GameTest 的维度集合由测试预设决定；维度往返另由正常客户端/集成服务端实际验证，不能用单纯的函数断言替代。
