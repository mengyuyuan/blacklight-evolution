# 呼吸与循环器官

目标范围内的第三批持续供养器官，NeoForge 1.21.1。不是新的玩家被动、永久免伤或免费回血。

## 各器官实际作用

| 稳定 ID | 结构和作用 | 代价与限制 |
|---|---|---|
| `gill_lamella` | 头侧连入式鳃盖与鳃片；原生水生宿主提高交换，陆生宿主获得水下交换 | 后长出的鳃每次支付 1 养分，供给 `200 + 20×强度` 个实际加载 tick；空养分且剂量耗尽后继续消耗空气 |
| `bronchial_lung` | 胸腔双肺与同一身体表面起伏；增加真实空气容量、空气补充速度和工作储氧 | 不会因此在水中呼吸；受伤降低有效供氧，不能无限潜水 |
| `avian_airflow` | 接入躯干的长气囊；真实移动时提高交换和储氧恢复 | 静止时没有运动交换加成；仍需空气，不能替代鳃 |
| `book_lung` | 躯侧薄层书肺与开合通气面；干燥静止时交换效率较高 | 运动时失去静息加成，身体浸水时失去干燥通气加成 |
| `tracheal_network` | 两侧通气带；头部淹没但下部实际通气点仍暴露在空气中时可继续交换 | 每份通气剂量支付 1 养分；完全淹没不生效，大体积降低扩散效率，主心泵可缓解 |
| `main_heart` | 连入躯干的主泵与同场体表脉动；缩短普通攻击、器官动作间隔及既有受伤修复等待 | 一次强化恢复支付 1 养分、18 工作储氧；只缩短等待，保留前摇、接触帧和收回动作；伤势降低泵压 |
| `branchial_heart` | 成对小泵；实际水中交换时增强交换并支持强化恢复 | 陆地不提供普适恢复加成；强化恢复仍支付养分和工作储氧 |
| `splenic_reservoir` | 有有限充盈与收缩的储血囊；危急缺氧或循环不足时释放已存资源 | 静息、可交换且储氧至少 65 时，累计 200 tick，再支付 1 养分与 30 储氧充入一份；容量 3–8 份，每份缺氧救援最多补 80 空气；没有初始免费储血 |

`gill_raker` 仍是上一批真实食物的滤食器，和本批负责呼吸的鳃片是不同器官。
“工作储氧”只用于组织出力和恢复，不是生命值或营养；伤势会降低供给并留下循环负担。
循环负担只在现有、已支付养分的组织修复中逐渐减轻。

## 接入与保存

- 宿主感染时记录实际来源的水呼吸、空气呼吸和空气容量。海豚保留 4800 空气容量及空气呼吸；普通鱼保留水呼吸，不能因感染直接在陆地无限呼吸。
- 旧存档缺少这些字段时，从保存的来源实体类型读取原生特性。不会重新随机器官、增加养分或凭空填满储血。
- 鳃/气管剩余剂量、工作储氧、储血份数、充血工作进度和循环负担均保存。卸载和读档不推进计时。
- 仅本模组的普通替换宿主使用此呼吸逻辑；不修改其他模组生物的呼吸事件，也不接管多部件 Boss 或吞噬体的专有逻辑。
- 既有水下呼吸保护可阻止空气消耗，但本系统不会把外部保护伪造为氧气生产。
- 身体、表面感染层和器官根部共享一个有限形变场。上下接缝固定；多个器官不叠加多个躯干，不向每条腿复制内脏。
- 普通专属感染体、通用宿主及真正替换了供体上半身的聚合体，都使用实际挂点和相同时间基准；鳃、书肺与支鳃泵的视觉活动跟随真实交换环境。
