# 锤拳普通攻击体积调整

目标：Forge 1.20.1 dev.12、NeoForge 1.21.1 0.3.4-dev.4。

前三段普通拳击原缩放峰值为 2.5，映射到现有大拳套后过于夸张。仅对 hammer_jab、hammer_hook、hammer_combo_c、hammer_combo_d 增加 basicGrowthStrength=0.3：保留原大小，只将超过 1 的增量保留 30%，前三段峰值变为 1.45，第四段约 1.25。不是把整个武器缩小到 30%。这是项目外观调校，不宣称为原版倍率。

对应蓄力曲线在起手阶段使用相同强度，之后平滑过渡到原来的蓄满尺寸，避免短按普攻也先冒出巨拳。完整蓄力攻击、地面重砸、空中重砸、冲撞、特殊连击和其他武器曲线保持原样；伤害、判定、身体动作、模型和静止尺寸不变。

可编辑参数位于 art/weapon-attack-scales/stages.json，由 tools/export_weapon_attack_scales.py 生成，共享资源与清单同步双版本。

静态核对：49 段中仅四段普通攻击和四段蓄力曲线改变，其余 41 段逐项一致；所有身体采样时钟一致，蓄力终点与原曲线一致。未运行游戏测试或实际观感验收。

两版 assemble 均通过；各自安装 JAR 中的 252 项动作／配置资源通过大小和 SHA-256 核对。
