# 主导器官与吞噬研究（NeoForge 1.21.1）

## 本次实现

用户确认随机进化应为每只生物形成一个最强的主导器官，并要求把这些宿主接入主角吞噬与进化收益。本轮覆盖普通随机组织宿主；旧多段 Boss、吞噬者专属系统保持分开。

主导器官从完整 UUID 派生的持久种子选择，五个方向为肌束、甲壳、颅颚、抓握、肩背骨冠。同种生物可以不同；同一生物后续每代保持主导方向，辅助器官与局部比例继续平滑变化。客户端、观察者和存档重载使用同一算法。旧版曾每代重选主方向，本轮按用户最新要求替换这一规则。没有给五种主导器官各自新增一套完整攻击 AI。

## 吞噬条件与表现

- 原通用抓取流程保留。未成熟宿主继续遵守原有最大生命/虚弱规则；组织成熟后（12,000 加载 tick）即使基础生命很低，也需降低至 15% 以下。
- Ⅱ级以上主导器官（年龄至少 240,000 tick）的宿主，需要先打破保护组织并降至 10% 生命以下。保护组织完整时，甲壳主导减伤 35%，其他主导减伤 15%。累计实际失去自身最大生命的 50% / 30% 后破裂；拒绝的伤害、吸收抵消的伤害及直接改血不会积累破裂。破裂值同步、保存；破裂时出现组织粒子。
- 这是保护组织耐久机制，不是为每个随机网格新增独立可瞄准部位。现阶段未实现逐块器官断肢或专属破甲模型。
- 人形与粘液共用虚弱条件。粘液不再能跳过大目标的原有虚弱门槛。最终执行仍检查是否真正接受死亡；拒绝执行不结算。
- 继续使用已有抓取、包裹、溶解和回收动画，大小按现有接收者系统适配；本轮没有录制或制作另一套原作动画。
- 锁定普通进化宿主后显示主导器官、样本等级及当前吞噬状态。教程与具体强化说明在技能页，不在行走过程中提示操作按键。

## 资源和样本

基础回血、生物质、进化点沿用普通吞噬算法。随机组织宿主再乘以 `1 + min(2, 0.35 × ln(1 + 年龄 / 12000))`，最多三倍；不从被其他模组任意抬高的生命值无限计算收益。最高样本先提供三阶研究，不限制宿主继续成长和演化。

| 样本等级 | 最低加载年龄 | 首次发现额外进化点 |
| --- | ---: | ---: |
| Ⅰ | 72,000 tick | 40 |
| Ⅱ | 240,000 tick | 80 |
| Ⅲ | 816,000 tick | 120 |

首次直接获得Ⅲ级时补齐未发现等级的奖励，共 240 点；同级或更低样本不会重复给发现奖励，仍有基础资源收益。研究只记录各器官最高样本和已购买阶数，不保存无限增长的受害者列表。单个受害者有服务端结算标记，重复确认/重复重组不会再次支付。

两种吞噬路径共用研究、基础资源和进化点结算。粘液保留原有成功吸收后满血重组机制；本轮也使它获得普通吞噬的进化记录和对应解锁。研究与已买强化通过持久附件保存、死亡复制，并在登录、重生、换维度及更新时同步。

## 器官研究页与强化

吞噬样本开放对应强化，再用进化点购买；三阶分别花费 200、400、700 点。服务端独立检查存活、感染、样本、已购阶数和余额。客户端只发送既有购买意图包。

| 主导器官 | 每阶效果 | 三阶合计 |
| --- | --- | --- |
| 极限肌束 | 虐杀模式直接近战伤害 +5% | +15% |
| 复层甲壳 | 虐杀模式常规受伤 -5% | -15% |
| 吞噬颅颚 | 吞噬回血 +10%，生物质 +5% | +30% / +15% |
| 抓握触手 | 生物抓取距离 +0.5 格，包含鞭拳抓取 | +1.5 格 |
| 承力骨冠 | 虐杀模式击退抗性 +0.1 | +0.3 |

肌束不提高间接投射物伤害；颅颚不提高进化点；普通模式关闭战斗强化；绕过无敌保护的伤害不额外套用本轮甲壳减伤。本轮没有按代数持续抬高宿主生命/攻击属性，也没有直接把宿主属性复制给玩家。
