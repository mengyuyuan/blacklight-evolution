# 红黄绿区域与刃臂进化者补完

2026-10-27 开工，范围 NeoForge 1.21.1。基线 `db86052e`；已核对远端主线，无遗漏新提交。

2026-10-27 用户明确清剿依赖另一开发者的 PR。本轮撤出新增击杀降压、清剿转绿、恢复期及对应 UI；原有核心销毁和城市历史兼容流程保留。后续以对方实际事件、清剿任务与结算接口接入，不能提前把清剿算作本轮完成。

## 本轮验收目标

- [x] 同一套街区状态服务主世界、深圳、洛杉矶及其他维度；红黄绿由当地实际感染压力决定，不只看世界天数。
- [x] 摔瓶建立当地起点；活体、成熟宿主、进化者与建筑核心影响压力；红区向相邻已加载区域传播。
- [x] 区域状态保存恢复与多人不会加倍计算；离线和未加载时不补算。原有核心销毁不触发本轮新增的区域奖励。
- [x] 环境、居民、建筑生产共用区域规则与既有出生预算，保留普通感染者作为战斗资源。
- [x] 客户端只读同步区域，简洁显示与技能页显示开关；重登、跨维度不串状态。
- [x] 保留六次成熟吞噬与整合后自然成为刃臂进化者的门槛，不靠随机空降人形替代成长。
- [x] 修复站定待机/戒备停帧与受击向中立姿态回缩；补有限连段、收招空当、追击和真实碰撞限制。
- [x] 单测、实际服务端、原生客户端连续画面通过；动作与地图不删帧、不降精度。

以上是本轮共享接口与已列用例的验收，不等于深圳、洛杉矶全部街区生态均已实地走遍。多人部分测试同批重复位置与重入；尚未同时连接两名真实玩家。

本轮只打磨已有的刃臂进化者，不把预留映射称为八种已实装敌人。清剿等待另一开发者 PR；其余器官、完整原作所有战斗分支与无限城市生态仍分别按总台账推进。

## 区域规则

沿用每 256×256 格街区、稳定城市 ID 及维度独立存档。新增压力以二十分之一单位累计，范围 0–10000，避免低频采样损失小额变化。进入黄区门槛 2000、红区 6000；返回门槛分别 1600、5400，避免边界反复跳色。既有城区感染阶段只作为首次初始化的历史/场景输入，不会每次覆盖动态状态。

统计实际正在模拟的感染生物、成熟宿主、进化者和存在核心方块的活建筑殖群；有供养且出口正常的作者母巢也进入同一统计。红区对相邻实际活动街区提供压力。整批先取邻区快照，再发布结果，不能在同一批里无限串联传播。缺乏感染源时的自然压力变化属于生态采样，不是新增清剿任务或击杀奖励。

世界释放时钟继续只决定高阶种群资格，睡觉或改白天不跳阶段。绿区至多使用早期种群；黄区最多低阶发育种群；红区按世界与当地活动阶段开放成熟、猎手和古老宿主。环境、居民与母巢沿用实际人口、共享出生预留、出口/碰撞和游戏规则检查，不直接生成已集齐六次吞噬的人形进化者。

默认局部人口上限为绿区 8、黄区 14、红区沿用服主原上限 18；配置更低时尊重较小值，不删除超额存活个体。三者的环境生成抽签通过率分别 12%、55%、100%，不是每轮保证出生的数量；仍有六次有限候选、真实地面、24 格玩家距离和人口预算。普通感染者的六个保留名额与后期普通资源权重继续生效。

未摔瓶不启动新增感染进程；重复摔瓶只在当地建立至少黄区级别的起点，不重置世界或街区时钟。主世界、下界、黑光世界及未来城市共用接口。未知城市从当地状态起步，不继承另一城市的清剿/活动历史。维度内仍保留 32768 个街区档案的原预算，不为未加载坐标请求区块。

## 玩家显示与同步

右下角仅显示一个有颜色的区域名称；技能页面的设置分类增加“感染区域显示”开关。开关只保存本机显示偏好，不发起服务器状态修改。区域由服务端发给玩家，仅状态变化时发送；退出清缓存，跨维度核对维度 ID，不在客户端读取服务器 SavedData。

网络握手升级为 `standalone-36-district-zones`，客户端与服务端应一并替换。区域显示不是安全屏障，不会清掉进入绿区的既有敌人。

## 刃臂样板的改动

源 idle、guard 是两帧相同的静态姿态。保留原文件、全帧动作和完整骨架，在静态姿态上叠加每层不到一度的呼吸、重心及头部微动；站定时钟不再依赖步伐或客户端接地标记。子树共享增量旋转，保持关节连接，不逐帧累积修改原数组。

受击姿态混入当前基础动作，不再将整个身体权重往无动作中立姿态缩回。命中后允许左右突刺接回斩，最多三段，完整播放已有动作的攻击与回收区间，再提供收招空当；空挥、脱离距离或丢失视线不追接。受压且闪避已就绪时放弃续段，保留原防御与反击机会。

攻击根位移检查整个扫掠身体的已加载区块，仍通过正常碰撞移动；完整成形的人形使用可漂浮的地面导航。六次亲自完成的成熟吞噬、六份成熟器官与整合门槛、形态选型和存档记录均保留。

## 对接边界

新清剿任务、奖励结算、军事占领及清剿导致的分区回收，等待另一开发者的 PR 后统一对接。本轮没有增加击杀减压监听，也没有改写旧 `clear` 的压力值；原有建筑核心销毁、已清除建筑历史与城市压制档案照旧兼容。

本轮区域与进化者的新增实服夹具放在 `src/buildingTest/`，不会进入发行 JAR。原生界面、身体与动作夹具使用独立强制模拟的测试场和显式六器官样本，不能冒充默认世界的整段自然进化。最终计数、生产 JAR 指纹和原始证据另列验收记录；此前包含清剿实验的 153 项运行已被范围调整后的测试取代。
