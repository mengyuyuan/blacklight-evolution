# 身份收藏与物种能力

适用预览版：`0.3.4-preview.20261023-identities.1`。

进入虐杀模式，吸收普通生物后会自动收藏其身份。轻按变形键（默认 X）切换本体与当前身份；长按 X，滚轮选择「身份收藏」，松开后进入收藏页。选择身份并点击「变成此身份」，会播放变形过程。

收藏页显示生物名称、能力条件、冷却和当前能力按键。能力键默认 Y，可在 Minecraft 按键设置中修改，收藏页与 HUD 会随之更新。

| 物种 | 当前适配能力 | 冷却 |
| --- | --- | --- |
| 蜘蛛、洞穴蜘蛛 | 面向附近实心墙壁，逐段向上攀升 | 0.5 秒 |
| 蝙蝠、蜜蜂、鹦鹉、鸡 | 振翅上升，空中减缓下落 | 0.9 秒 |
| 兔子、青蛙、史莱姆、岩浆怪 | 在地面向前弹跳 | 1.5 秒 |
| 鱼类、鱿鱼、发光鱿鱼、海豚、美西螈、海龟、守卫者 | 水下呼吸、水中冲游 | 1.2 秒 |
| 末影人 | 沿视线短距瞬移，最多 8 格 | 5 秒 |
| 骷髅、流浪者、凋灵骷髅、沼骸 | 玩家归属的实体箭矢，不可拾取 | 1.2 秒 |
| 烈焰人 | 玩家归属的实体小火球 | 2 秒 |
| 苦力怕 | 伤害周围实体的爆炸冲击，保留地形，自身不受此次爆炸伤害 | 8 秒 |

烈焰人、岩浆怪、炽足兽身份还具有火焰伤害免疫。未适配主动能力的物种仍可用于外观伪装，收藏页会明确标注。

能力沿用正常实体命中与保护事件。瞬移检查碰撞、世界边界和区块加载状态；被墙阻挡、空中弹跳等不满足条件的请求不消耗冷却。冷却由服务端保存，在切换身份后继续计时；能力不消耗死亡重生储备的生物质。

最多保留 64 个不同外观，重复吸收相同外观不会挤掉旧身份，满额后淘汰最早收藏。死亡后保留收藏；解除黑光感染会清除收藏。旧存档的当前身份在登录后自动加入。

收藏列表仅同步给本人。客户端发送收藏版本号、序号或能力使用意图，无法提交任意实体 NBT；失效列表、越界序号和当前形态不符的请求由服务端拒绝。单个外观 NBT 经压缩裁剪后最多 512 字节，避免携带大量物品数据的实体撑爆联机数据包。

收藏沿用当前普通生物身份捕获范围；这次没有开放任意第三方生物 AI 或 Boss 数值复制。后续物种可通过 `SpeciesTrait` 与 `SpeciesAbilities` 添加明确适配。
