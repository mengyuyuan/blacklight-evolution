# 黑光击杀收益

已感染玩家在普通模式、虐杀模式击杀生物，默认获得该目标吸收基础生物质与进化点的各 50%，整数四舍五入。拥有归属的远程攻击、TNT 和原版保留玩家击杀归属的延迟伤害也可结算。未感染玩家、其他玩家死亡、无归属的自然死亡与管理击杀不触发。

吸收保留完整基础资源、回血、器官发现奖励、吸收次数与形态/伪装解锁。击杀不会冒充一次吸收，也不会领取吸收专属器官研究奖励。母巢原有的专属击破奖励独立保留，不再叠一次通用击杀奖励。

死亡监听器结束后才在服务端结算；死亡被取消、目标复活或已成功吸收时不重复给资源。多人只发给实际归属玩家；一次范围攻击同一刻的结算合并为每名玩家一次资源状态同步，不额外生成掉落实体。

进入世界后在 `serverconfig/blacklight-gameplay-server.toml` 生成：

```toml
[combatRewards]
enabled = true
killBiomassFraction = 0.5
killEvolutionPointFraction = 0.5
```

单人游戏位于 `saves/<世界>/serverconfig/`，多人由服务器服主管理。原存档无须重建。生物质容量、进化点存储边界沿用原规则。

测试入口为 `combatRewardTest`；发行包排除 GameTest 类。覆盖普通模式击杀、投射物与 TNT、晚到的死亡取消、吸收/击杀互斥、多人、32 只范围击杀与重复回调、服务器开关与独立比例；同时运行原有 8 项器官吸收回归。
