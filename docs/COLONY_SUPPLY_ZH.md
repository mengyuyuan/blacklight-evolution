# 建筑殖群的实际供养

本分项推进总台账 2.1，不代表作者母巢、跨建筑血管、运输器官和完整城市生态已经补完。

## 已接通的资源路径

玩家手中实际食物 / 核心嘴部附近实际掉落物 → 保存的消化队列 → 有限养分储备 → 实际组织建造 / 已加载维护 / 有代价的出生。

- 手持食物交互接入核心方块本身的 `useItemOn`。生存模式每次消耗一个真实物品；汤类返回实际容器。食物使用组件值，兼容其他模组提供的正常食物组件，不按生物或食物名字列白名单。
- 无食物的旧核心不凭空填满储备。时间不能产生养分。核心与宿主共用一个每维度、每 tick 最多 8 次的拾食查询预算；单次最多收集 32 个掉落候选，然后最多尝试其中 16 个。
- 核心只在近距离嘴部收集可见的实际掉落物。射线所经的相邻区块先检查已加载；不隔墙吞物，不调用强制加载，不从远处未接通的组织岛抽取资源。
- 附着物、实体血肉等本系统生成的方块不能反复喂回去产生材料。天然叶类等只通过已有发酵标签接入，仍需真实物品和完整发酵时间。
- 消化使用已有 `TissueDigestion` 的工作和存档机制。殖群具有分布式容积，队列最多 12 份；无胰腺、吸收加成或脂肪的伪造收益。

## 真实开销

| 操作 | 开销 |
|---|---|
| 新表面附着组织 | 1 养分 |
| 新实体血肉单元 | 2 养分 |
| 已有实体形状更新、受损收缩/移除 | 不再收一次建造费 |
| 每 200 个已加载生长 tick 的维护 | `1 + min(4, 实体单元数 / 512)`，向下取整 |
| 初生 / 成长 / 成熟 / 猎手 / 远古出生 | 12 / 20 / 32 / 64 / 120 养分 |

建造先预留材料，保护插件否决或实际放置失败时退回。出生失败不会吃掉生产费用；成功生成真实实体后才记一次出生。
世界和当地阶段仍限制可生产的档位，结构已经成熟不等于可以在病毒刚爆发时提前生产高阶生物。

## 断供与保存

- 空储备暂停建筑成熟、生长和出怪，保留已有建筑结构。旧存档保留结构和阶段，但不会补出免费养分。
- 维护债务不足时也不能绕过维护、把最后几份材料继续用于建造。
- 消化所需工作、待消化份数、实际储备和维护尾数保存。卸载和重进不结算离线时间。
- 重新喂入的物品完成实际消化后恢复有代价的生长。清剿历史、切断单元、原地禁止重种和保护区规则继续生效。
- 核心空手交互提供阶段、实际养分与待消化数量；不新增常驻调试 HUD。
- 核心正前方保留两格深、两格高的喂食位置。旧结构堵口时，只按共享工作预算清理自身血肉；不拆除旁边的原建筑，也不在无粮时继续建造。
