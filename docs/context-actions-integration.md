# 情境技能动作接入：第一、二批及第三批携带动作

适用 NeoForge 1.21.1，现已移植到 Forge 1.20.1。2026-11-14 完整构建通过：NeoForge 使用 Java 21，1324 项测试通过；Forge 使用 Java 17，1340 项测试通过。两端 JAR 均包含全部 27 条新增动画。原工程已有怪物、载具等修改保留。

Forge 网络协议为 forge-1.20.1-20-context-aerial-carry，沿用 Forge 附件、事件和网络适配层。已进入独立超平坦创造世界并解锁测试角色。用户按 Esc 停止界面控制后，未继续自动操作；逐动作、联机和异常中断实机验收仍待完成。下面“已执行验证”与批次说明中的独立验证、JUnit 未运行等文字属于原补丁交付时的历史记录，以本段完整构建结果为准。

| 操作 | 行为 | 条件 |
| --- | --- | --- |
| E | 普通抓人 | 沿用现有目标、距离、视线、血量和归属验证 |
| 潜行键 + E | 潜行吸收 | 空手形态、两手无物品、双方在地面且不在水中；成年类人、非巨型；目标无战斗目标、攻击记忆、最近伤害关系；玩家在背后 0.25–1.8 格，高差不超过 0.65 格 |
| C | 地面踩踏 | 地面、无抓持或搬物，沿用战斗系统可用条件 |
| 抓住人后 C | 抓腿抡砸 | 空手或肌肉形态；成年类人、非巨型目标 |
| 搬物时 C | 双手砸击 | 肌肉形态及原搬物解锁；完成拾取、未蓄力或投掷；在地面且不在水中 |
| 抓住人后左键 / 右键 | 投掷 / 普通吸收 | 原操作保留；普通空手吸收可选踩头、连殴、膝撞 |

不满足潜行吸收条件时，E 继续普通抓人。潜行键可重绑，默认 Shift；C 也可重绑。潜行吸收仍受原血量门槛约束，不代表新增隐身或保证其他 AI 不会察觉。

NeoForge 协议为 standalone-60-aerial-carry；本 Forge 端协议为 forge-1.20.1-20-context-aerial-carry。同一加载器的客户端与服务器须一起更新。

## 动作与结算

五组潜行吸收是扭颈、熊抱、双臂锁颈、断头台式锁颈及颈部撕扯。服务端在获取目标时先检查警觉状态，再清除 AI 目标；随机变体只选一次并随原附件同步。复用已有吸收会话、取消、死亡清理和唯一奖励结算。普通右键吸收不会随机选到潜行变体。

砸击仅使用已经抓取的物块，单块与整块共用原版双手动作，并沿用货物尺寸调整握持位置。挥动中固定朝向并锁定移动；提前撞墙或天花板取消并按原流程回收。释放从上一帧握持点开始扫掠，实际命中、伤害、碎片、物块回收和防重复结算均复用投掷物流程。不会再挖出一份方块，也不会以视觉碰撞代替服务端命中。

抓人抡砸为非吸收阶段，不发放吞噬奖励。踩踏追加到 WeaponMove 尾部，保留旧动作网络序号。

## 来源与时序

新增动画取自本地 alex.p3d.rz，资源 source 字段记录原包 SHA-256、原动作名、帧范围及适配信息。五组潜行动作均使用 gv / rcv 配对；物块使用 alex_weap_2hnd_slam。第二批新增 12 条，第三批再新增 6 条；累计 27 条动作，整个资源清单 287 项。

潜行吸收的命中提示、吸收特效、完成时刻是 Minecraft 适配值，不声称已还原 FIG 事件。物块第 54 tick 释放由转换后的手掌低点推导，实际伤害仍取决于后续扫掠碰撞。首批踩头参考 FIG 0.9 秒；其他来源与适配说明保留在各资源 source / timingNote 字段。

## 第三批：携带与空中投掷

| 操作 / 状态 | 新增行为 |
| --- | --- |
| 已抓人后冲刺 | 使用 alex_loco_grap_sprint_n_gv / rcv 双人冲刺动作 |
| 已抓人后跳起或离地 | 服务器发布 AIR_HOLD 阶段，使用 alex_grap_air_float_gv / rcv；一次过渡后保持末帧，落地恢复 HOLD |
| 空中持有人时左键释放投掷，或再次 E | 空手 / 肌肉形态、成年类人、非巨型目标使用 alex_grap_hmn_jump_throw_gv / rcv；沿用原投掷伤害和蓄力 |

这是先抓住目标再腾空的动作补全，尚未新增空中获取新目标。原滑翔、鞭拳等分支继续按原逻辑工作。空中持有可移动、可蓄力、可投掷；空中投掷阶段屏蔽新的技能输入，但保留重力和既有运动，遇到无法跟随的阻挡会取消。投掷前固定朝向；释放先解除归属，再进入现有抛物与碰撞流程，保留施动作的收招，不调用吸收奖励结算。

空中保持不能把完整过渡片段当成循环，因此新增同步阶段和起始时刻；携带姿态切换有短暂插值。投掷释放取第 13 tick（含 0.05 秒过渡），依据受击者 Motion_Root 在原第 18 帧后保持不动的观测。它是 Minecraft 适配时刻，不是已解码的 FIG 释放事件。

生产 PairedMotionClock 的 387 项独立检查通过，包括提前采样、连续推进、末帧钳制不循环，以及释放时刻与源帧对应。新增 AerialCarryMotionTest 覆盖成对资源、AIR_HOLD / AIR_THROW 语义、真实附件编解码；JUnit 尚未执行。人工需验证冲刺转向、起跳/落地、空中蓄力、投掷中落地、墙边取消、释放后碰撞及旁观者看到同一动作。
