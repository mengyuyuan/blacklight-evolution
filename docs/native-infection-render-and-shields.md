# 修仙灵盾近战与原生感染外观修复

版本：0.3.5-preview.20261101-ecology.2。

黑光模式普通近战在修仙 NPC／妖兽上单独跳过气盾与灵盾的拦截、自动反冲处理。仍通过原来的 hurt 事件；没有给所有模组攻击加真伤、没有倍增伤害、没有跳过领地或玩家保护。修仙玩家的护盾不变；非黑光模式普通攻击不变。服务器配置 blacklight-combat-server.toml 的 cultivationCompatibility.nativeHitsBypassMobShield 可关闭这项兼容。大招真伤仍由独立开关管理。

第三方感染生物继续保留原实体、UUID、技能、能力数据与原生 AI。外观借用同一套逐部位组织生长渲染，跟随原模型已经完成的骨骼姿态。覆盖普通 LivingEntityRenderer，以及持有 EntityModel 的自定义渲染器（实际验证了修仙黄鼠狼）。刚感染先有轻微组织变化，成熟后增生、覆盖。不是把原实体替换回丢失能力的空壳。无 EntityModel／ModelPart 的自定义网格需要专门适配，不能据此宣称所有渲染器都已覆盖。

此版本保留 ecology.1 的局部感染来源、区域与维度数量预算、原生能力保留、击杀 50% 资源、一次残血保命、OPAC 保护及无限进化规则。没有清理存档里的生物，也不抹除已进化的记录。

安装时退出游戏，替换对应版本的黑光 JAR，GeckoLib 保留一份。联机客户端和服务端同时更新。原存档可继续使用。仅旧版已经替换成 blacklight:infected_host 且丢失能力的生物，无法凭空恢复原模组的能力数据。
