# 感染属性范围修复

只有黑光感染判定为真的生物才获得 CombatScale 的生命/伤害/治疗单位换算及移速、攻速加成。普通原版生物、普通 Mod 生物和未感染黑色守望士兵不获得这组加成。感染玩家保留原有成长规则。

旧存档生物重新载入时会移除本模组误加的 health_units、combat_speed、combat_attack_speed 等修饰符。保留生命比例（例如原来 50/100 恢复成 10/20），不重置基础属性，也不移除其他 Mod 的属性修饰符。

感染开始时立即同步；直接施加或移除感染效果时，在服务端下一次实体 tick 同步。感染宿主、猎手、变异体及蜂巢保留感染强化。重复同步和重新载入不会叠加倍数。
