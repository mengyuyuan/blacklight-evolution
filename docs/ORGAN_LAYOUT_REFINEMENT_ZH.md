# 器官布局整理预览

版本：NeoForge 1.21.1，`0.3.5-preview.20261024-organs.2`。

此前多个器官会各自占用每条前肢，还叠着旧的尖爪，六次吞噬后很容易变成尖刺堆。本次调整外形分工，保留原来的继承库存、强度、成熟进度、攻击能力与吞噬计数。实际感染体仍为 12 类器官，另 60 项处于设计阶段；新增 7 类的主角技能尚未开放。

## 各部位如何生长

- 骨刃沿一侧前肢外缘生长，静止时贴近肢体，攻击时向前展开扫过。
- 螯钳位于另一侧前肢末端，采用短而厚的双钳面；它不再像一组平行长矛。
- 肌索平时盘成腕部或真实尾部上的连续肌肉组织，抓握时解开、伸出、收回。
- 弹腱集中于后方承力肢，压力腔贴着各支撑关节，减少每条腿上重复的外置组织。
- 头部新增撞角合并为一处连贯的额鼻结构；内部咽颚继续在吞入时工作。
- 新武器形成时，所在部位旧的尖爪和侧刃逐渐收回，让新结构接续原有肢体。皮肤、口器和其他部位不通过这个替换规则删除。

侧别由宿主稳定种子决定，绑定顺序不会使左右器官互换。多足动物先选合适的前足和后足，而不是在每条前足上重复安装整套武器。原模型缺少肢体时，会在身体两侧安排不同的生长根部。

## 验证范围

这次主要修改客户端布局、几何与动作。伤害、位移、夹持、消耗、冷却、成熟与继承逻辑保持原实现。测试检查布局数量与稳定性、根部连续性、静止轮廓和攻击展开；原生客户端再用牛、蜘蛛、僵尸完成相同的六次吞噬序列，并复测七类器官动作。具体结果和候选包的 SHA-256 随试玩文件夹提供。

六次吞噬测试中的供体和低血量由独立测试地图设置。实际吞噬收益来自正常结算；完成形态的检查点单独加速了消化，不把它描述为等待了完整的 180 秒。
