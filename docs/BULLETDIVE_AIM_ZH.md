# 子弹俯冲落点修正

移动键按当前镜头方向修正水平移动，松手刹停。已明确锁定目标时，松开移动键会继续朝该目标的当前位置校正；按住移动键可临时接管，不自动选择其他目标。

先锁定再升空，目标仍在同一世界、存活、可攻击且未离开已加载区域时，高度本身不再清除锁定。水平距离仍受原锁定范围约束。再次按锁定键可以取消，目标死亡或失效后停止引导。高空目标不在客户端实体追踪范围内时，使用服务器同步的坐标预测，HUD 显示横向偏差。

水平速度上限为每 tick 1.6 格，按移动意图平滑加速、反向和刹车。纵向保持原有持续增加的加速度，实际落差、真实伤害、地形破坏与地面碰撞结算均不改。没有瞬移落点、隔墙命中或自动选择新目标；接近地面才改变远处目标时，受剩余下落时间和水平控制速度限制。

网络协议升为 standalone-33-bulletdive-steering，服务端与客户端须使用相同版本。瞄准坐标仅由服务端下发，客户端只上传原有移动按键和镜头方向，不上传伤害、落差或命中判定。
