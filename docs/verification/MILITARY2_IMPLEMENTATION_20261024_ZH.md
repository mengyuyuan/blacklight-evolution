# military.2 城市军事、兵模与枪械实施记录

日期：2026-10-24（Asia/Shanghai）。本地预览版本：`0.3.4-preview.20261024-military.2`。本记录以当前两端文件和真实日志为准；原有military.1已由用户报告实玩测试全部正常，该反馈不冒充本代理客户端验收。

## 已落地功能

- 两方独立分层外观：完整制服基础人形、军方/BW普通及重装；512×512独立贴图、110个独立UV岛。`outfit uniform/equipped`移动同一真实枪栈并持久保存，护甲/击退抗性随状态变化。护具目前是NPC模型层，未宣称已提供玩家可穿戴护甲物品。
- 八枪七弹：步枪、卡宾、机枪、榴弹、火箭、导弹、温压与感染弹发射器；枪械/弹药有独立创造栏和合成。右键射击，潜行右键有限库存装填。普通兵首次30+90，重装首次60+180；所有参数为项目玩法配置，非已确认原作型号参数。
- 玩家和NPC共用服务端武器定义。普通弹射线裁切墙体/首实体；友军、创造与旁观保护。实体弹有主人、有限半径和寿命；主人缺席后停止有害结算，保留有限视觉。导弹当前直射，不具有追踪锁定；统一不破坏地形、不放火。
- 大型军方65×65、BW65×81，均高18格；真实指挥/营房/军械/弹药库/医疗/后勤、塔岗与屋顶路径。军方16、BW20有限槽位，实际实体按人口/加载预算发放，不死亡重生、重载刷箱或凭空补弹。
- 自然城市基地使用原生结构起点与逐区块裁剪；确定性选址保护建筑、道路、水体、地标和返回点。可清理新地块植被；旧块不回填覆盖。附近存在安全道路地块时附加17×17检查站，保留5格通道，门岗复用所属基地原有有限编制。
- 岗位随实体/基地存档；无显式命令时守岗、补给后返回，编制管理命令可覆盖默认岗位。导航经过实际模块门口与中央通道，复用每tick原有导航令牌。补给只从已加载、实际到达且视线可达的箱子取相应弹药，并扣精确接收数。
- `base status`区分WATCH/ENGAGED/FALLEN/UNLOADED/MUSTERING，不把卸载当安全。Neo支持当前全市与福田生成器；Forge仅针对其实际福田城市，不伪称已移植全市地图。

玩家操作：[MILITARY2_PLAYER_TEST_ZH.md](../MILITARY2_PLAYER_TEST_ZH.md)。美术细节与可复现脚本见同目录兵模/大型基地/武器报告。预览均从生产Java/PNG/NBT渲染，已实际查看，非游戏截图。
