## 决定及原因

1. 实际参考BB人物骨架和曲线。原参考共5365个cube，其中枪占5349，人物16个；不以整枪过重为由跳过轻量人物骨架。military.4的NPC模型和人物贴图与.3相同，仅改整枪视图，之前“已参考落地”的表述过度，本轮明确纠正。
2. 基地由建筑加登记记录组成；16/20是军方/BW的一次驻军发放槽，并非最大容纳人口。当前驻地与原生发放来源分开保存，避免转移导致复制人员、死亡重发或免费补弹。
3. 以指挥楼6处实际终端作为功能判据：任一存续即可维持功能；全部处于已加载区块且持续缺失约10秒才确认失效。区块卸载不是毁灭。修复恢复功能，但不重建建筑、不恢复箱库存或驻军槽。
4. 自动归属仅选择附近、已登记、已加载、同阵营的有效基地；否则持久保存野外巡逻锚点。普通寻路转移，不传送、不强载远方区块；手工与组织命令优先。
5. 补给继续真实扣减登记弹药箱库存。更换驻地不改变武器、弹量、军衔、角色、UUID和单位。
