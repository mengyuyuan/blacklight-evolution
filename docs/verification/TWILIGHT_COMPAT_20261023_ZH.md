# 暮色森林战斗适配 — 2026-10-23

范围为网站反馈 #21 的九头蛇和巫妖，两个 Minecraft 版本使用相同规则。暮色森林保持可选依赖，黑光安装包不包含暮色文件。

## 实现

- 黑光原生攻击和技能可以伤害九头蛇本体与真实身体部件；每个目标每次命中只应用一次既有的外部伤害倍率。
- 黑光原生命中突破巫妖的护盾/阶段伤害拦截；伤害被正常事件取消时，不清除护盾。
- 命中选择、粘液接触和视线改用多部件实体的实际伤害盒。已经附着的粘液保存服务器上的临时部件坐标，跟随部件移位；不跨越实体方块、不加载缺失区块，异常移动会释放附着。
- 使用原有 hurt/death 入口，保留伤害来源、攻击者与暮色自身死亡处理。没有直接 setHealth、删除 Boss、修改全局伤害类型标签或开启永久无敌。
- 非黑光原生攻击保持暮色原有规则；显式 Invulnerable 标志、伤害事件取消仍有效。
- 服主可在存档 serverconfig/blacklight-combat-server.toml 中关闭 externalTrueDamage 或 externalOffense，恢复原有机制。

## 测试环境与命令

- NeoForge 1.21.1 / 21.1.244，暮色 4.8.3345 正式 JAR。
- Forge 1.20.1：开发测试使用 Forge 47.4.10，安装包客户端使用 Forge 47.4.20；暮色使用 4.3.2508 正式 JAR，开发 GameTest 使用其 ForgeGradle 映射产物。
- `runGameTestServer -PtwilightTest` 加载实际暮色，未安装时测试会失败，不把缺失模组记为通过。
- 12 项集成检查：本体伤害、部件伤害、普通九头蛇规则、巫妖破盾、普通巫妖规则、俯冲正常击杀、聚合体吞噬、配置关闭、显式无敌/管理来源边界、远端部件与去重、取消事件、移动附着/遇墙释放。
- QA 客户端使用最终安装 JAR 的副本，只附加私有验收驱动，通过真实网络选择粘液并验证完整附着、吞噬、重构流程；不注入操作系统鼠标或键盘事件。私有驱动不会出现在交付包中。

NeoForge 客户端单独复测通过：完整战斗检查后主动保存成功，退出时全部维度保存完成，进程正常结束。首次并行测试中曾停留在 ChunkMap.scheduleUnload，保留线程记录后结束了该隔离进程；该次退出未计为通过。

早期失败记录保留于本地隔离 QA 目录。原先发现的九头蛇转向导致部件移位、吞噬附着中断，已经由真实客户端复现并修复。测试覆盖上述两个 Boss，不代表所有暮色 Boss 或任意整合包均已验收。
