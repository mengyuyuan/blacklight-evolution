# 试玩动作与下台阶修复 — 2026-10-26

候选：`0.3.5-preview.20261026-feedback.2`，NeoForge 1.21.1。

## 修改

- 抓持配对片段保留当前奔跑的根节点与距离驱动腿步；空中只覆盖抓持臂，保留滑翔的躯干、腿与另一条手臂。
- 按配对动作实际的右手接触点绑定。最终手掌拟合在墙面约束之后执行，目标位置与接收者的绘制插值一致。
- 原先客户端最多修正 4 格、渲染最多补偿 2 格，目标包稍晚后会永久落在疾跑者身后。现在按正常逐帧速度提供有界追赶，识别大幅传送，仍执行方块碰撞扫掠；抓持期间清理旧的独立目标插值。
- 服务端与客户端共用滑翔抓持位置，并在 4 tick 内平滑调整，避免把地面持物高度硬套到俯身滑翔。
- 一格以内的向下台阶继续既有疾跑缓存，客户端与服务端共用判断。跳跃、飞行、悬崖、失效缓存与持续按跳跃不取得该地面驱动。
- 试玩准备脚本移除误放的旧传送信标，改给活性蜂巢组织、喂养用生物蛋及牵引绳。保留原试玩存档，离线修改前备份了玩家数据。九头蛇成熟后进出维度仍是既有生存流程；本批不把信标当作该流程的验收。

## 验证

- 完整 682 项单元测试通过，零失败、错误、跳过。包含源动作右手接触约束、各方向滑翔骨架、携带跑步腿步、延迟包追赶、平滑抓持过渡，以及上一批波形越界回归。
- 后台真实服务端 5 / 5 项回归通过，覆盖下台阶保速、拒绝空中加速、抓持行走转向、疾跑投掷及共享滑翔锚点。
- 隔离原生客户端完成利爪抓牛奔跑、利刃抓鸡奔跑，以及利爪抓猪与利刃抓牛的滑翔姿态；每个场景至少 25 次骨骼与接触采样，并实际查看截图。
- 最终地面用例最大接触偏差约 0.029 / 0.108 格；滑翔调整后约 0.114 / 0.023 格。腿部锚点与当前移动姿势的最大差约 0.00022 格。
- 滑翔用例显式设置两端滑翔状态，验证抓持渲染和锚点衔接；不将此表述为完整人工输入操作或全部第三方模型联机兼容验收。
- 初轮画面测试发现目标追赶失效与右手绑定问题，未计为通过；修复并复测后才整理候选包。

## 本批边界

自然刷怪已在普通地图观察到，原配置每 60 tick 尝试生成，病毒进度以每 24000 tick 为一天。普通感染者的僵尸底模及其较高配比本批未修改，也没有宣称新增生物外形。

本批不改动任何动作、模型和地图资源文件，不删帧、不降采样、不改动画精度或原始时序。网站 #28 / #20 / #9 已完成的标记保留，#26 的整合包冲突仍单独排查。
