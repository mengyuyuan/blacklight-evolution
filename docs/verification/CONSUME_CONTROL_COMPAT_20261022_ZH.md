# 吸收期间的第三方控制兼容（2026-10-22）

抓取与吸收原先只屏蔽普通击退。Spore 的 PullGoal 直接写入速度，抓取技能还会强制骑乘；这些入口会让配对分离，随后服务器的距离校验取消吸收。粘液附着也有同样的问题。

本次修改：

- 抓取、持握与吸收期间阻止外部碰撞推挤、push 冲量、普通击退和强制骑乘；持握仍可走动。
- 已确认的吸收、粘液附着及恢复阶段由自己的动画逻辑拥有速度控制权，阻止外部直接写速度。内部动作使用限于当前实体的作用域，退出（包括异常退出）后还原。
- Spore 的 PullGoal 软适配在玩家持握阶段也阻止直接拉扯；不改变其他目标的 AI，不依赖安装 Spore。
- 用 `blacklight:consume_control` 效果标签拒绝控制效果，并在开始抓取/附着时解除已有的对应效果。毒等其他负面效果仍可正常生效；整合包可通过数据包补充控制效果。
- 已确认的吸收和粘液固定阶段不接受旧客户端坐标覆盖。死亡、主动取消和完成沿用原来的释放流程。

这不是永久霸体或无敌。吸收者仍会受伤、死亡；不会拦截其他模组任意直接传送、修改生命、删除实体或取消死亡等自定义逻辑。

## 验证

在 NeoForge 1.21.1 / Spore 2.2.0j 与 Forge 1.20.1 / Spore 2.2.0j 的实际服务端内，各通过 10 项 GameTest：5 项既有混装回归与 5 项新增控制回归。Forge 开发环境使用同一官方 Spore JAR 的映射副本；没有将 Spore 打入发布包。

新增回归实际调用 Spore 的 PullGoal，并覆盖：未保护时可拉扯、持握时不可拉扯、强制骑乘的真实 Entity 路径、结束后恢复控制、两种直接速度写入、内部动作速度、普通伤害、非控制负面效果、完整人形抓取吞噬，以及粘液吞噬 Spore inf_human / slasher 后恢复身体。伤害测试使用真正的 ServerPlayer，避免 FakePlayer 自带无敌导致误判。

详细日志保存在本机 `E:/Blacklight-Spore-QA/consume-control-*-gametest*.log`。Spore 的可选 Create 配方在没有 Create 时有既有配方解析警告，服务端仍完成上述测试并保存退出。

未安装 Spore 时，NeoForge 另通过 17 项基础服务端回归，Forge 另通过 18 项。旧的受阻恢复测试硬编码 30 帧，而现有生产恢复时长为 40 帧；本次将该用例改为读取 `BiomassState.REFORM_TICKS`。最初的基础回归日志保留此失败记录。NeoForge GameTest 环境没有加载自定义城市维度，额外一次全选运行的城市返回用例因此失败；最终显式选择了其余 17 项适用用例，没有据此声称已验收城市维度返回。

Scape and Run: Parasites 的具体移植 JAR 尚未确认，不能把通用入口保护等同于已完成该移植版的联测。该部分仍待对应整合包验证。
