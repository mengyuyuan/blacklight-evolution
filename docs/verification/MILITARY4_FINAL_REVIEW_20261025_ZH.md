# military.4 独立审阅与处置

审阅范围为本轮驻军、第一人称反馈、结构破坏和资料归档，不把既有military.1至.3的全部未提交变更误算成本轮。独立审阅者只读源码/实际缓存Minecraft API，不运行Gradle、不修改文件；主代理负责实际RED、修复和验证。

生产补丁复核未发现新的Important/Critical。不是仅凭Gradle退出0认定通过，具体场景与普通服JSON结果见主实施记录及交付evidence。

## 保留的边界

- 玩家真实单/多块放置覆盖已复现修理路径；任意命令、活塞或不发放置事件的外部模组同状态替换没有统一世代标记，不宣称全部识别。
- 双手分批网络更新若与真实单手射击完全同数据，无法无歧义区分；该有限表现边界不改变服务端伤害、库存或发射授权。
- mobGriefing由加载器canEntityDestroy实际钩子覆盖；不把未另写一遍游戏规则检查误判为缺失。没有声称支持每一种第三方领地插件。
- 驻军上限限制新的发放，不为降低上限删除已存在守军；卸载不等同死亡，已死亡槽不无限补发。
- Neo大世界与城市、Forge城市已有原生结构接入，Forge没有Neo大世界，不能用Neo测试冒充Forge对应维度存在。
- 静态模型/纹理预览、状态规则和服务端测试不能替代实际GL、玩家键鼠、光影环境和穿模验收。
