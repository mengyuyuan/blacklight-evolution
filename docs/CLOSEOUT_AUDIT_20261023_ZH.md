## 确认并修复

1. **Forge 按键注册事件总线错误。** 闪避、防御和感知的注册监听处在 GAME 总线，而注册事件属于 MOD 总线。原生客户端复现三项均不在控制设置中；修正为客户端 MOD 注册类，游戏输入监听仍在 GAME 总线。复测发现同名注册入口影响其他既有按键，最终使用独立注册类与唯一回调名称；原生客户端明确验证全部 11 项按键及三项改键后的输入/教程同步。
2. **自然建筑感染绕过可取消的方块放置边界。** 表面扩散、感染地形生出的组织及自然核心现在发出正确的新方块放置事件。保护取消时回退；核心仅在事件接受后登记，避免留下死亡核心记录、占用容量或封死以后合法生长。
3. **立体建筑血肉未检查每个目标格的城市禁生长区域。** 现在与表面组织共用地点许可检查，避免从区外跨入安全区或已有母巢保留区。
4. **保存的血肉路径只校验参数，未校验派生体积。** 加载时同时检查候选/实体方块预算，拒绝超预算路径，避免延迟到服务器 tick 中抛错。正常路径保留完全相同的方块顺序。
5. **两版投掷方块恢复时遗漏停止状态同步。** `Recover=true` 只还原了服务端字段，没有还原实体同步字段；客户端可能继续预测其飞行。加载时立即同步停止标记，复用 NeoForge 既有失败测试并补入 Forge 回归。

上述建筑感染与器官进化系统当前只在 NeoForge 分支实现，因此相关修复没有伪造一个 Forge 同名空实现。Forge 本轮修复按键注册、投掷回收同步并同步测试维护。

## 测试维护

扩大回归时保留了失败记录，并区分现行行为与过期测试：猎手预算测试明确进入虐杀模式；母巢奖励测试使用具有完整组织破坏能力的虐杀模式攻击；共享肌肉动作按 `damageFor(activeForm)` 检查强化后的伤害，仍要求单次命中及正确命中窗口。没有为迎合旧断言改弱生产战斗逻辑。

喂养测试单独运行通过，而与其他大场景共同运行会被模板外的地形相互干扰。该组测试使用独立批次；异常信息保留实际位移。建筑血肉测试也恢复自己修改的墙面和地面，防止上一项测试遗留的墙体成为下一项跨建筑连接测试的真实锚点。合并测试时重复添加的共享 NBT 模板通过 `tools/closeout_audit.init.gradle` 去重，其他资源冲突仍报错。

## 边界与未宣称完成的事项

本轮对两个版本做源码边界审查、单元测试、独立服务端 GameTest 与原生客户端验证。它不等于所有第三方模组、资源包和服务器插件的穷举测试；没有把两个真实远程客户端的联机验收算进来。已有可选模组的既往联测记录与本轮回归应分别看待。

独立药水模块本轮核对了接口签名与纯规则测试，未重新做其全部游戏运行验证，也没有在此次文件夹中另发药水 Mod。对非关键变更以清单、静态检查和回归覆盖，未声称全部变更逐行人工审查。

Forge 尚未包含 NeoForge 独有的完整世界地图和新建筑/器官进化系统；本轮不是这部分的移植。网站 #22 的注射剂/挑战链、同类吞噬进化为伪原形体的讨论方案也未混入发布修复，不应标为完成。
