# dev.13 原地蓄力水平滑动

用户确认问题发生在按住空格蹲着蓄力期间，不是松开后的空中前移。

原因：服务端原地蓄力只把 XZ 速度乘 .72，未归零；客户端仍接受普通走路输入，并可在已开始的原地蓄力期间重新施加冲刺加速度。此前蓄力动画的时钟插值修复不涉及这些物理输入。

修改：非跑动蓄力开始和持续贴地蓄力时，服务端 XZ 速度归零并保留 Y。客户端在原地蓄力且仍按住空格时清除普通 travel 输入和 XZ 惯性，并在预测阶段阻止冲刺加速度重新注入。物理按键状态继续保留用于松开判定；墙跑拥有自己的优先路径。跑动蓄力、镜头和松开后的发射算法不变。未强制传送锁死坐标，没有凭空制造 onGround。

验证计划：在独立 QA 存档进行完整原地蓄力并额外满蓄力保持 12 tick；期间持续注入 W/D/冲刺键及 .3/.2 XZ 惯性，记录两端实际位置漂移。随后实际释放和落地，并检查普通跑动蓄力仍然移动。结果见下。
