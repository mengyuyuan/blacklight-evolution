# 宿主解剖式成长模板

> 此文记录先前手工设计的感染牛样板。当前默认路径已经改为[骨架驱动的器官生成器](TISSUE_MORPHOGENESIS_ZH.md)；下列牛专用造型、头部资源与大碰撞范围不代表当前通用引擎。

## 本轮范围

先完成 NeoForge 1.21.1 的感染牛样板：局部伤口 → 单侧前肢与肩背增生 → 前重后轻的成熟四足体。用户认可了概念图方向并要求更方块化；运行模型仍需用户评价，功能测试不代表美术已获认可。

设计稿与可编辑网格位于 `art/tissue/cow/`，模型源脚本为 `tools/author_tissue_cow.py`。头部修订后运行资源为约 43 KB 的模板 JSON 和一张 128×32 图集；概念图、Blockbench 工程不打入 JAR。

## 外观与动作

- 同一拓扑保存三份形状键，平滑插值改变胸肩、前肢、后腿、颈部、头骨和下颌。没有整体缩放宿主。
- 原生皮肤 UV 投射到重构后的基础表面；组织从局部连片显露，完全覆盖后跳过对应基础面。
- 前肢长出三根真正有厚度的爪指。前臂绕肘弯曲，爪指先继承前臂，再在掌指关节卷曲；支点随三个成长形状键一起变化。
- 头部上下重构表面初期恰好组成原生立方体，随后口鼻延长、额骨和颧部拓宽，表面逐渐变为甲壳、肌肉和疤痕。头部从躯干同阶段开始变化；下颌独立绕生长支点开合，保持宿主真实转头动作。口腔内壁、后掠角和两枚上颌獠牙都有成长形状键。
- 关节继承宿主当次渲染的实际 ModelPart 动作，不修改共享模型的持久状态。普通近战、触须蓄力/命中/收回都有对应姿态。
- 宿主 UUID 决定主导侧、成长时序、连片显露差异和前肢宽度 ±6% 的差异。没有逐帧重新随机。
- 成熟模型为 6 个原生绑定区域、35 个可编辑网格、596 个源四边面；不额外生成附着物实体。使用游戏场景光照。口鼻端面使用连贯四边面，避免三角扇的放射状材质接缝。

## 服务端与存档

沿用保存的 `BlacklightTissueAge` 和原来的加载时间成长规则。牛的局部身体重构会逐渐扩大真实碰撞范围，眼高则跟随下移的头部；其他通用覆盖宿主保持原本尺寸。没有新增生命、攻击数值倍率。

触须仍只在服务端命中帧结算一次伤害，并检查距离与视线。修复了命中使目标感染后提前取消收招的问题：命中前检查目标有效性，命中后完整播放收回。相对命中点由服务端同步，目标死亡、消失或改变阵营后仍有稳定的收回终点。

网络协议更新为 `standalone-21-tissue-anatomy`，新旧实体同步字段不匹配的客户端/服务端在连接协商阶段拒绝混用。

## 模板格式

文件：`assets/blacklight/tissue_blueprints/cow.json`。

- `regions` 对应实际宿主部件；`part` 为原生部件名，`reference` 为初始立方体局部坐标边界。
- 每个 `mesh` 的 `stages` 为三份同拓扑坐标数组；单位是原生模型单位（16 单位一格）。
- `faces` 每项为四个顶点索引、材质编号、显露起点、显露终点。材质 0 保留原生皮肤。
- `skin=true` 表示承接原生皮肤的重构表面；其他网格从原生内部向外长出。
- `phase` 0 为躯干和头部、1 为主导前肢、2 为另一侧前肢、3 为后腿。
- `pivots` 与 `parentPivots` 同样有三份形状键；支持前臂和爪指的层级弯曲，`motion=jaw` 则使用独立的下颌动作。

加载器检查格式、有限坐标、索引、显露区间和面数预算。资源或骨骼匹配失败时保留原宿主的旧路径，不让错误模板破坏其他实体的渲染。

## 兼容边界

精细重构目前只接入成年原版牛的 ModelPart 路径。其他使用原版部件渲染的宿主继续使用专属附着物与通用表面覆盖；不能因此宣称全部第三方模型已获得精细器官和站姿重构。GeckoLib、自定义网格、多部件 Boss 和不同体型需要对应骨架接口与模板。

Forge 1.20.1 尚未移植本轮样板。当前没有创建 PR 或发布新安装包。
