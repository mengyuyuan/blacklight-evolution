# 四种感染宿主的后期结构

本轮修复此前“组织年龄增加，局部组织基本不再变化”的问题。NeoForge 1.21.1 的蝙蝠、幻翼、普通感染铁傀儡以及感染凋零增加第二套结构形状键。

## 时间与模型

- 组织年龄 48,000 之前保持已有早期几何。
- 48,000 到 144,000 之间平滑展开新增结构；由服务端已有的组织年龄驱动，随存档和实体同步保留。
- 蝙蝠：胸骨龙骨、翼根肌肉、分支翼骨与连膜、成对颌支。
- 幻翼：腹侧胸腔、背部支撑、翼骨和尾部稳定结构。
- 普通铁傀儡：肩胛背弓、前臂鞘、三指爪与腿部支撑。
- 凋零：肋架内部的连续胸腔、连接侧头的颈部组织和尾部承托结构。

生长从原部位内部或表面展开，跟随已有动画后的关节矩阵。新增部分参与当前吞噬渲染、破碎和器官来源快照。模型不随帧数累积，也不对共用原版骨骼写入缩放。

这套形状键完善物种自身的后期轮廓；并不是新增的吞噬器官，也不替代既有遗传器官。凋零和铁傀儡仍走原有多部件遭遇流程；本轮没有把它们改进普通无限代谢及竞争逻辑。进入巨化遭遇的铁傀儡保留原有独立巨型模型。

## 资源和验证

`tools/author_late_species_growth.py` 是原创建模源，重复运行只更新 `lateGrowth` 和 `nativeLateGrowth` 通道。四种早期几何和贴图保持原数据。新增三角面：蝙蝠 840、幻翼 634、铁傀儡 836、凋零 560，顶点量固定。蝙蝠外翼膜使用原版左右翼尖的独立关节及局部坐标，避免整翼组织被缩进两像素宽的翼根。

单元检查覆盖早期精确保留、平滑阶段边界、极端年龄、有效面索引、有限顶点和固定面数预算。实机静态对照使用同一物种种子、无吞噬器官的预设年龄；不能据此声称自然出生到六次自主吞噬的生态流程已验收。

粗暴缩放现有整模的首次结构稿已否决并移出项目，不进入游戏资源。
