**二、战斗体验与共用规则**

普通感染者承担清场与吸收节奏；精英迫使玩家选择武器和位置；大型 Boss 通过可见的身体变化改变战斗。玩家应能从姿态、运动、声音和命中位置理解攻击结果。

每招均使用这条流程：发现目标 → 接近或调整位置 → 可辨识的准备动作 → 锁定攻击方向或落点 → 实际接触或弹丸释放 → 收招 → 再次决策。失能、死亡、成功抓取、目标失效会撤销尚未发生的伤害事件。技能冷却与收招分开，取消不能刷新技能。

| 共用问题 | 本轮规则 |
| --- | --- |
| 索敌 | 使用实际视线、阵营、距离和威胁记录。失去视线后追向最后可见位置；不能隔墙直接取得新落点。已有伪装系统继续生效 |
| 选招 | 依据有效距离、朝向、障碍、冷却和自身状态选择；准备动作开始后不因玩家侧移突然换招 |
| 转身 | 跟踪窗口与最大转速属于每招数据。窗口结束后锁定，不能扑出去后急转追着玩家命中 |
| 地形 | 扑击和冲撞移动服务端碰撞体。撞墙停止前进；斜坡、台阶和坑洞先检查可达性，不以瞬移补救普通寻路失败 |
| 重复伤害 | 用攻击实例、子击编号、目标 UUID 去重。一次爪扫碰到同一目标多个身体部位，只结算该子击一次；真正下一抓必须再次接触 |
| 群体战 | 初始调试配置：同一玩家最多面对两个精英的攻击承诺，其中大型控制招最多一个；其他个体追击、侧移或等待。普通感染者保持群体密度，另调接触节奏。此限制是 MC 适配，需结合实战调整 |
| 打断 | 身体局部受击反馈与打断 AI 分离。霸体期间依然有皮肉、护甲和声音反应；大幅硬直只在允许窗口或破防时发生 |
| 多人 | 服务端确认命中、阶段、抓取归属与奖励；不同玩家不能重复吸收同一对象。后加入客户端按动作时间恢复显示 |

新适配招式的起测预算：普通攻击预警约 0.60–0.80 秒，重击约 0.90–1.30 秒；均为项目调试起点，不是原作数据。真正可躲避的预警还须覆盖当前玩家动作剩余不可取消时间、输入响应和移动到安全位置的时间。若原作快招短于该预算，应以先前动作、距离或连续技节奏提供预警，不能默默把所有原作动作统一减速。原版已核对片段优先保留。

**三、基础怪物的具体分工**

| 怪物 | 核心行为与动作 | 玩家应对 | 必须看见和听见的反馈 |
| --- | --- | --- | --- |
| 普通感染者 | 接近、左右抓击、双手扑打；失去目标后短暂搜索 | 移动清场、范围攻击、抓取吸收 | 胸肩先转再伸手；轻击有局部后仰；挥空只有风声，命中才有肉体冲击 |

| 潜行者 | 低姿接近、短扑、双抓；落空后必须有恢复 | 横移躲扑，追击落点 | 后腿蹬地、身体前冲、爪扫轨迹连续；落地声晚于起跳，不能起跳就伤害 |

黑光猎杀者作为第一只完整验收对象。普通挥击源帧 6–11 对应 0.5 秒准备，11–37 的出手段按 FIG 的 0.9 倍速度播放；当前总长 37 tick。手掌到爪尖扫掠与目标身体相交才结算，AI 先进入所选招式能触及的位置。连抓总长 57 tick，保留五个腕部窗口及第三次左爪；砸地 43 tick、扑击 48 tick、侧闪 24 tick。伤害去重、方块接触、无敌和取消事件分别检查，不保证每个窗口都必定扣血。

**四、伊丽莎白·格林战斗设计**

核心体验是拆除外层防护、迫使主体暴露、抓住倒地窗口输出，再应对恢复后的新压力。三处附肢各自有状态和受击反馈；身体血条与附肢状态明确区分。结构沿用当前三附肢实现，伤害比例、循环次数和场地尺寸属于 MC 适配。

| 状态 | 玩家看到的行为 | 可造成的伤害与应对 |
| --- | --- | --- |
| 进入战斗 | 按已有出土曲线定位根部，逐步显露主体；先检查空间与安全站位 | 进入片段不产生未显示的攻击伤害。首次进场与重新载入不能重复触发 |
| 外层防护 | 附肢活动、喷吐、咆哮各自有准备动作 | 优先攻击能接触到的附肢；主体减伤要显示防护反馈，不能看起来命中却完全没反应 |
| 附肢被破坏 | 对应部位收缩或断裂、局部组织与声音反馈；已破坏部位不再充当完整挡板 | 伤害归属只记到实际命中部位；不能同时扣完三个部位 |
| 主体倒下 | 使用 `mother_reveal_body` 倒地段，颈柱与身体连续运动 | 碰撞与弱点随头身降低；允许接触命中，不能等隐藏计时器结束才承认已露出的身体 |
| 暴露停留 | 60–150 源帧作为倒地循环，穿插已有受击动作 | 输出机会持续到明确状态条件结束；重击有重量反馈，普通击中不重复延长整场倒地计时 |
| 起身恢复 | 播放恢复片段，附肢与防护按各自恢复事件重建 | 先给出起身动作和声响，再恢复战斗；起身过程不能悄悄补发倒地前的弹丸 |
| 击败 | 使用死亡曲线与已有任务或奖励入口对接 | 取消未发射攻击；奖励仅结算一次。格林最终吸收若没有对应演出资料，单列待做，不套用至尊猎手处决 |

格林暂不按任意 65%/30% 血线硬套三阶段。阶段首先由防护破坏、主体倒地和恢复驱动。原版计时器关系解析完成后确定退出规则；调试期间可使用显式配置的暴露窗口，但须标注为适配值，不能再藏在动画长度里。

| 招式 | 接触或释放设计 | 玩家反制 | 物理与音效 |
| --- | --- | --- | --- |
| 咆哮冲击波 | 保留原始分段蓄力及扩圈节奏；源记录从约 3.333 秒开始有 Hit，原始圈半径依次为 8、12、16、20、25、30、40 | 根据起手动作拉开或寻找经验证能阻挡该波的实体遮挡；格数缩放和传播边界用实际场地验证，不把所有地图都套 40 格无条件必中 | 声音由吸气、低频蓄力、释放和远处衰减组成；波面经过目标才施加反应，每次成功命中受攻击去重约束 |
| 两种喷吐 | 各自片段和 Execute 对应项目第 14/47 tick 释放；从已校准口部插槽产生，不从实体中心发射 | 在锁定后移动、利用可阻挡弹丸的地形；每种喷吐的数量和轨迹须分别核对，不能靠随机散射替代 | 出口液体、弹丸飞行、碰撞溅射独立；被墙挡住只在墙面生成命中反馈 |
| 暴露受击 | 采样 `mother_collapse_hit` 与倒地姿态的合法衔接 | 鼓励攻击露出的主体；附肢已破坏后不再吸走本体攻击 | 受击点出血，主体局部晃动；镜头反馈受距离影响，不能每一颗粒子触发震屏 |

场地先设独立 QA 样本，提供环绕路线、明显实体掩体和可观察的附肢位置。最终生成规则遵守现有世界破坏设置；地形破坏是否改变掩体必须与伤害规则一致。

**五、歌利亚战斗设计**

核心体验是对抗巨大身体，利用巨臂承诺后的空隙打击腿部，改变它的行动方式。巨臂在当前模型右侧，动作、碰撞、弱点和镜头演出都按同一侧校准。

原始曲线包含 `behemoth_com_biped_leg_stun_to_biped`、`behemoth_com_biped_leg_dismember_to_crawl`、`behemoth_loco_crawl_idle`、`behemoth_com_crawl_front_body_slam`、`behemoth_com_crawl_front_spike`、`behemoth_com_prone_to_biped`。这些支持制作失衡与爬行形态，但不证明所有玩家武器、阈值和顺序。以下触发规则是待验证的 MC 设计。

| 状态 | 行为 | 玩家机会 |
| --- | --- | --- |
| 直立 | 沉重行走、巨臂前砸、身体砸地、可避开的直线冲撞 | 从巨臂摆动外侧接近腿部；重击后有明确收招，不原地瞬间转身补拳 |
| 单腿失衡 | 腿部累积有效伤害后播放腿部受创到恢复的原始动作，身体重心转移 | 短暂攻击窗口；受创腿有可见伤口与姿态差异，不能只减少一个隐藏护甲数值 |
| 腿部遭破坏 | 严重部位破坏触发原始断腿转爬行动作；具体断腿门槛在伤害测试后确定 | 切割结果对应实际受损腿部；身体降低时保留实体连续性，未受损部分不四散 |
| 爬行 | 降低身体高度，切换爬行移动、前方身体重击与前向地刺 | 改变攻击高度和危险方向；玩家能绕侧，但不能继续使用直立腿部的旧碰撞盒骗伤害 |
| 恢复或终结 | 是否恢复由已验证的原作条件决定；调试先区分可恢复失衡与已断腿状态 | 普通失衡可恢复，真正断肢不能无提示瞬间长回。死亡取消追踪与待释放伤害，沉重身体接地后才产生落地震动 |

| 招式 | 动作与命中 | 反制与反馈 |
| --- | --- | --- |
| 巨臂前砸 | 读取前砸原曲线，校准肩、肘、腕和拳面；拳体扫过与落地点分别产生直击和地面事件 | 侧移离开拳面，趁巨臂落地攻击暴露侧；空中挥动只有破风，撞上生物或方块才有对应冲击 |
| 身体砸地 | 身体重心下降，实际接地后产生局部冲击传播 | 大幅蓄力提供撤离机会；脚下泥土、石头、冰雪的碎屑和撞击声音不同 |
| 冲撞 | 沿承诺方向运动，受方块碰撞和转弯半径限制 | 侧向避开，撞实墙产生中止与失衡；不能隔墙播放撞击后继续穿过 |
| 爬行前刺 | 使用爬行曲线与前方释放方向，逐段确认生成点的地表 | 玩家向侧面退出危险带；地面预兆先于生成，刺尖实际出现后才命中 |

原始歌利亚曲线此前未可靠接入实际战斗。先完成脚底、巨臂和断腿转爬行的姿态校准，再决定数值；不能直接启用所有曲线后把碰撞与伤害留在旧位置。

**六、伤害和玩家武器的分工**

保留当前原猎杀者与至尊猎手的既有数值，先记录实际承伤和击杀时间，再调整本轮新怪物。每招分别定义生命伤害、失衡积累、部位破坏和运动冲量，不能用一个“伤害大”参数同时决定全部结果。

所有数值注明是基础属性单位还是最终显示血量；项目 `CombatScale` 已有单位换算，新增技能不能再乘一次倍率。护甲、抗性和其他模组防御继续走现有伤害路径，反馈只依据实际接受的命中结果。

| 玩家形态 | 本轮表现重点 | 不应出现的结果 |
| --- | --- | --- |
| 利爪 | 各条实际爪刃的接触轨迹产生对应伤口和切面；相近切口可合并，形成多段但连贯的分离 | 不接触也固定分成四块，不同爪子重复给同一子击扣四次血 |
| 刀刃 | 依命中位置、斩击方向延伸为完整断面，保留原版顺畅分段观感 | 永远只掉固定手脚或一点薄屑 |
| 锤拳 | 更高破防与失衡作用，钝击变形、抛飞、落地反馈明显 | 砸中也生成刀切口；蓄力完成但拳未落地就出现地面冲击 |
| 鞭形态 | 沿既有鞭刃轨迹做接触，牵引按目标体型和可抓取状态受限 | 一拉就把巨大 Boss 整体拖到手边；脱离后残留持续扣血 |
| 其他已有形态 | 按其既有攻击性质区分切割、穿刺和钝击，不额外新增形态 | 统一套利爪效果或统一碎尸 |

普通命中先做伤口与局部受击。完整死亡布娃娃只能由确认死亡或已完成的吸收终结接管。非致命断肢必须有明确可存活的部位状态和后续行为；未实现这套状态的生物保持受伤完整体，不能出现“活体隐去，尸块却在飞”。

吸收中的抓取仍抓完整目标。接收方姿态与手掌、爪根对齐，武器实际进入身体后才发生相应切割；组织牵引由接触位置进入吸收点。取消或断线时释放占用并恢复合法状态，不产生第二份活体或尸体。

**七、物理和声音的具体制作标准**

物理先区分局部受击、失衡、击飞、倒地、死亡布娃娃五种结果。活体关节仍受骨架约束；死亡后保留未被切断的连接。碰撞处理统一考虑地面、墙、台阶、斜坡和水面；尸块不能依靠穿墙或突然缩小来消除重叠。物理表现预算优先保证近处正在交互的身体。

| 事件 | 视觉与物理 | 声音层次 |
| --- | --- | --- |
| 脚步 | 脚真正压地后触发，体型决定可见震动幅度 | 落足的接触声、身体重量低频、地表材质声 |
| 蓄力 | 肩、臂、躯干和组织的张力动作 | 呼吸、肌肉或组织张力；重要技能有可辨识提示 |
| 挥空 | 与武器或肢体速度一致的拖尾 | 破风，不播放肉体破裂和重落地声 |
| 肉体命中 | 命中位置出血、局部形变和方向受击 | 短促冲击、湿润肉体声；连击避免同一采样机械重叠 |
| 护甲命中 | 局部挡住、刮擦或碎裂；破防前后外观不同 | 刮擦、硬壳撞击、破裂分别对应不同结果 |
| 重击接地 | 真实落点的碎屑、扩散尘土和近距离相机反馈 | 初次接触瞬态、低频重量、材料碎裂与回落尾声 |
| 切割 | 切口出现、组织分离和碎块惯性连续 | 切入、断裂、脱离、落地分开触发，不能出刀就播放整套碎尸音 |
| 吸收 | 切割、牵引、身体消失按同一进度发生 | 抓取、穿刺或撕裂、组织牵引、完成声；中断时结束循环层 |
| Boss 转态 | 身体变化、血条提示和碰撞状态一致 | 有明确方向与距离的阶段提示，优先于普通环境声 |

原始 FIG 的 Sound 行目前部分只解出 Patch 哈希。逐个建立“状态路径—事件时间—Patch—实际音频”映射；找到事件不等于已经找到声音文件。没有映射成功的声音标为待补或临时素材，不能把劫掠兽吼声等通用声音标成原版还原。

同一个服务端攻击实例记录准备、释放、接触、破防、落地等事件。客户端用同步时间播放相应声音与画面，并按事件编号去重。来自受伤拒绝、挥空或取消的分支不能播放成功命中声；方块接触和生物接触分别结算。原始子状态的相对事件时间先展开到完整动作时钟，不能把局部 0 秒当成整个动作开始。

可调项包括震动、闪光和血效强度；关闭声音后仍能看清准备动作与危险方向。多人情况下仅附近玩家接收相应反馈，不让全世界同时震屏。

**八、按完整对象验收**

执行顺序：范围整理与重复猎杀者兼容 → 原猎杀者完整战斗样板 → 普通感染者与感染宿主 → 潜行者、喷吐者、蛮兽 → 主宰与飞行感染体 → 九头蛇现有动作回归 → 格林完整循环 → 歌利亚完整形态变化 → 双版本回归与打包。每次只推进一种，下一种复用已通过的基础能力。

| 验收项 | 需要留下的证据 |
| --- | --- |
