# 单腿前后翻转修复

问题存在于已烘焙的动作资料：鞭拳待机的左大腿、行走的右大腿在相邻
60 Hz 帧间出现约 177° 翻转，疾跑和跑动起跳也存在类似问题。
原数值转换工具用膝盖投影决定整个腿骨的横向轴；腿接近伸直时，投影
跨过零点会把膝盖平面翻转。这与游戏移动速度无关。

`tools/repair_locomotion_legs.py` 从已核对哈希的解包动作取得髋部朝向，
用它确定稳定的弯曲平面，固定骨长重新求解腿部。保留既有脚端点、
动作时间、根骨和全部上半身轨道。未改移动速度、相机、攻击或按键。
原解包文件留在仓库外，资料的来源说明仍保留。

本次覆盖四条动作：`basic_idle_whip`、`basic_walk`、`basic_sprint`、
`basic_jump_running`。待机左大腿每帧最大角差从 177.1° 降至 1.9°，
行走右大腿从 177.2° 降至 4.6°。脚端点误差小于 1e-7 个模型单位。

`LocomotionLegContinuityTest` 用实际运行时采样器在 240 Hz 下检查这四条
动作的双腿旋转连续性和循环接缝；未用降低播放速度掩盖异常。
