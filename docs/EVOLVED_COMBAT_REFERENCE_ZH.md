# 二代刀臂进化者战斗对照

本轮面向 NeoForge 1.21.1 的一个刀臂超级精英。原资源为本地研究目录中 `evolved`、`evolved_runner1` P3D 与已解码动画；每份动作及网格的指纹保留在 design 目录。没有把未解析的战斗树字节码宣称为已还原的 AI。

## 本轮接入

- 突刺、后撤双斩、跳斩和闪避的原 motion_root 位移接到真实服务端实体移动。遵守方块碰撞，不传送穿墙；前冲根据目标距离缩放，移动步长有界。
- 根据距离追击、前冲、突刺或跳斩；受压时侧闪或后撤反击。收招时能绕步，抓取需要真实继承器官、距离和冷却。
- 二代戒备姿态、前后左右戒备走步、磨刃和招手。挑衅可被危险打断，不是无敌表演。非战斗待机有耸肩、活动颈部。
- 刀锋轨迹来自最终蒙皮后的刀尖和腕部，随身体缩放与插值。突刺先有贴附刀臂的红色预兆，伤害窗口才出现切割拖尾；每条拖尾最多四十份短时样本。
- 接受真实命中后才有暗红组织粒子、命中声。起跳、侧闪、突进带地面碎屑；跳斩触地带尘土与沉闷撞击声。只广播有限粒子，不生成常驻特效实体。
- 独立超级精英属性与按玩家血量限制的单次命中预算，保留防御与有限受击控制。

## 原始效果引用核对

Runner1 与通用 Evolved 包中可读到以下路径：

- `effects/motiontrails/blades_charged/blade_l`
- `effects/sparks_dust_debris/impaler/charge_effects`
- `effects/motiontrails/air/jump`
- `effects/various_effects/sparks_dust_debris/combofinisher_slam`
- `motioneffects/character_body_effects/enrage_mode/evolved/on`

这些路径证明源包存在相关效果引用，不证明已经还原其原生着色器、完整状态机或每帧粒子参数。本轮以 Minecraft 风格实现相应反馈，不复制源粒子贴图、音频或着色器。伤害与特效窗口是对原动作的 MC 适配，并非从未解码的 FIGHT 字节码取得。

## 尚未完成

- 原生完整四连击、六连击链及所有分支：当前只有已核对的前冲入口和部分回收片段，不能将回收片段称为完整连招。
- 车辆或大型物体投掷、空中连击、龙卷变体、感染炸弹、召唤猎手或飞行感染体，以及对应专项 AI。目录中存在相关名字，不代表该 Runner1 必定会调用全部能力。
- 源游戏的完整组织液化材质、怒化着色器和原音频。目前为贴附组织流、拖尾及 MC 粒子声音的适配。

后续能力需分别核对原动作、实际触发流程和多人同步，再接入这个超级精英，避免把目录里所有能力同时塞给一个敌人。
