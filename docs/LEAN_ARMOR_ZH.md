# 旧方块战甲 · 收腰兽型试玩版

Minecraft 1.21.1 / NeoForge / Blacklight: Ascension 0.3.0-standalone-dev.17。

以之前游戏里的方块战甲为基础，使用原有像素贴图与变形时序。胸腹改为连续收窄的五段核心，保留宽胸细腰轮廓。新增四块倾斜的斜方肌甲片，与加厚的后颈甲衔接；大腿上段加厚约 16%、中段 13%、下段 8%，向膝盖收细。颈侧甲刺保持去除。

123 个编辑器方块导出为 127 个关节部件。完全展开时，静止绑定姿态的脚底到头顶视觉高度约为 2.27 格（原尺寸等比放大 1.2 倍），整套角色与装备等比缩放，收甲时平滑恢复。此轮调整的是外观，玩家碰撞体、眼睛高度和攻击距离仍沿用现有机制。

模型源：art/armor-vshape-preview/，包含可编辑 Blockbench 模型、像素贴图、布局和导入记录。生成流程：先执行 tools/shape_original_armor_lines.py，再执行 tools/export_vshape_armor.py。后者核对原贴图、绑定关节、面片、变形数据并更新资源清单。

使用 -PleanArmorPreview 启动开发客户端会在单人测试世界自动启用战甲、切到第三人称，并显示 dev.17 提示。普通启动不自动改变玩家状态。

本次是 1.21.1 NeoForge 试玩包，尚未同步 1.20.1 Forge；两个加载器的包不可混用。
