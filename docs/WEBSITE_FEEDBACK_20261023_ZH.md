# 网站反馈处理（2026-10-23）

本批版本：`0.3.4-preview.20261023-feedback.1`。NeoForge 1.21.1 与 Forge 1.20.1。
客户端与服务端必须使用同一批构建；本批新增飞行偏好同步，不能混用旧协议。

## 已实现

- #18：技能界面 → 设置 → 血条位置，可调整横纵位置并预览；红血、蓝色临界质量和恢复状态一起移动。本地保存，不影响其他玩家。
- #11：设置 → 飞行速度，选择已解锁速度的 10%–100%。服务端校验并保存，仍受升级档位和已加载区块安全限速控制。
- #19：强化同化三级阈值为 15% / 20% / 25%，液态吞噬耗时为 60 / 48 / 36 tick；回血倍率 1 / 1.35 / 1.7。新增三级液态移动升级。新增生物质代谢：虐杀模式受伤时，每秒消耗 10 生物质恢复基础最大生命的 2%，满血不消耗，不产生临界质量。大型成熟器官的破绽条件仍保留。
- #6：清道夫对贴身目标最多九段接触判定；利爪地刺仅实际起手阶段获得保护，不覆盖蓄力、位移和收招；肌肉强化使共用体术伤害翻倍，不额外翻倍大招和子弹俯冲。锤拳高抛自身沿用已有实现。
- #3 的基础防护：感染后的普通模式防摔，对一般伤害减免 20%；两种模式均减免 80% 火焰伤害、20% 爆炸伤害。普通模式挖掘速度 ×1.5。虚空和管理员强制伤害不免疫。未来黑色守望枪械联动尚未实现。
- #16/#17：死亡母巢不能重新加入 Boss 血条观众；吞噬处决确认真实死亡后才发奖励。遭拒绝时释放猎物，短暂跳过该目标。死亡生成方块前保存可达空间，重构时重新校验，不通过旧墙传送，不强行破坏保护区。
- #15：专用 A 哥桥接模型搭配 Hold My Items 2.1，第一人称手臂改用持物动画的同一坐标框架。普通模式适配，不改动其他 YSM 模型，不修改 HMI 用户配置。Forge 补上此前仅 NeoForge 已合入的 YSM 动作桥；需要官方 YSM、Mapping API 和专用桥接模型。
- #9：在实际服务端回归创造模式、生命提升、再生、吞噬溢出及死亡/存档清理路径。
