# 城市感染扩展：已验收基础与下一轮

本轮 PR 收集 NeoForge 1.21.1 已完成的进化者、感染体吞噬与器官继承、玩家无限成长、
首轮世界感染、固定双城地形和无损资源压缩。黑色守望由另一项工作负责，本轮不扩展该内容。

现有固定城市地理位置、精做核心与已有存档区块保留。城市包内存储生成资料，游戏时按请求
生成地形；没有游玩时下载地图或要求玩家导入城市存档。

## 本轮已有基础

- 首次摔瓶的共享游戏时钟，重复摔瓶不重置。
- 固定双城的 256 格街区活动/清剿状态，保存重进保留，离线不补算刷怪和方块变化。
- 分阶段混合感染体、普通补给感染者名额与人口上限。
- 现有建筑生长、实体母巢与原城市母巢流程。
- 程序化普通建筑、冻结真实地理与精做核心，地图和动作逐字节压缩校验。
- 主 JAR 预算与资源占用报告。

## 按原方案继续补全

1. 在保留原位城市的前提下，为维度外围接入按种子复用城市片区；数据只保留一份，处理
   街道与地形过渡，保存稳定的城市副本身份。
2. 将普通城区的自然建筑感染选址、建筑核心、母巢生产与生态阶段统一；核对释放病毒前
   的休眠规则，避免各系统各自生产造成超预算。
3. 拆除建筑核心也产生统一清剿反馈；清理历史与活跃殖群名额分开保存，保持防重复刷核心规则。
4. 将感染源供养、建筑增生和邻区扩散串为健康、潜伏、暴发、母巢与成熟感染区的发展。
5. 同模板的不同城市副本使用独立感染、清剿与破坏记录；新城市接入共用逻辑。
6. 所有真实世界操作保持服务端权威、玩家附近已加载范围、共享工作与人口预算，并补验
   多城市、多人共享预算、游戏规则、保存重进和清剿不复活。

以上属于后续工作，不能把本轮固定双城及首轮生态的通过记录当成完整重复城市感染系统的验收。
