## 1. 可直接用于方案的结论

- **原作确认**：P2 的军事存在属于城市布局的一部分，开发者明确谈到基地、城市道路上的军用载具和屋顶瞭望塔。城市基地可以与路口、屋顶和周边街区建立联系，不能仅用城外随机营地代替这种体验。[R1]
- **原作确认**：三色分区体现不同感染程度和城市状态。绿区接近正常生活但军事存在明显；黄区有拥挤的临时居住区及 Blackwatch / Gentek 的不道德实验；红区有破败高楼和病毒增生。[R1]
- **语义边界**：用户要求的“基地保护城市、清理感染者、救援居民”可以作为本项目玩法。P2 的 Blackwatch 还承担封锁、占领及实验等叙事功能，不能把它描述成原作中始终保护平民的救援组织。[R1]
- **原作确认**：P2 玩家可以拾取世界中的枪械并使用；军人伪装可进入受限区域、使用终端。把枪械、受限入口、科研外勤与基地关联有原作依据；MC 合成、分层穿装备、具体弹药配方则是本项目扩展。[R2]
- **未完成视觉确认**：本轮定位到官方发行截图及候选兵装概念图，但图像工具没有向模型提供可检查的像素。不能声称已逐项确认 P2 制服的准确颜色、护肩形状、迷彩、面罩零件或基地材料。[R4][L1]

## 4. 城市设施：参考含义与项目扩展

以下每一行的“项目设计”是 MC 适配建议，尺寸、岗位、补给量和生成数量均应由项目需求另定。

| 设施 / 城市关系 | 原作证据 | 本项目可以如何采用 |
| --- | --- | --- |
| 城区驻防基地 | 开发者直接确认绿区有坚固军事基地。[R1] | 在有道路可达的完整地块设置基地、入口、营房、指挥空间和仓储；大基地包含弹药库。弹药库具体房间不是本轮原作确认 |
| 路口检查站 / 隔离入口 | 军事控制与受限区域有文本依据；未完成逐个路障镜头核实。[R1][R2] | 路障、岗亭、检查通道、警示标识与城市路网衔接，留出可寻路的出入口；门禁与误伤规则属于项目实现 |
| 屋顶据点 | 开发者明确提到城市屋顶瞭望塔。[R1] | 只在面积、承重视觉和出入路径合适的屋顶设置小型警戒点；梯道、通讯件、补给和驻军上限是项目设计 |
| 科研 / 隔离设施 | Gentek 科研与 Blackwatch 外勤组合由手册确认，黄区实验由开发者确认。[R1][R2] | 采用科研区、隔离区与军警戒区的空间区分；以装饰与可交互设备表现研究。不能把实验活动写成单纯救援 |
| 城市边缘前沿点 / 失守点 | 红区破败建筑和病毒增生有直接文本依据。[R1] | 完整基地、受损前哨和失守补给点使用不同状态模板；动态失守 / 夺回流程是本项目扩展 |
| 街区保护与支援 | 原作存在城市军力，不等于证实统一的救援行为。[R1][R3] | 建立驻军防感染、巡逻、警报与有限增援，满足用户“保护城市”的玩法；是否救援平民、怎样识别感染、是否接受玩家需要单独明确 |

**材料与轮廓尚未视觉闭环。** 混凝土隔离件、钢网、金属设施、编号标识、探照灯和工业设备可先作为项目美术语汇；本轮不能声称已经逐项从 P2 官方镜头看见这些具体资产。应在美术制作时给出参考链接与项目原创部分，并做游戏内昼夜、远近、四方向和实际行走展示。
