## 默认规则与容易误判的原因

- 病毒由真实药剂破碎启动；服务器共用一个以主世界 gameTime 计算的起始时间。另一名玩家再次摔瓶可建立当地感染区，不会重置全局时钟。`/time add` 改变昼夜时间，不直接推进这个计时。
- 默认环境调度每 60 tick 一轮，每个玩家最多成功出生一只，每个维度每窗口最多 4 只。六次候选位置尝试并非六只必定出生。同一个 256×256 街区的多名玩家会去重，避免人数直接放大生产。
- 环境感染体补充的默认绿/黄/红区候选位置通过率为 12% / 55% / 100%；局部感染体上限分别为 8 / 14 / 18；维度感染体上限 128。成功还需要有效支撑、全身无碰撞/液体、已加载区块与玩家安全距离。红区 100% 仅指概率门，不绕过这些条件。
- 全球阶段默认在释放病毒后实际经过 1 / 3 / 7 / 14 个游戏日解锁；地区还需活跃感染压力和加载中的暴露时间。空地长期没有感染体或组织会降低压力。红色区域与高阶资格是两回事。
- 建筑组织和城市母巢需要真实养分、已加载的生长/繁殖时间和可走出的出口。只等待而不喂养，不能从空气中产出怪物。未加载地区没有离线补产。
- 进化者不是权重池里直接随机刷出的普通种类。成熟感染体还需要真实吞噬、成熟器官整合和进化门槛；不能用“区域红了”作为保证已出现进化者的依据。
- 固定红色装饰囊 `blacklight:city_sac` 不是可喂养的维度组织或繁殖核心。

## 仍需后续设计的限制（本次未擅自修改平衡）

1. **城市总名额竞争**：默认 `cityMobLimit=80` 统计全部活 Mob，居民、士兵、宠物和感染体都在内，包含保持加载的远处实体。持久居民填满名额后，红区也无法新生感染体；本次没有删除居民或偷偷突破上限。后续可设计居民/军方/感染体分组预算与总上限并存。
2. **街面可见性**：外围城区路径每 100 tick 只抽一个道路位置，且有局部 48 格 8 只全部 Mob 的限制；环境路径可能使用屋顶最高高度。因此“街上没看到”不等于全维度没生成。本次未改为强制街面刷怪。
3. **两版生态尚不相同**：Forge 1.20.1 当前分支没有 1.21.1 的全局爆发调度、动态区域压力和共用建筑组织养分生态。已核对 GitHub 分支头：NeoForge fbe95ee、Forge 59f8fb1，本地基底一致；本次仅修共用缺陷，不把整套新生态隐式移植过去。
4. **物种多样性**：环境主动出生池目前选取十种陆地宿主；其他生物可通过感染进入系统，但不代表都被等概率主动生成。水生、飞行宿主的主动种群配额尚未单独设计。
