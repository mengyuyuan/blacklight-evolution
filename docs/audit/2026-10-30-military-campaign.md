# 军方 PR 整合与双维度清剿验收

整合对象：PR #95 `06858b01a7c3a312dba400abf520cf5299ffc106`。主线基准 `f807cf09b6c2f98029ff2d99816d09fbd0b6700a`。本轮只实施 NeoForge 1.21.1，两个维度指主世界与黑光维度。

## 已解决的边界

- 六处合并冲突保留当前主线外部镜头角度、城市人口预算、配置与翻译，同时接入载具消息。协议统一为 `standalone-43-military-consume`，保留此前吞噬随机分支及接收者恢复修复。
- 红区新编增援和基地原驻军休整分开；原驻军休整不能阻断持续增援。真实毁坏指挥设施、潜入瘫痪才会切断附近支援。
- 行动不会覆盖玩家明确命令、载具乘员或手动编队。外围入口验证实际地面、加载/活动状态、距离、碰撞和水；城市屋顶、建筑和桥梁不能被当作地面增援入口。
- 进攻建筑核心使用实际携带的枪、瞄准周期、弹匣与有限储备。射线遮挡、`mobGriefing`、方块材料和保护钩子继续生效。
- 指挥设施受损只在真实破坏后归因；枪械的权限探测事件不计破坏，别的方块出现在旧终端坐标也不计功。
- 缺少区块不代表基地被摧毁。旧存档已摧毁基地也会接入停援记录；恢复真实终端后才能恢复指挥。
- 实体母巢只有接受死亡后才通知清剿结算；不能因可取消的死亡事件提前清区。
- 多人共享每维度预算与地区行动；地区轮询避免固定偏向第一个玩家。停服或无人活动不会自动完成行动、补回旧部队或刷新其库存。

## 实际限制

本记录覆盖冲突整合和新增清剿路径，不代表对 PR 的 1947 个文件全部逐行审完。原有坦克、装甲运兵车、卡车与车队系统保留，本轮自动派遣以步兵为主体；飞机、直升机、空中突击队和坦克自动参与这套任务未列为完成。大型主世界基地只接受少数安全平地，因此较稀少；持续红区部队不依赖必须在玩家面前加载出一座基地。

本轮未做可见客户端画面的最终复验，不把服务器通过称作客户端视觉验收。预览包需客户端和服务端同时更新，不与旧协议混用。
