# 附生异变造型修订

后续用户仍否定了本页的 r5 躯干包络外观。本页保留为历史实现与验证记录；当前默认使用[骨架驱动生成器](TISSUE_MORPHOGENESIS_ZH.md)。其间制作的[感染牛解剖模板](TISSUE_ANATOMY_BLUEPRINT_ZH.md)及 `art/tissue/cow/README.md` 也仅保留作参考。不把下述历史截图作为当前造型。

用户否定上一版放射状长刺、近似翅膀的刃肢和整片发黑的成熟外观。本轮从感染牛近景开始重做，功能测试通过不能替代用户对造型的认可。

## 美术方向与运行目标

- Java NeoForge 1.21.1，PC 原版实体渲染与场景光照；不依赖光影包或 PBR。
- 优先解决可见轮廓和身体连接，沿用用户此前要求的精细造型与 Minecraft 风格。没有可调用的 Blockbench MCP；参考已读取的建模规范，实际修改的是运行时网格代码，没有冒称在 Blockbench 完成模型工程。
- 身体保持能辨认的头、四肢和重心。异变来自胸肩、背部、肋侧的体积变化与局部肢体肥大。
- 没有为每只生物再插数根同形长刺。四足宿主不额外挂悬垂的长刃；人形可以在主导手臂生长一片短刃。
- 有限预算：成熟躯干 9 个截面、每截面 16 点，共约 298 三角形（含组织裂口）；攻击触须最多 144 三角形；可选前臂刃 96 三角形。新器官层合计最多约 538 三角形，不包括原有专属感染模型及附着覆盖层。不创建额外附着物实体。

## 实现

- `SurfaceTissue.renderBodyEnvelope` 把两侧肌束、胸肩与背部组织做成同一个连通体积。主导一侧与另一侧的增厚分别取各自成长进度。
- 早期网格沿原生躯干立方体展开；截面数量为八的倍数，保留原始角点。覆盖完整后才抑制原生躯干皮肤，逐渐收圆局部轮廓，防止原始方角从新网格里突出来。只跳过当前躯干部件的 compile，不取消整只生物、不修改共享骨骼和子部件。
- 头部前表面不再被统一黑壳盖住，保留实际眼、口鼻与已有伤口。侧面组织和原有专属角、甲片继续沿原生骨骼动作。
- 触须平时收在胸肩组织内；攻击时从一处连续凹陷裂口展开，接触与收回仍使用原有服务端同步阶段。目标瞬移到远处时不会出现无限拉长的可见尖刺。
- 修正连续截面侧面的三角形绕序，使其法线朝外，恢复正确场景光照；不通过提高全亮度掩盖错误。
- 16×16 中性纤维材质仅补充表面纹理；实际厚度、凹陷和器官形状仍由几何产生。局部投影 UV、就近像素过滤，不引入高分辨率材质和新渲染实体。
- 几何变形仅在本次渲染的部件矩阵上进行；成长、存档、导航、伤害值与原有同步协议不因美术修改而重置。
