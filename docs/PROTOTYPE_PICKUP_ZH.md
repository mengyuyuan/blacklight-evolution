# 虐杀模式物品拾取开关

位置：技能页面 → 设置 → 虐杀模式物品拾取。

- 默认开启，旧存档继续允许拾取。
- 关闭只阻止该玩家在虐杀模式下拾取地面掉落物，不删除掉落物。
- 普通模式拾取、经验球不受影响。
- 开启仍遵守原版的拾取延迟、物品归属和背包容量规则。
- 设置由服务端处理并同步，随玩家存档保存，死亡重生后保留。

本次为 NeoForge 1.21.1 城市测试分支。设置同步数据增加了字段，客户端和服务端需使用相同新版；网络版本已区分，避免旧版错误解码。

验证：设置存档和网络编解码覆盖全部八种开关组合；独立设置请求不会覆盖其他偏好。服务端 GameTest 使用实际掉落物的拾取流程检查关闭保留掉落、开启拾取、拾取延迟及普通模式不受影响。
