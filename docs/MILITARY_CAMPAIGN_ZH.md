# 主世界与黑光维度的双向争夺

本轮范围为 NeoForge 1.21.1：整合 PR #95，并保留当前主线的生态、越肩镜头以及吞噬随机分支修复。Forge 移植单独跟踪，不把“双维度”误作两个 Minecraft 版本。

## 原作依据与 Minecraft 适配

- 一代的军事基地摧毁、基地潜入吞噬军官、蜂巢摧毁，是不同目标的行动，不等于杀完附近任意几个敌人。参考[一代行动记录](https://www.supercheats.com/guides/prototype/consume-events)及[基地潜入记录](https://www.supercheats.com/guides/prototype/infiltrating-bases)。
- 二代开发者将绿区描述为军事重防线，黄区为戒严与实验区域，红区为大型血肉增生和感染体占据的战区。参考[设计总监访谈](https://www.dreadcentral.com/news/29691/design-director-matt-armstrong-talks-prototype-2/)。
- 将两方行动结果接入本模组动态红黄绿压力，属于 Minecraft 的开放世界适配；不声称原作三岛颜色会按同一算法自由变化。
- 原作街区交战和追击主角的突击队是不同系统。一代突击队呼叫可被抢先击杀呼叫者打断，二代采用警戒后的延时到达；不能混写成同一规则。参考[突击队机制](https://prototype.fandom.com/wiki/Strike_team)、[一代官方手册](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/10150/manuals/Manual_english.pdf?t=1655760765)。本轮实现持续地面清剿与现有士兵的警戒交战，尚未实现空中突击队。

## 要完成的流程

1. 先解决 PR 的六处主线冲突，再接回已验证的吞噬修复；载具输入、外部镜头角度、人口配置和客户端协议合并保留。
2. 主世界与黑光维度分别保存基地和行动。黑光维度使用军方大型营地、黑色守望大型基地两种不同布局，并按真实可用地形组合入口检查站和车库；保留道路、现有建筑与地理。不同副本、维度、旋转的据点保持独立身份。
3. 病毒释放后，附近可用基地从实际驻军中派出清剿队，前往已加载感染源。红区还会持续接收新编队：缺少感染源时巡逻，发现感染源后前往作战。新编队有新 UUID、有限初始武器和弹药；不复活阵亡的原驻军，不重置现有库存，不用倒计时替代实际攻击和破坏。外围入口距所有观察玩家至少 32 格，并验证已加载、实体可活动的地面、边界、水和碰撞。
4. 清理建筑核心、实体母巢或作者母巢的实际出入口后，压低当地感染压力。还有活动感染源时不能直接变绿；清干净后进入恢复期，外来感染仍可造成反扑。
5. 玩家摧毁基地的真实指挥设施，会停止该基地的新驻军/车库工作。匹配阵营伪装可在基地终端取得潜入目标，吞噬实际军官后造成有限期瘫痪。重复交互、读档和多人操作不会重复结算同一基地奖励。
6. 行动结束、缺弹、损失过重或任务失败后，幸存者返回真实基地。未加载、无人活动、停服期间不补刷、不开远程区块、不跳过战斗。
7. 开关、行动间隔、目标距离、部队规模、并发预算、恢复时长、压力与奖励均提供服务端配置。
8. 士兵使用现有真实目标 AI：视野内发现未伪装的感染主角可主动交战，匹配阵营且未暴露的伪装可骗过士兵，暴露身份后恢复追击。没有跨维度或隔墙的全知目标追踪。

## 默认服务端预算

配置：每个存档的 `serverconfig/blacklight-military-campaign-server.toml`。

| 配置 | 默认值 | 含义 |
|---|---:|---|
| dispatchIntervalTicks | 600 | 可用基地组织原驻军的检查间隔 |
| reinforcementIntervalTicks | 400 | 红区尝试补入一队新地面部队的检查间隔 |
| squadSize | 4 | 单队最多人数 |
| activeOperations | 2 | 每维度行动数，不随玩家人数翻倍 |
| fieldPersonnelLimit | 24 | 加载中的环境增援人数上限；仍受总驻军上限约束 |
| operationTimeoutTicks | 6000 | 行动实际活动时间上限 |
| fieldLifetimeTicks | 12000 | 环境增援活动寿命；撤离后远离玩家才退场 |
| sabotageTicks | 24000 | 潜入瘫痪的附近活动时间 |
| naturalBases | true | 新主世界／城市区块的天然基地选择 |

毁坏的基地要恢复真实指挥设施才能恢复支援。未知／未加载的基地不能被误判为已经摧毁；无人活动、关服期间不自动清剿或累积部队。已有驻军、手动编队、载具乘员及玩家命令不会被环境增援的退场清理删除。

本轮保留 PR 中已有的卡车、装甲运兵车、坦克及车库／车队系统。自动清剿派遣的主体是地面步兵；没有把直升机、空中突击队或坦克自动参与本轮步兵任务列为完成。
