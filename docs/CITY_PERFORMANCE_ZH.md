# 城市生成性能与预生成

适用版本：0.3.4-dev.10-city.2，NeoForge 1.21.1 / Forge 1.20.1。

## 默认行为

- 福田城市仍按原有种子和离线地图生成。优化不会重新生成已有区块或覆盖玩家建筑。
- 每个存档第一次加载福田城市维度后，后台准备市民中心南广场周边 7×7（49）个完整区块；传送前不保证已全部完成。不会自动预生成整个深圳。
- 同时仅持有一个预生成目标区块的临时加载票，不强制实体运行。Minecraft 为完成光照和区块依赖仍可能处理周边区块，因此“一个目标”不等于只使用一个区块的内存。
- 默认完成一个目标后至少间隔 10 tick，服务器平均 tick 用时超过 35 ms 时不派发新目标。已在生成的工作不会被强行中断。
- 暂停、完成和维度卸载会释放本功能的加载票，区块由 Minecraft 正常保存、卸载。已有玩家加载票不受影响。
- 进度与运行/暂停状态保存到当前世界；正常重启后恢复之前状态。崩溃/断电后的磁盘数据仍以 Minecraft 存档为准，必要时重新 start 检查全图；不会覆盖已存区块。

## 管理员命令（权限等级 2）

```
/blacklightcity pregen status
/blacklightcity pregen pause
/blacklightcity pregen resume
/blacklightcity pregen start near
/blacklightcity pregen start full
```

`near` 从出生点向外准备 49 个区块。`full` 在旧福田维度覆盖 6930 个区块；
在新的 `blacklight:world` 中覆盖已收录地理地图（约 2541 万个区块，包含海域），
仅供管理员主动预生成。正常游玩只生成附近请求的区块，无需先执行 `full`。
`start` 重新从头检查目标范围；已有区块走原版加载，未生成区块才生成。`resume` 保留当前进度。
整片预生成适合开服前进行，需要时间和更多存档空间。它降低探索时现场生成的压力，不能消除磁盘读取、光照、网络发送、渲染与生物 AI 的开销。
旧版程序城市模式不启用此功能。

## 服务端设置

当前存档 `serverconfig/blacklight-city-server.toml`：

- `arrivalWarmup = true`：是否在首次初始化时自动准备出生点周边。已经开始的任务使用 pause 停止。
- `pregenIntervalTicks = 10`：新目标间隔，范围 1–200。调大更保守；不是每 tick 硬性毫秒预算。
- `mapCacheTiles = 64`：地图解码缓存条目，范围 8–256。默认数组数据约 8.1 MiB；不包含 Minecraft 区块和正在解码的数据。
- 原有 `cityMobLimit`、`population`、`infectionSpread`、`hiveFacadeDamage` 保留，控制运行中的城市开销。

## 实现

地图缓存只在索引和淘汰时短暂加锁，解压不再占用全局锁；相同区块的并发请求共享一次加载，不同区块可由原版工作线程并行解码。失败结果不进入缓存。
方块柱复用地图数据与屋顶几何参数，高度查询从实际最高范围向下查找，不再从世界顶逐层重复取地图。
预生成通过临时 FULL 加载票和非阻塞查询驱动，不在服务端 tick 里等待 `getChunkFuture`，也不另建线程直接修改世界。

## 验证范围

并发缓存、容量缩减与失败重试；地图覆盖顺序；生成方块与各类高度图一致性；预生成暂停/恢复及进度序列化；保留玩家方块；完成后释放加载票；现有城市、母巢和拾取回归测试。
性能测试只计指定坐标的地图查询及方块填充，不把该倍数当作整体帧率或完整世界生成速度提升。
本轮只使用后台测试服务器，不接管鼠标。最终客户端画面、多玩家长期压力仍需另行实机验收。

## 本机测量记录（2026-10-15）

剔除第 0 轮预热，取后 5 轮中位数。同一组 6 个区块的纯方块填充对照：

| 版本 | 原逐层计算参考路径 | 优化路径 | 耗时减少 |
|---|---:|---:|---:|
| NeoForge 1.21.1 | 25.37 ms | 17.90 ms | 29.5% |
| Forge 1.20.1 | 23.08 ms | 18.45 ms | 20.1% |

两条填充路径共用当前地图解码缓存，比较的是重复几何计算优化，不包含磁盘保存、光照和网络发送。六个样本的全部方块一致。
另对约 600 个分布坐标及地标、母巢出口的 0–319 高度逐块对照，并核对全部高度图类型。
NeoForge 355 项单元测试、Forge 354 项单元测试全部通过；两版各 14 项真实服务端 GameTest 全部通过。暂停恢复测试实际完成末尾两个区块，未跑完整 6930 区块或多人长时间压力测试。
