# 感染牛：解剖式成长样板

用户确认 `approved-direction.png` 的三阶段轮廓，要求进一步 Minecraft 方块化。概念图是方向依据，不代表模型已百分百还原或已获最终美术认可。

## 资产计划

- 目标：Java NeoForge 1.21.1，PC 原生实体光照；允许同时出现多只感染体。
- 风格：明确的方折面、大肌束、有限甲片；保留可辨认的牛科特征和后半身皮毛。头部也会重构，不能一直保留普通牛头。精细轮廓优先，同时避免碎块堆积。
- 材质：一个 128×32 像素图集，使用其中七个 16×16 材质块；原生牛皮继续读取当前资源包原生 UV。没有 PBR、半透明或全亮材质。
- 密度：约 1 texel / 模型单位；长面分配较长 UV，细节采用成组像素，避免高频噪点。
- 网格：6 个实际宿主绑定区域、35 个可编辑网格、596 个源四边面。基础皮肤和组织覆盖分两个绘制通道；成熟完全覆盖的基础面会跳过。口鼻端面采用连贯四边面，避免放射状三角扇接缝。没有新增附着物实体。
- 动作：身体各区域继承本次渲染的真实原生 ModelPart 矩阵；增生前肢将旋转中心移到肩部，前臂独立弯曲，三爪继承前臂后再卷曲。
- 头部：上下两片重构表面在初期准确组成原生牛头立方体；随后长出口鼻、额骨、颧部和后掠牛角。下颌有独立的三阶段铰链支点，呼吸和攻击时开合，不套用前肢摆动。口腔有内壁，两枚獠牙从上颌长出。
- 连续变化：同一拓扑的初期、中期、成熟形状键平滑插值；组织从局部裂口向外增长。左右前肢延迟由 UUID 固定，读取存档与更换观察者不重新随机。
- 变化范围：左右主导侧、连片组织显露时序和前肢宽度的 ±6% 差异均从宿主 UUID 固定派生。前肢关节与爪指支点使用对应的形状键一起移动。

## 编辑与运行

`cow_anatomy.bbmodel` 是成熟形态网格的可编辑参考工程，包含重构头骨和下颌；原生小角、保留的其他原生立方体和运行时原生皮肤 UV 仍由游戏提供。工程使用材质图集作形状参考，不能代替原生客户端材质验收。运行时三阶段形状键以 `tools/author_tissue_cow.py` 为源，导出至 `assets/blacklight/tissue_blueprints/cow.json`。编辑某阶段后需要同步三份顶点拓扑，并重新导出；不能只编辑成熟工程就认为另外两个阶段也已更新。

没有可调用的 Blockbench MCP，本轮通过仓库已有的脚本网格资源流程制作并导出 Blockbench 工程，不声称在编辑器中完成了操作或验收。

`approved-direction.png` 由图像生成工具生成。原始请求为三阶段感染牛：裂口、单侧肩背与前肢肌肉异变、前重后轻的成熟四足体；保留牛头，增加分节三爪、连贯肌束、黑色甲片和肩后触须腺体。随后按用户要求编辑为大块方折面、像素材质和可建模结构。概念图不打入模组 JAR。

## 当前边界

这是一套感染牛样板及可扩展的模板接口。其他宿主仍走此前的专属附着物/通用覆盖流程；尚未宣称所有模组模型都能自动达到同一美术质量。每秒同步保存的组织年龄仍由服务端控制；造型更新不增加生命、攻击等战斗数值。
