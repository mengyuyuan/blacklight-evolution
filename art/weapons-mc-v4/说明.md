# 黑色块面与红色血管武器组

基于用户已确认的利爪和粗细血管风格，手工设计刀锋、锤拳、鞭拳和肌肉强化。本目录保留可编辑造型母版；dev.20 已通过 `tools/integrate_mc_weapons.py` 接入游戏，详见 `docs/MC_WEAPONS_ZH.md`。刀锋使用 `art/blade-mc-v6/`，本目录刀锋仅为历史稿。

## 造型

| 文件 | 结构 |
| --- | --- |
| `claws.bbmodel` | 保留已确认利爪；双臂、掌侧弯刃、细腕、粗细血管 |
| `blade.bbmodel` | 前后双向长刃、厚刃根、连续连接组织；按用户反馈接合中段断口 |
| `hammerfists.bbmodel` | 双臂、收腕、纵向组织桥、厚拳面、骨质拳峰 |
| `whipfist.bbmodel` | 长鞘、斜向骨脊、后伸尖刺、末端双钩 |
| `muscle_mass.bbmodel` | 双臂、大块肌束、窄腕、独立弯曲手指 |

血管采用粗主干、较细分支和收尖末梢，交汇处略宽。暗红组织边缘与细亮芯分层，分布随每种武器的结构重新设计。

原版解包仅用作轮廓与解剖位置参考。新模型没有导入原版网格或贴图，也没有体素化原版模型。对照图中的原版武器用于本地审阅；模型文件仅包含本次手工设计的几何和配色。

## 文件与尺寸

- `.bbmodel` 均为 Blockbench Free 模型，内嵌基础配色图。
- `weapons_pixel.png` 为基础配色图；前六个材质保留已确认利爪的配色。
- `weapons_emissive.png` 为同 UV 的自发光颜色和透明遮罩。
- `layout.json` 保存右侧设计母版、部件分组和自发光材质名称。双臂武器的 `.bbmodel` 已包含镜像左臂，并反转面绕序、映射左侧骨骼分组。
- 坐标为参考 A 姿态，每米 16 个建模单位；尚未转换为游戏骨骼局部坐标。

总览中的各列单独取景，便于看清细节，不表示武器之间的大小比例。每种武器的原版并排对照使用相同视角和同一个投影范围。原版参考照明提亮；鞭拳本地参考缺少漫反射图，使用灰色。

## 验证与待接入工作

已检查部件名唯一、有限坐标、非退化面、实体部件闭合边，以及血管路径位于模型表面。血管为明确标记的表面薄片，不要求闭合。已渲染正面、内侧、外侧、背面和明暗环境进行外观检查。

## 游戏接入与重建

骨骼转换、武器变形、自发光层和手部锚点已接入。普通自发光材质不会产生屏幕泛光。

修改 layout.json 中的可编辑母版后，运行 `python tools/integrate_mc_weapons.py`（需要 NumPy），再运行 `python tools/test_mc_weapon_geometry.py` 核对比例。

Blockbench 文件供手工编辑和造型审阅；导出游戏资产以 layout.json 为输入，修改 bbmodel 后需同步对应母版。
