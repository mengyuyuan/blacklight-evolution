# 原创毁灭技地刺模型

这六种地刺的控制曲线、截面、拓扑和颜色在本仓库独立建模。原作画面和本机研究只用于尺寸、组织结构与释放方式参考；生成工具不读取 P3D、私有顶点、UV、三角、贴图或形变数组。

`spikes.model.json` 是可编辑建模配方，`tools/author_devastator_spikes.py` 构造厚组织根、肌束、反曲骨刃、开放双叉、偏心棘刺及凸起红筋。红色筋络本身有体积，不是贴在黑色表面上的纹理。OBJ 可在三维软件中编辑；当前程序构建的配方和工具是生成版本的源文件，重新生成会覆盖同名 OBJ。

```text
python tools/author_devastator_spikes.py
```

输出为同目录十二个带顶点 RGB / UV / 法线的 OBJ，以及 `src/main/resources/assets/blacklight/models/devastators/spikes.json`。坐标 Y-up，单位为 Minecraft 格，`sourceScale=1`，白纹理配合顶点颜色和 Mod 湿材质；生成物没有原作贴图地址。

地上主尖高度分别为 2.90、4.15、6.95 格，完整簇为 3.45、6.35、7.75 格；根部留少量地下体积供真实地面遮挡。完整模型单刺 2186 三角、簇 7594 三角；对应 `_lod` 单刺 806 三角、簇 2134 三角。LOD 保留同尺寸的厚根、双叉、主侧刺和凸起红筋，用更少截面重新构建闭合体，不跳过三角打孔。`lod` 配方可编辑采样密度与预算，每对模型共用保守包围盒。

模型检查覆盖有限坐标、索引、单位法线、开放叉刃和凸起红筋组件；实际材质、增长/回收、碰撞和帧率由游戏运行时验收。
